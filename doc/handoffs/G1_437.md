## 用户 10-06 的观察（三组判法完全不同，用户要求总管新开三道分别做）
- **ry 日曰**：
  - 字形可用，量宽高比：「曰」稍宽，「日」稍瘦；
  - 「曰」常用于排比，连续几个反复出现；
  - 两字意思区别明显：高置信的用规则，低置信的交大模型；
  - 整理本大部分对，偶尔有错字。
- **rr 入人八**：
  - 字形有区别：「入」上头像有一横，撇捺连着；「八」上面也有一横，但不和左撇相连；「人」连写，上面没有横；
  - 试投影法，或单独训一个小模型；
  - 整理本置信度高。
- **jys 己已巳**：
  - 整理本几乎不用看，整理时没按文意；
  - 靠常见词组：干支匹配；大部分是「而已」、表示「已经」→「已」；
  - 「己」用在天干，或表示「自己」，后面常跟「意」「見」「說」（以己意、參以己見）。

各组 README 的「用户人裁与观察」一节有详细记录和本批的搭配实例。

## 复现
```bash
# 快照解到沙箱同 G0（dataset char-groups/README「快照与复现」）
python research/char_groups/build.py <snap_root> <dataset>/char-groups          # --ctx 默认 30；收 review/*_verdicts.jsonl
python research/char_groups/baseline.py <dataset>/char-groups
python research/char_groups/summary.py <dataset>/char-groups
python research/char_groups/review_pages.py <snap_root> <dataset>/char-groups <ry|rr|jys> -o page.html [--seed-verdicts <组>_verdicts.jsonl]
python .claude/skills/review-artifact/scripts/harvest_verdicts.py <读回的 html> -o <dataset>/char-groups/review/<组>_verdicts.jsonl
```
续裁：三页都留着，用户接着点就会存回页面。再收一次后，覆盖 `review/<组>_verdicts.jsonl`，再重跑上面三步。
新道要换题时：删掉或改名 `review/<组>_cards.jsonl` 会重抽；同一批续裁要保留这份文件，id 才对得上。
