## `border_detect` Step1 边框探测

- 输入：`raw_page`
- 产出：`borders`、`line_index`
- 出口闸 `border_detect_gate`（page，不过时 block）：
  - L0 `page_type_skip`：页型是否判定为 skip 类（封面/书签/牌记）——block 级，这些页没有正文栏格，套列窗口是无中生有
  - L0c `page_type_custom`：页型是否为 custom（如上諭，列数与正文不同）或判不准——flag，不拦（custom 还没有专门的窄列处理逻辑，uncertain 按 body/standard 兜底）
  - L1 `column_count`：探出的列数是否等于版式列数——block 级判据，列窗口错了 Step2 整页都没法射影
  - L2 `vline_wander`：是否有单条界行 w80 跑飞——flag，不拦（未验证阈值超了必错）
  - L2b `line_adjusted`：下版框有没有被推到框条上 / 界行有没有按文字缝重定位——flag，只是记录 Step1 自我修正了什么，给人核对
  - L3 `outer_frame_missing`：上/下外框有没有探到——flag，不拦。單邊框（frame_kind=single）不算没探到；剩下的 none 仍分不清「磨没/裁掉」与「漏探」
  - L4 `page_size_odd`：Step0 页面预检（page_survey）判尺寸异常——缺省 flag 不拦，书级 params.border_detect_gate.page_survey_block=true 才升 block；命中白名单永远只 flag。页1 另标，不管尺寸判据
- 进指纹的册配置：`leaf_layout`、`expected_cols`、`bottom_gap`、`top_band_frac`、`bottom_band_frac`、`column_grid`、`col_pitch`、`frame_height`、`vline_polyline`、`outer_shift`、`outer_gap`、`frame_layers`、`columns`
- 进指纹的代码：`open_guji_cv.impl.keben.border`、`open_guji_cv.seg.polyline`、`open_guji_cv.seg.frame_types`、`open_guji_cv.seg.grid`、`open_guji_cv.seg.lines`、`open_guji_cv.impl.keben.column_types`、`open_guji_cv.impl.keben.column_pair_merge`、`open_guji_cv.impl.keben.pitch_rescue`、`open_guji_cv.seg.columns`

## `line_detect` Step1 行探测（现代印刷）

- 输入：`raw_page`
- 产出：`borders`、`line_index`
- 出口闸 `line_detect_gate`（page，不过时 block）：
  - L1 `no_body_column`：有没有探到正文列——block，空页不套列窗口
  - L1b `column_overflow`：正文列数是否超过版式上限——flag
  - L2 `merged_column`：有没有并列/粘连的宽列——flag
  - L3 `footnote_column`：有没有脚注列——flag，只提醒
- 进指纹的代码：`open_guji_cv.impl.modern.line_layout`
