# borders 产物的框型字段（事实与口径）

产物 `borders`（`border_detect` 出，字段全表见 `步骤与产物.md`）里与外框有关的字段。**以下字段名与含义保持稳定**，下游（切字做字与框线分离等）可以依赖。

| 字段 | 含义 |
|---|---|
| `top_frame_kind`／`bottom_frame_kind` | `double`（内外双线）／`single`（只有一条线）／`none`（没探到）／缺省 None |
| `top_outer_offset`／`bottom_outer_offset` | 外框离内框线的偏移，上负下正，像素；`double` 才有 |
| `top_bar_extent`／`bottom_bar_extent` | `single` 时粗条从内框线起向外的宽度，像素 |
| `top_outer_estimated`／`bottom_outer_estimated` | True＝这页没量到外框，位置是按册 `outer_gap` 估的（往外让了 10px，不会切到字） |
| `v_outer_side` | 纸边侧外框在哪一侧：`left`／`right`；靠版心一侧没有外框 |
| `v_outer_offset` | 纸边侧外框离最边上界行的偏移，右侧为负、左侧为正（新坐标口径同上下） |
| **`v_outer_estimated`**（2026-11-23 新增） | True＝册配置 `side_frame` 规定这一侧有外框，但这页没量到（磨没／裁掉／糊了），位置按 `outer_gap.side` 估。缺省 False；**False 时不落盘**（同 `cells.alt_columns`），没用新规则的册产物逐字节不变，读回按 False |

## 指纹
`side_frame` 不进 `border_detect.book_deps`（那会让所有册指纹变）；只给写了的册在 `engine._self_payload` 加键，没写的册指纹逐位不变。

## 怎么来的（套书规则，册配置）
- `frame_layers: {top: 1|2, bottom: 1|2}`：1＝单线（脈經上下），一律 `single`；2＝外框一定存在（殿本、史記、全唐文上下），只量位置。
- `side_frame: {even: left|right|none, odd: …}`：按页码奇偶指定纸边侧。殿本偶左奇右，史記奇左偶右；换书必须重标。
- 估出来的位置（`*_estimated=True`）是"应当在这里"的推断，不是看到的线：做字与框线分离时，要用实测墨线的地方（如判墨条是否是框）应当跳过估位的边。

## 内框线落在外板框上：`inner_pull`（border_detect 参数，11-25 起缺省开）
双线版框的书内板框线磨淡时，探出的上／下框会落在外板框粗条上（殿本、全唐文、史記，见 `已知问题.md` 第 1、4 条）。参数 `inner_pull: true` 且册声明了该边 `frame_layers: 2` 时，线压在（或紧贴）≥10px 的粗条上就往文字一侧找细条当内框线（细条离粗条外沿的距离须在册 `outer_gap` 的 0.5–1.7 倍内）；找不到且线压在粗条里，按「粗条外沿 − 册 `outer_gap`」估。要用就写册 `params.border_detect.inner_pull: true`，并标好 `outer_gap: {top, bottom}`，该册从 border_detect 起过期。
