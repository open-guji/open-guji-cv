# 开关登记表

每个「缺省关、按书开」的参数在这里占一行，写清它的默认值、证据、哪些书开了、谁负责。
**开或关一个开关之前先有证据**：用 `guji exp`（[exp_framework.md](exp_framework.md)）跑一份 A/B 报告，把报告链接填进「证据」列。报告末尾的判准只说达标没有，开不开由人定，定了记在这里。

- 册上实际开没开，以工作区 `books/<册>.yaml` 的 `params:` 为准，这张表是账，不是配置。
- 改了某行（开、关、换阈值），同时在「证据」列补上新报告或 issue 链接。
- 参数路径写 `步.字段`；阈值类参数跟着它的开关写在同一行。

## 怎么给一个开关出证据

```bash
# 1. 写实验 yaml（只写与基线不同的参数，判准先写好），例子见 doc/exp_framework.md
# 2. 跑（上游从快照复用，只从受影响的步起算；绝不写正式 products/）
guji exp run exp/shadow_veto-vol05.yaml -w $WS --snapshot <快照产物根>
# 3. 看 $WS/experiments/<实验名>/report.md；翻转格抽人看：
guji exp flips <实验名> sample -w $WS && guji exp flips <实验名> page -w $WS
```
