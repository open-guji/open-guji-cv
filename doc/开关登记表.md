# 开关登记表

每个「缺省关、按书开」的参数在这里占一行，写清它的默认值、证据、哪些书开了、谁负责。
**开或关一个开关之前先有证据**：用 `guji exp`（[exp_framework.md](exp_framework.md)）跑一份 A/B 报告，把报告链接填进「证据」列。报告末尾的判准只说达标没有，开不开由人定，定了记在这里。

- **会自动放行一类格的开关**（新通道、放宽门槛、越过整理本），上线门槛按降人审框架（guji-manager `doc/01-粗校/降人审迭代框架.md` 第五节，sheldon 11-05 定）：该类金标上的放行子集 0 错，且独立盲读抽样 0 错；抽样量按放行量定——放行 <100 格抽 30，>300 格抽 100，>1000 格抽 200（0/30 只说明错率上界约 10%）。有错先收紧（只收与整理本同字、只放白名单组、提高字形分）再测；上线后每轮滚动抽 30 格。证据列写明金标文件、抽样量和结果。
- **越过整理本放行的白名单按书、按组定**：每书每组抽 30 格金标，不继承别的书（殿本的名单不带到别的书）。「哪些书开」一列逐书写。
- 大模型的读法只能当文意证据，字形侧要算法证人（库字形分、字体渲染分等）；**看图的大模型不当放行证据**，只给人审页预标注（11-05 定）。现行代码里的出入见 [降人审漏斗-管线侧对照](design/降人审漏斗-管线侧对照.md) 第四节。

- 改了某行（开、关、换阈值），同时在「证据」列补上新报告或 issue 链接。
