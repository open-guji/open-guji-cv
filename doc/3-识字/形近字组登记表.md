## 二、合并规则

- 注册字组表每组一条，组 id 照旧；
- 字对来源 1–4、6 按无序对去重，`src` 记全部来源。两个字同在某个注册组里的对挂到那个组（同在几个组就挂几个）的 `pairs` 下；
  其余每对单立一组，id 为 `p:<两字按码位序>`；
- 剔除名单里、又没有手工／人裁／刻形（shape）来源的对不收（同 `build_near_groups.py merge`）；
- 仓里的表只用仓内来源（1–5）。书级来源（6、书配置里的 3b 组）用 `--pair-clf <书>=<文件>`、`--glyph-near <书>=<册配置>` 生成书级版本，
  放数据目录，不提交。

现版（仓内来源）：**620 组**＝注册 185 ＋ 单立字对 435；字对 573（手工 20、人裁 42、字体 78 全在 `near_groups.json` 的 572 里，另加刻形 1 对 之矣）；
按类型 near 292、variant 322、fold 6。带全唐文 pair_clf 的书级版本：669 组（多出 50 对没别处登记的）。

## 三、schema

```json
{
  "format": "near_groups/2",
  "types": {"near": "…", "variant": "…", "fold": "…"},
  "font_tau": 0.988,
  "n_groups": 620, "n_registry": 185, "n_pair_groups": 435, "n_pairs": 573,
  "n_by_type": {…}, "n_groups_by_src": {…}, "n_pairs_by_src": {…},
  "books": [],                                   // 并进来的书级输入（仓里的版本为空）
  "groups": {
    "guan": {
      "chars": ["官", "宫", "宮"],               // 成员，按码位序
      "type": "fold",                            // near 异字形近／variant 同字异码／fold 折叠组
      "name": "官宫宮",
      "fold": {"宮": "宫"},                      // fold 组才有：异体 → 它归的字（注册表 families 每族第一个字）
      "families": ["官", "宫宮"],
      "canon": "…",                              // 有暂归一（PROVISIONAL）的组：归到的字
      "methods": ["near_p", "ctx"],              // group_flow 方法数组，按顺序；单立字对为 []
      "combine": "agree", "review_methods": […], "form_methods": ["top1"],
      "registry": {"table": "SHAPE_GROUPS", "kind": "near_form", "config_dir": "config/groups/guan",
                   "overlaps": [], "default_flow": true},
      "src": ["near_groups", "registry"],
      "pairs": {"官宫": {"src": ["near_groups"], "ng_src": ["lib:qtw", …], "near": {"qtw": 0.9881}, "core": true, "font": 0.99}},
      "books": {"<书>": {"pair_clf": {"model": "config/groups/pair_clf.json", "pairs": {"官宫": 3}},
                         "glyph_near": {"id": "gong", "methods": {"cnn_small": "models/glyph_near_gong"}}}}
    },
    "p:天夭": {"chars": ["天", "夭"], "type": "near", "methods": [], "src": ["near_groups"], "pairs": {…}}
  }
}
```

类型怎么定：注册组 kind=variant → `variant`；kind=near_form 且有 `families`（族里不止一形）→ `fold`；其余 → `near`。
单立字对：`near_groups.json` 的 src 里有 `variant` → `variant`，否则 `near`。
人定覆盖：`config/near_groups/type_override.json`（`{对: {type, note}}`，只管单立字对组；2026-11-28 Sheldon 定 pair_clf 来的 侣侶＝variant、凊淸＝near）。
只改 `type`；现役读口（`NEVER_MATCH_FAMILIES`、`partners()` 等）按 src 派生、3b `expand_refs` 只取 chars／fold／books，都不读 type。

## 四、读口

`near_registry.load(path=None)`；`reg.get(组)`、`reg.groups_of(字, types=None)`（注册组在前）、`reg.by_type(*类型)`；
`reg.glyph_near_spec(组, book=None, **覆盖)` 转成 3b 书配置 `groups.<组>` 的 dict（`chars`、`fold`、`methods`，书的 `trigger`／`delta`／`topk`）；
`expand_refs(groups, book)` 展开书配置里的 `{ref: <组 id>, …覆盖}`，一个 `ref` 都没写时原样返回同一个对象（参数哈希逐位不变，测试守着）。
**`steps/glyph_near.py` 2026-11-28 接上了**（`GlyphNearStep.book_params`，按本册 id 展开、重算 `methods_sha`）：书配置写 `{ref: rr, trigger: member, methods: {rr_shape: config/groups/rr_shape.json}}` 即可，成员从表里来；没写 `ref` 的书参数原样不动。从第四步搬来的看图判法（rr_shape、wu_shape、hou_shape…）用 `trigger: cands` 罩住 4d 的触发格，各方法的 sims／证据写法见 `groups/near_methods.py` 模块头。一份模型文件挂多对的方法（part_shape）写 `methods: {part_shape: {path: config/groups/part_shape.json, pair: [剌, 刺]}}`，一个组取一对。pair_shape（一对一个文件）照样写 `{path, pair}`：大太 `ref: dt`、王玉 `ref: wyu`、還遺 `ref: yh`、之矣 `ref: "p:之矣"`。
