# 人审率分析：vol04–09 未放行格的类型与降低办法（2026-10-19）

重跑 vol04–10 时对"未放行（要人审）"的格做的分类与分析。口径：vol04–09、非标题槽、去掉刚重裁未补认的页，共 **1,641 格 / 160,159 格 = 1.02%**（vol10 还在认字，未含）。cv rc/v0.4.6。

## 先读这三条
1. 整理本匹配算法没有坏。"整理本没字"是我们这侧格子与整理本行对不上（多切、并格、劈开、整理本写〓），要修切分与列级对位。
2. 巻不是异体映射表的问题：字形库里没有"巻"（卷 40 例、巻 0 例），刻本是巻形，库首位只能是卷。
3. 空位判非字不能批量放行：126 格里 22 格是整页破损，31 格近方有真字，67 格是半个字。改列成切分缺陷清单。
