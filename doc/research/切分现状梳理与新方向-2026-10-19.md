# 切分现状梳理与新方向（2026-10-19）

> 用户：切分是准确率提升的一大障碍。四类问题：①字的截断（二、三、高、元这类部件不相连的字）；
> ②上下粘连；③首末字带上下版框、或带左右界行；④双行小注认成正文。各种特殊处理越加越乱，
> 调一处坏一处。要求：先理清现状，找问题在哪，再想没试过的方向。
>
> 本文只读代码、文档与 overview 卡片写成，没有改生产代码。有一处是我自己现量的（§二·3 的版式转写核对、§四·E 的跨列相位），已注明。

## 一、现状：四类问题各靠什么在挡

链路（keben_body_v2）：Step1 版框/界行 → Step2 列图矫正 + **抹掉**框线界行 → Step3 **固定格数**弹性 DP
→ DP 之后逐格定类型（空白 / 雙行 / 單行注 / 正文）→ 粘连切点出候选、U-Net 裁判 → Step4 `CharExtractor`
十来道列端清渣 + 裁紧（格内剩余墨的外接框）。

| 问题 | 现在靠什么 | 量到的残余 |
|---|---|---|
| ① 截断（二三高元、書被劈） | Step3 **没有**「部件归组」。全靠 DP 代价把切点挤出字内空隙：`INK_LAM`、矮格墨满 `mass_lam`、间距 λ、`BLANK_MIN_RATIO`；`lam4` 缺省关；L0′ `split_suspect` 只标记不改切法。Step4 的列端渣格闸另有两条逃生口保「一」「二」。 | 「一矮一高 + 切点附近零墨」两册扫出 48 条；10 册末格偏矮 26 格（17 格是末字被劈，复核 10/10 切错，5 格已被错放成「一」「上」「仁」）；「顶部被切」测了 5 个量都分不开；列尾细字尾裁三版都是修 2 坏 1–3 |

## 二、病根：为什么调一处坏一处

### 1. 早定、硬定、不能回头

- **格数在 DP 之前就定死**：版式常量 21 + 闸给的抬头 hint + 「版框矮就减一格」。多一个字就无解或丢字，少一个字只能靠空白格吸收。格数一错整列滑格，后面的缝、U-Net 都救不回。
- **DP 只出一条路径**：没有 k-best，没有格数或相位的备选。约一半补丁其实是在「补候选点来源」（低墨行、合成点、周期锚点、窗顶点）。
- **格类型在 DP 之后才判，不回馈 DP**：DP 自己判空白用「行墨 <0.08 列宽」，定类型用 `min_ink_ratio`，两把尺子。

### 2. 判据是「局部几何量 + 阈值」，而这四类问题都卡在几何量分不开的地方

四类问题其实是同一个问题：**这块墨属于哪个字、是不是字、是哪种字**。在几何量分布重叠的区域，阈值只是把错从一类挪到另一类。手册自己写过「分布重叠了就别再调阈值」，负结果也一再印证：

- 「顶部被切」5 个量全分不开；
- 列尾细字三版都修 2 坏 1–3；
- 型1 夹注自动裁剪假阳性 89%；
- `lam4` 注释写着「收益和代价纠缠在同一个量上」，`LOW_INK_FRAC` 写着「不单调」。

代价项（ink_lam、λ、mass_lam、blank_cost、drop_lam、lam4）都作用在同一对量（格高偏离、墨量）上，彼此抵消。默认 λ 来自 vol02/135 一页的网格搜索，INK_LAM 只在 bxgb 上扫过——**是手调的，不是学出来的**。

### 3. 最强的信息没有进切分

**(a) 整理本的逐列版式（本次核实，这是最大的发现）。** 工作区 `corpus/daizhige/*.jsonl` 不是一段纯文本，而是**逐页、逐列的版式转写**：每列给出若干 run，`text` 带起始格号 `start`，`note` 带右行 `r`、左行 `l` 各几个字。我拿 vol02 p19 对了一遍：

```
0001-0229 (1-57b)  cap=21 ncol=9
 col 0 text start=2 殆京氏易傳三卷舊本題曰陸績注溶偶觀之未
 ...
 col 7 text start=2 讀晚乃卓然自立葢亦竒士云
 col 8 text start=0 周易注十卷 + note start=5 右「浙江巡撫」左「採進本」
```

和刻本图像逐列逐字一致：提要正文低两格、书名顶格、小注右四左三，都对。全语料 10,107 页，149,512 个 text run，11,660 个 note run；职名页的「臣」也以 note 记着。

也就是说，对四庫總目这部书，Step3 最难的几件事——**这一列几个字、从第几格起、哪几格是小注、小注右行几个左行几个、末格有没有字**——在切分之前就有一份几乎就是答案的东西。

可它现在只在切分**之后**用：`align_ref_coord` 拿它按坐标配字，**格数对不上就退回**（vol03：876/900 列对上，24 列退回；vol01 1,752 列里退回 466，多是职名/目录页），而且不进任何准入通道。方向反了：退回的那 3% 列，恰恰就是切分结构错的列。

**(b) 字形库知道每个字长什么样**：「二」是两横、中间留白，「一」很矮——这是判断「这道白缝在字里还是字间」所缺的知识。现在只有 vol01 职名页的 `roster_glyph_refine` 用它（104/106 数对）。

**(c) 识别器本来可以当裁判，但现有的识别器「太宽容」**：实验一、四表明，CNN 和弹性配准对半字、多一截邻字笔画几乎不敏感（cov 差在千分位）。所以「用识别选切法」的几次尝试都失败了（实验九没信号；64 条盲裁人只认同 10%）。**失败的原因是打分器没见过负例，不是「多方案后选」这条思路错了。**

### 4. 最有效的学习工具只盖住最小的问题

U-Net 只看双格窗口，只在 char–char 切点的 ±20~45px 走廊里改形状。格数、相位、类型、框线一概不碰。粘连点本来就只占格线约 8%，而且对文本影响小（识别不敏感）。

### 5. 验证面太窄，金标会漂

- 切线金标 1,603 条里 1,498 条是 legacy 坐标；`row-boundaries` 只有 2 页；格类型金标试点 39 格。
- 人裁按 (页, 列, slot) 绑定，上游一变就整体漂移（开 `hint_ignore_dash` 会让 vol01 500 个人裁错位）。
- 每次改动只能在一小批页上「内存新旧对比 + 放大看图」，很难同时看到别的册被改坏。这就是「修 A 坏 B」的机制性原因。

### 6. 重复逻辑

夹注两套判据（Step3 一套，Step4 v1 再跑一遍，参数还不同步：ALIGN 8 对 16），十来道列端清渣互相有顺序依赖。

## 三、已经试过、不必再试的（摘自 05/08/10 卡与 research 文档）

| 方向 | 结果 |
|---|---|
| 只有字形项的整列联合 DP | 切点被拉进字身，R2s 46→52、94→123 |
| 识别引导局部精修（±14px） | 50 个人审字位救回 0 |
| 成对模板校验代替识别 | 真字对排第一 67.9%–84%，不如 CNN 93.5% |
| 模板归属（先认后切）当候选 | 加进池子无增益，配准 25 分钟/750 条 |
| 选择器：模板 δ / 合议 / 线性排序 / CNN 身份 | 都停在大块错约 1.5% |
| U-Net 真金标五折微调；身份条件 U-Net v3、v3a | 大块错不动；网络不读字形通道 |
| 笔画级归属 | 与 U-Net 打平（27 胜 26 负） |
| VLM 当选择器 | ≤39%，低于现役 45% |
| 送审门槛学习化（X3） | 漏放 147 对 149，代码反而多 |
| YOLO 整体替换 | 粘连打平、印章更差 |

这些几乎全是**粘连点的局部选择**问题。四类问题里的另外三类（截断、框、夹注），以及「格数 / 类型 / 相位」这一层，**没有被这种强度的实验覆盖过**。

## 四、没试过的方向（按投入产出排序）

### A. 版式转写驱动切分：从「切完再配字」改成「照着答案切」（最高优先级）

**做法。** Step3 的输入多一份「本列应有的单元序列」，来自 daizhige 逐列本，例如：

```
[空, 空, 正文×19]
[正文×5, 空×0, 夹注(右4,左3)]
```

DP 不再自己猜格数和类型，只解几何：在已知的 K 个单元、已知类型下，求最好的 y 边界。代价项照用，还可以按字加先验（第 k 格是「一」就该矮，是「二」就允许中间留白）。

**为什么四类问题都受益：**

- ① 二/三被劈：格数是固定的，把「二」劈开就要多出一格，不可行。顺带知道哪一格是「二」。
- ④ 夹注：转写写明了从第几格起是小注、右几左几，几何判据只需定位，不需判别。职名页的「字数静默错」也随之消失——每列字数是已知的。
- ③ 首末框：知道末格有没有字、是不是「一」，「框渣还是字」就有了答案（26 个末格偏矮里那 9 个空白/残边、17 个劈字，可直接分开）。
- 抬头：`start=0` 与 `start=1/2` 直接给出抬头多几格，不必用框上高度去推 `n_raised`。

**为什么不会循环。** 转写是独立于本管线的外部文本，不是识别结果。页↔语料页的对应，`align_ref_coord` 已经能做（列→行投票 97% 成功）；也可以按卷做一次性对照表放进册配置，作为 Step3 之前的一个 `needs=corpus` 小步。

**必须做成软约束。** 版本异文存在（`align_ref_coord` 抽 30 格看到 1 格），转写本身也可能分行错一位。所以允许插入/删除/类型不符，但要付代价。不符之处本身就是有用的输出：要么切分错，要么版本异文，都该进人审。

**零改算法就能先拿到的收益**（符合冻结期规矩）：

- 先做一个「逐列本对照闸」：现役 Step3 的单元序列与转写不符的列，一律降级待审。
- 同时它也是一把**不漂移、覆盖全书的结构尺子**：十册每一列都有「格数 + 类型」的参照。第一次可以量出真实的结构错误率，并按「多格 / 少格 / 漏夹注 / 误夹注 / 起始格错」分类。

**换书时：**

- 有带分行的整理本（光盘版也是一行一列）：同上。
- 只有不分行的整理本：分行可以和图像一起解——每列 ≤21 单元，整页做一次 DP。
- 什么都没有：退回现状，或用 C 的列识别器生成假设。

**第一步实验（约 1 天）。** 在 vol02/vol03 上对比现役 Step3 与转写的单元序列，出分册、分类型的不符表；挑不符列，在 `seg_harness` 里加一个「给定单元序列」的 DP 变体，量修好几列、在原本一致的列上有没有改坏。

### B. 「这一格完不完整」判别器：用合成负例训练

前面说过，「多方案后选」一再失败，是因为打分器对半字和多笔不敏感。补上的办法是专门训一个判别器：

- **正例**：字形库里人裁过的干净刻例。
- **负例**（全部合成，零标注）：
  - 切掉上/下 10–40%（截断）；
  - 拼上邻字一截（混入）；
  - 叠上真实版框/界行条（带框，框条可从空白格和列端裁真图）；
  - 两字合一格；
  - 雙行小注的半边、或并排两小字一框。
- **按需加难例**：二、三、一、元、高、書、言、之 这类部件分离的字，多造「从字内白缝切开」的负例。

用途有三：

1. 给 Step3 的 k-best 路径和 A 的候选打分；
2. 直接当放行闸——「不完整」概率高的格不放行，比现在的十几个几何 flag 更统一；
3. 给现有的 26/42/19 格清单做自动复核。

这与现有的 `instances` 四分类（clean / contaminated / truncated / not_text）是同一个任务，区别是从 91 个真样本换成无限合成样本。

**第一步验收**：在 26 个末格偏矮、vol01 42 格、vol02 19 格、A 批 196 条上，看它能否把切坏与整字分开（现有几何判据只有 65% 精度）。

### C. 整列过切分 + 格子图联合解码：把「几个方案后选」做成完整形态

这是用户提的第三个思路的完整版本（手写中文行识别的经典做法，切分-识别一体化）：

- **过切分**：每个可能的缝都切开，宁多勿少。
- **组合候选**：相邻 1–3 段合成一个候选字。
- **打分**，每个候选综合五项：
  - 几何先验（按字类的高宽比，可从字形库统计——「一」矮、「書」高）；
  - B 的完整性判别器；
  - 识别置信；
  - 21 格与转写的约束（A）；
  - 语言模型。
- **解码**：整列 Viterbi，各项权重在金标上学。

和过去失败的「只有字形项的联合 DP」差在三处：有几何先验项；打分器能拒绝半字（B）；候选是整列路径，不是 ±20px 的缝。

适用于没有逐列转写的书（全唐文、北行日录），或者当作 A 的备胎。投入比 A、B 大，建议等 A、B 的数出来再定。

### D. 列级学习模型，用整列合成数据训

U-Net 只看两格，所以只能裁粘连。换成看整列（或 3–5 格窗口）的模型，同时输出两样：

1. 逐行「格界」热图；
2. 逐像素墨的类别：正文 / 小注右行 / 小注左行 / **框线界行** / 噪点印章。

训练数据**整列合成**，真值精确：

- 字形库干净刻例按真实格距排列；
- 随机插空白格、夹注段、抬头；
- 首末格压上从真图裁下的版框条，左右贴界行；
- 控制粘连重叠量；
- 加真实背景和噪点。

能解决的：

- ③：把「抹框」从十道规则换成一个像素分类——框线和笔画交叉处，按像素判它是哪一类，不再「抹掉再找补」。
- ④：小注右行、左行的墨直接分开。
- ①：模型看得到整个字的上下文。

注意事项：

- 文献路线 2（1D 热图）原计划「金标 250+ 条再训」，现在已有 1,603 条可作验证集，前提已满足。
- 要吸取 U-Net v1 的教训：感受野要够大，加纵向平移增强，防止学到绝对行号。

### E. 页级共享行网格：只能当弱先验（本次现量，结论是不值得优先）

刻本是先写在格纸上再刻的，我想看各列字缝的相位是否跨列一致，可以拿邻列互证。用 15 页（vol02 10 页、vol01 5 页）粗量，周期取 113px：

- 跨列相位偏差中位 **10px**，75 分位 19px；
- 同一列上中下三段的相位差中位 12px，只有 47% 在 10px 以内。

能当软先验（比如 DP 无解时的兜底候选），撑不起硬约束。量法较粗（脚本在 scratchpad，未入库），结论只作参考。

### F. 方法上的三件事（不改算法也该做）

1. **参数学出来，不手调。** 现在 DP 那几个权重是在单页、单书上调的。可以拿切线金标 + A 给出的结构金标，按页分折，用结构化学习（structured perceptron / SSVM）一次性拟合整组权重。这样「这里调一点、那里坏一点」就变成「在全集上最优」，留出集上量。
2. **一把全书的回归尺子。** 用 A 的逐列本对照做每次改动的必过闸：十册所有列的「结构不符数」按类型列出，改动前后对比，任一类上升就不合。这把尺子挂在图像和外部文本上，不随重切漂移。
3. **合并重复逻辑。** 夹注只留 Step3 一套；Step4 的 v1 判据删掉，不再「先判一遍再覆盖」。
