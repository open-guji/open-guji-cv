一现状：R2s 到底有多大、伤在哪

R2s 的定义：格线处行墨占比 > 0.02，且 ±12px 内没有 ≤ 0.02 的墨谷。投影法在这里没有任何信号可用，之前记成"图像极限、标 flag 不算错"。

3.4 整列联合精修（forced alignment 风格）

以现役切点为初值，全列 20 条内部格线在 ±16px 内联合 DP，目标 Σ cos(格, 期望字模板)。结果见文末补记：可识别性小幅上下，R2s 反而增加。

四文献怎么说

我们的问题在文献里叫 transcript mapping / forced alignment，不是通用字检测：文本已知时，任务只剩"在候选切点上找恰好 n 段的最优路径"。

路线代表机制对粘连的解法数据 / 算力
1. 网格锚候选 + 单字分类器 + 21 格先验的 DPYin/Wang/Liu PR 2013（CASIA 字级对齐 99.04%）；KESAR AAAI 2024 的 OSR候选 = 每条格线 ±δ 所有位置；打分 = 分类器置信 + 格线偏差/字高一致先验；DP 恰好 21 段粘连处照样有候选，靠字形打分1 万核对字位训分类器；CPU 毫秒级
2. 文本条件的 1D 切点热图Zheng 2016；Peng TMM 2022；CRAFT 亲和度列图 → 逐行"这是切点"概率（<1M 参数）；DP 取 20 个 + 网格先验；期望字嵌入拼进特征网络看字形上下文不看墨量1 万边界 ≈ 500 列偏小；粘连样本要过采样/补标
3. 列级 CRNN + CTC 强制对齐Peer 2025（弱模型对齐更准 88.5 vs 86.1）；DTLR 2024只需列级文本即可训；Viterbi 给每字帧区间与墨量无关需较多列或合成预训练；只给粗位置

Yin 2013 的关键数字：过切分 + DTW 后仍有 4.46% 字欠切分（真粘连），DTW 补不了——和我们的 3.1% 是同一失败模式；他们的答案也是靠字形打分而非墨量。双行小注：MTHv2 按字尺寸把小字单独分组；Lee 2024 用相邻字关系区分正文/夹注，阅读顺序 98.6%。我们的整理本里夹注文本已知，子列字数直接得到，夹注的格数先验比正文还硬。

五判断与路线

  1. R2s 是真实存在但危害有限的指标。切点挪动救不回人审（§三.3），说明当前 3 到 9% 的 R2s 大多是"切在墨上但字仍完整可认"（cell-truncation 金标里 8/23 的 overlap 就是它）。它该被优化，但优先级低于识别层。
  2. 投影法在粘连处确实到头了，识别引导能再拿 +1.3 到 +2.3 点。要更多，得换路线 1（联合 DP + 学出来的打分），这是文献与实验一致的方向。
  3. 夹注不能说"趋于完美"：vol02 夹注格人审率是普通字的 3.2 倍，且 vol01 无样本无法回归。要在 vol02 上建夹注专项批次。

修复：空白格弹性 + 列尾按墨算高 + 上界 1.5（2026-09-05）
