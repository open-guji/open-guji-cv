字形套长期方案

同一套书字形相似、异体用法一致；同时代、同字体相似。把这些知识做进系统，但不为每套书训一个网络，也不总重训。附今天四个不改算法的小实验。

一句话为什么在索引层小实验五层架构何时重训近期动作风险

〇一句话

一个共享的度量网络，加多个可插拔的原型库（套）。套放在索引层，不放在网络层：加一套、换一套、给套加权，都不碰网络权重；重训只在"新风格在冻结基准上掉到阈值以下"时做，而且是多风格一起训。

一为什么"套"应该在索引层，不在网络层

"无关字形污染训练集"这个担心，对两种用法的影响完全不同：

分类头（训一个 4,636 类 softmax）原型检索（embedding 对模板最近邻）
训练集里多了别的风格决策边界和类先验被改，会污染只让度量更风格不变，是好事
换一本新书类表不同要重训换原型库即可，不重训
限定"只在这本书的字里找"做不到天然：候选 = 该套的原型
当前书权重极高做不到该套的名次表权重最大

我们现在已经是检索为主：embedding 单源比分类头高（94.5 vs 93.3），三源融合里它权重 3。架构上要做的只是把"模板库"从"4 套字体的均值"推广成"若干套、各有元数据和权重"。

文献里这条路已被验证：CoLa 用每类 10 张模板做原型分类（历史文献 57% vs CCR-CLIP 22%）；CCR-CLIP 把冻结的原型矩阵当分类头，新字免微调；EASA 给每个未见类 1 张真实样本，24% → 92%。它们都是"网络固定、原型可换"。

度量网络的训练集反而应该尽量杂。越多风格，学到的越是"这两张图是不是同一个字"，而不是"这张图像不像四库总目"。污染的说法只对分类头成立。

E3 线性适配器（不重训）

模板侧"字体 → 刻本空间"最小二乘映射：94.1，比不适配的 96.8 差；两者相加持平。刻本与字体在现役网络里已经对齐，没有"风格鸿沟"可以用线性层填，这是训练时把真刻例和字体同类混训的结果。

E4 同一套书的另一册：vol02 dev_set 12 页重跑

三长期架构：五层

  • 层 1
    度量网络（一个，版本化）

    现役小 ResNet，256 维；指纹进产物，换网络相关产物自动过期。训练集 = 所有套的真刻例 + 字体渲染 + 退化增广，风格越杂越好；不做每套一个网络。换网络时所有套自动重新 embed（15k 样本几秒，10 万字字体渲染约 1 分钟，已有磁盘缓存）。

  • 层 2
    套（glyph set）

    定义：{set_id, 元数据, 样本引用, 原型索引}。元数据字段 glyph.db 的 sources 表已经有（edition_tag / script_style / era / kind / collection / title / volume），目前全是空。现有的套：Jigmo 四字体（4 个子套，等权最好）；vol01（15,332 例、1,921 字）；vol02 将是第二个 source，同 edition_tag。一个字在一个套里 = 该套所有已确认实例的均值向量。

  • 层 3
    套选择与加权

    现有 RRF 三源就是雏形：每套出一份名次表，按权重融合。权重初值（规则，不学）：当前书 2 ／ 同版本其它册 2 ／ 同时代同字体 1 ／ Jigmo 0.5（E1 说明当前书权重不要超过字体太多）。形关度 = 两套在共有字上的原型平均余弦（E2 的算法），等有第二种风格再校准。候选召回沿用两级字表：本书字表 → 整理本字表 → Unicode 全集；Jigmo 套负责全覆盖召回，本书套负责精排。

  • 层 4
    异体偏好表（每套一份）

    从放行记录自动导出 config/variants/<edition_tag>.json：字形 → 文意 → 次数。三个用处：定字时 reading 的默认推断；候选排序先验（本书常用 卽 就把 卽 排在 即 前）；新书按时代/版本继承最近的表当初值。通用的"是否异体"知识与"这本书用哪个"分两层。

  • 层 5
    字符集策略

    默认候选 = Unicode 全部汉字（Jigmo 能渲染），按套分层缩小。没有 Unicode 编码的刻工写法走 IDS 文本锚（调研报告 §五.B），这是唯一对口机制。

四什么时候重训，怎么判断数据够不够

  • 触发条件（量化）：新套进来先不训，只做 embed + 原型；在它的 dev 页上量 0-shot unseen top-10 与 1-shot top-1。低于 97 / 95 才把它的真刻例加进训练集重训一轮（1 小时）。同版本另一册预期不触发。
  • 过拟合的判断：现役网络对 1,022 个训练里没有真刻例的字做到 95%，说明它学的是形状不是背样本；风险在"只见过一种风格"。下一本不同风格的书（抄本、影宋本）才是真考题，vol02 不是。
  • 数据再多能否看出效果：已做。真刻例取 25 / 50 / 100% 各训 40 epoch：
    真刻例用量分类头 unseen top-1emb 检索 top-1三源 rrf
    25%88.392.393.2
    50%86.192.392.5
    100%84.092.693.2

    分类头随真刻例增多而退化 4.3 点（真刻例只覆盖 658 类、字体渲染覆盖 4,636 类，占比失衡让网络偏向背熟已见类）；embedding 检索与三源融合完全不受影响。结论：现有做法安全；"多跑几册"对当前算法既无害也无益，真刻例的正确用法是当原型而不是当训练样本——这正是本文第一节的论点，现在有了本地实证。

六风险与口径

  • 同书迁移好（vol02）不代表跨风格好，别外推到抄本。
  • 异体偏好表只有 6 组，作先验不作规则；己已巳 仍按规矩强制人审。
  • 评测口径：unseen 1,327 条里约 30 条的金标不在整理本字表内，融合评测（字表 = 整理本）的 emb 单源 94.5 与本实验（字表 + 基准字）的 96.8 差在这里；比较时对齐字表。
