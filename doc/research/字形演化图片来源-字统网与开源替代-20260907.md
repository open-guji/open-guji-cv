# 字形演化圖片來源：字統網 zi.tools 的原數據與開源替代（2026-09-07）

> 迁入说明（2026-10-15）：原在 overview `项目进展/古籍目录/资源搜索匹配/`，由资源块交 CV 块接收（GUJI-361）。正文未改。下文引用的抓取脚本 `fetch_zitools_glyphs.py` 仍在 overview `scripts/`，随 overview 拆空另行处置。

## 一、字統網 zi.tools 的數據怎麼來

zi.tools 是 Vue 單頁應用，頁面本身沒內容，全走 JSON API，無鑒權、無 robots 限制、curl 直連可用。

| 頁面區塊 | 請求 | 說明 |
|---|---|---|
| 首屏 Evolution 字形演化 | `GET https://zi.tools/api/zi/<字>` | 返回 ~170–290 KB JSON；圖在 `yi.tubrief[]`，是縮圖（高約 50 px）的 **內嵌 base64 PNG** |
| 「更多字形 more」 | `POST https://zi.tools/api/tu/`，body `{"zi":"蚤"}` | `tu[].styles[].rows[]`，同結構、**原尺寸** PNG（70–650 px），仍是內嵌 base64，沒有獨立圖片 URL |
| 說文小篆、當代標準字形 | `font` 字段 | SVG path，不是圖 |

row 結構：`[source_key, source_id, 圖上字, 查詢字, base64PNG, 書體, 朝代, 出處/書家, '', 1]`

- `𫊫`（U+2B2AB）本身在 zi.tools **沒有任何字形圖**（tubrief 為空，/api/tu/ 返回 `tu:[]`）。網頁顯示的圖是母字「蚤」的。
- 「蚤」共 31 張：甲骨 3（賓組）、秦簡 4（睡虎地、關沮）、漢簡 6（張家山）、清隸 1（陳鴻壽）、宋明楷行草 6、宋廣韻 1、宋增韻 2、明洪武正韻 2、**清康熙字典 1（70×70，同文書局本掃描切圖）**、當代標準 3、傳抄古文 2（集篆古文韻海）。
- 「康」123 張，含金文 36、傳抄古文、石鼓、開成石經、歷代書家。書法類圖明顯來自書法字典類站點的匹配整理。

zi.tools 首頁只有 Telegram/QQ 聯繫方式，**沒有數據許可聲明，沒有開源倉庫**。整站抓取（Unihan 全部 10.3 萬字，每字 1–3 s）技術上可行、法律上灰色，只宜個人研究。

抓取腳本：[scripts/fetch_zitools_glyphs.py](../../../scripts/fetch_zitools_glyphs.py)
```
python scripts/fetch_zitools_glyphs.py 蚤 康 --dynasty 清 --out D:/tmp/zitools_glyphs
python scripts/fetch_zitools_glyphs.py -f chars.txt --out D:/tmp/zitools_glyphs
```
輸出 `<字>/<朝代>_<書體>_<出處>_<key>_<id>.png` + `manifest.tsv`。

## 二、要「所有 Unicode 字在各朝代的字形原圖」，開源/公開替代

### 清・康熙字典（最完整的一層）

Unihan `kIRGKangXi` 給出每字在康熙字典（同文書局本頁碼）的位置：

| | 數量 |
|---|---|
| Unihan 統一漢字總數 | 102,998 |
| 康熙字典實有字頭（位置末位 0） | 40,423 |
| 只有虛擬位置（字典無此字，末位 1） | 29,805 |
| 其餘 | 無 kIRGKangXi |

補充索引：cjkvi `kx2ucs.txt`（48,823 行，含 Unihan 缺的約 6,000 字頭，格式 `KX1078.020\t蚤`，1568 頁以後未完全校對）
https://github.com/cjkvi/cjkvi-dict/blob/master/kx2ucs.txt

可用掃描（全部 Public Domain）：

| 版本 | 位置 | 備注 |
|---|---|---|
| 康熙字典（永新書局影印同文書局本等）12 冊 DjVu | Commons `Category:康熙字典`（CADAL09009061–072） | 2737×4104，與 kIRGKangXi 頁碼體系一致 |
| 康熙字典十二集（國圖清刻本）PDF | Commons `Category:康熙字典十二集`（NLC892-…） | 4920×7770，最高清 |
| 康煕字典 42 卷（日本國會圖書館） | Commons `Category:康煕字典`（NDL2562576–） | 和刻本 |
| 御定康熙字典（四庫薈要抄本） | Commons `Category:御定康熙字典` / IA 06079628.cn | **手抄本**，字形非刻本，慎用 |

→ 路線：kIRGKangXi 頁碼 → 對應掃描頁 → 版面切字（康熙字典版式規整，字頭黑底/大字可用連通域定位）。這是能覆蓋 4 萬字、且無版權問題的唯一開源路線。

現成的單字圖（非開源但可看）：
- **康熙字典網上版** kangxizidian.com（馬來西亞私人站，2005–）：每個字頭有 SVG 矢量字形
  `https://www.kangxizidian.com/kxzt/5000s/5166-01-27273-86A4.svg`
  命名 = `<武英殿版圖頁>-<欄>-<字頭序號 1..47043>-<碼位>`，由 ImBatch 從掃描描邊而來；字頭頁 `/kxhan/<字>` 可取得文件名；頁面掃描 `v1/index.php?page=<康熙頁碼>`（同文書局）、`v2/index2.php?page=<圖頁>`（武英殿）、v3 渡部氏版。robots 全開放但無許可聲明，站方靠賣「康熙字典體」字體維生，整站抓 4.7 萬 SVG 不合適。
- 教育部異體字字典（含康熙、說文、玉篇等字形圖）：**非商業，需申請**（onile@mail.naer.edu.tw）。

### 先秦～漢（甲骨、金文、篆、簡、隸）

- **EVOBC**（華中科大，2024）：229,170 張 / 13,714 字類，六階段 甲骨・金文・篆・春秋・戰國・隸；CC BY-NC-SA 4.0；
  Hugging Face `HaisuGuan/EVOBC`，Data-CN.zip 4.9 GB + Data-EN.zip 5.1 GB；`Key&Value.json` 把 ID 映射到楷書字。
  https://github.com/RomanticGodVAN/character-Evolution-Dataset
- HUST-OBC、Open-Oracle（同組，甲骨為主）https://github.com/Yuliang-Liu/Open-Oracle
- 小學堂（中研院）字形演變：18 萬字形，網頁可看，**無開放下載/API**。
- 全字庫 CNS11643（政府資料開放授權）含說文小篆字型——是字體不是圖。

### 宋・明・清刻本（廣韻、增韻、洪武正韻、康熙字典）

沒有現成單字圖數據集。zi.tools 是自己拿掃描本按索引切出來的。要復現同一路線：
- 廣韻（澤存堂本）、洪武正韻、增修互注禮部韻略：掃描在 ctext 圖書館 / IA / Commons，但沒有「字 → 頁位置」索引，得先 OCR 定位再切。
- 康熙字典有 kIRGKangXi 索引，是這一類裡唯一能直接做的。

## 三、結論

1. 想要 zi.tools 那一套（含清代書家、康熙字典切圖）：用上面的腳本按字表抓 `/api/tu/`，只能私用。
2. 想要開源、覆蓋全 Unicode 的清代字形：自己切康熙字典——索引（kIRGKangXi + kx2ucs）和掃描（Commons PD）都齊，缺的是切圖腳本。
3. 先秦～漢直接用 EVOBC（非商業）。
4. 宋明刻本層目前沒有任何開放的單字圖集。
