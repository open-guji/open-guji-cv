## 要做成什么

一页看清「这本书目前收集了哪些字形」。建议三块，异体组视图降为其中一个子 tab。

### A 总账（顶部卡片 + 表）
- 每套一行：套名、类型（刻例/字体）、字种数、刻例数、stable/sparse、单例字数。
- 来路分布：human / align / match / context …（`admissions.provenance`）。人裁占比要显眼——它是 Step7 新设计的「铁证」来源。
- 真源健康：store 行数 vs db 行数（01 卡的告警在这里也亮）、最近更新时间。
- 与其它书/字体的覆盖交集：本书字种里有多少在另一本书也有、多少不在 I.Ming/Jigmo 里（后者是生僻/无码候选）。

### B 字表浏览
- 按字排列的网格：字、刻例数、来路小标、是否单例、是否在形近字表/IDS 护栏里。
- 过滤：只看单例 / 只看无人裁 / 只看 context 放行 / 只看 semantic≠char / 只看有体检旗的（03 卡产出）。
- 排序：刻例数、字频、Unicode 区段。

### C 单字页
- 该字全部刻例缩略图（按来路分组），点开看原页位置（复用 `/api/glyph-match/exemplar/{id}.png` 与已有页定位）。
- 同字在别的套（另一本书、字体）的形并排——这就是 03 卡人审的主界面，先把看的能力做出来。
- 字元信息：unicode_cp、semantic、IDS（04 卡之后才有）、可信度档（04 卡之后）。
