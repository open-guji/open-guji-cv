# 05 IDS 反查与多字体比对

- **状态**：✅ 已完成（2026-09-25），cv `496f13fa39`（IDS 反查）、`4188c75435`（多字体）；两书体检已按多字体重跑（guji-workspace `83e3c2d0`）。
- **起因**（用户 09-25）：Unicode 标准里有什么？有没有 IDS、标准字形？能不能拿我们的字形和它比？

## 先说结论：Unicode 能给什么、不能给什么

| 想要的 | Unicode 有没有 | 我们用什么 |
|---|---|---|
| 逐字 IDS | **没有**。只规定 IDS 语法与结构符（⿰⿱…）；Unihan 没有逐字 IDS 这一栏 | 社区表 yi-bai/ids（`config/ids/ids_lv1.txt`，10.2 万字） |
| 标准字形 | **没有唯一的**。码表是各来源（中/台/日/韩/越…）的代表字形，不是规范；细微差异按认同规则合并在同一码位；具体字形要靠 IVD，以日本字形为主 | 字体：I.Ming、Jigmo（全 Unicode，CC0）、源流/源雲/源樣明體 TC、康熙字典體（商业，只在本机比对） |
| 异体关系、读音、部首笔画 | 有（Unihan：`kSemanticVariant`/`kZVariant`、`kMandarin`、`kRSUnicode`…） | 还没接（见「没做」） |

## 一、IDS 反查（标「最近似码位 / 无码」前先查）

- `clustering/ids_lookup.py`：三档匹配
  - **exact**：拆法逐字相同；
  - **expanded**：两边逐层展开到底后相同（认得拆到不同深度的写法）；
  - **near**：按写出来的样子逐 token 编辑距离 ≤2（换了一个部件 / 结构符不同），同差数时常用区排前。
  - 没在「展开到笔画」的层面做近似：那一层 `⿰木⿱亠口` 会和笔画凑巧相同的 𡘗 判成零差，结构信息全丢（试过）。
- 控制台：单字页、体检卡上的「最近似码位 / 无码…」改成反查面板。边写 IDS 边出候选（字体图、区段、本书有没有）。
  **命中已编码字就提示「该改字」并锁住标注**，人勾「看过了，上面都不是」才放行；候选可一键改字。
- 后端也守：`glyph_audit` 的 nearest/unencoded 如果 IDS 反查命中已编码字、又没带 `force`，就拒收。
- 实点验证（四庫库副本）：蹖 那例写 `⿰𧾷春` 反查到 踳 → 一键改字；淮 写 `⿰冫隹` 反查到 准，标注被锁、勾选后放行。

## 二、多字体比对（「和 Unicode 的字形比」的可行版本）

每个刻例对**本字**在六套字体里各算一次弹性覆盖率，取最优那套；「更像另一个字的字体」旗也改看最优。
**只和一套不像多半是刻本异写，和每一套都不像才值得怀疑。**

| | 刻例 | 康熙字典體 | 源雲明 | 源流明 | 源樣明 | I.Ming | Jigmo |
|---|---|---|---|---|---|---|---|
| 四庫 中位 | 17,258 | **0.968** | 0.943 | 0.943 | 0.941 | 0.937 | 0.920 |
| 四庫 最像它的刻例 | | **13,363** | 1,218 | 1,054 | 625 | 792 | 206 |
| 北行 中位 | 4,854 | **0.969** | 0.949 | 0.949 | 0.948 | 0.944 | 0.929 |
| 北行 最像它的刻例 | | **3,623** | 353 | 324 | 183 | 283 | 88 |

- **两本清代刻本都最像康熙字典體**（四庫 77%、北行 75% 的刻例最像它），其次是源系明體；Jigmo（GlyphWiki 系，日式字形）最远。
  康熙字典體是商业字体，只在本机做比对参照，不进任何产物。
- 「更像另一个字的字体」旗：四庫 109 → **2**，北行 20 → **4**（单套 I.Ming 时的噪声基本清掉）。
- 体检总数：四庫 564 → **456**，北行 222 → **209**（北行期间人裁还在进库，刻例 4,761 → 4,854）。
- **与各字体都不像的字**（刻例对本字最优相似度的中位 <0.80）：四庫 0 个，北行 48 个。
  北行这 48 个多是二值扫描下的残损、墨糊（仍、白、似…），要看图判断。字表有「与各字体都不像」过滤和「与字体最不像的在前」排序。
- 控制台：单字页并排六套字体；体检页头有各字体相似度表；`GET /api/glyphlib/font/{c}.png?font=…` 现场渲染。

## 环境

本机 `.venv` 缺 `fontTools`（pyproject 声明了），已 `pip install fonttools` 补上——字体渲染要它读 cmap。

## 没做

- **Unihan 异体关系**（`kSemanticVariant`/`kZVariant`）没接。接上能让 強/强 这类在体检里算同字、不再出卡；要先下载 Unihan.zip。
- 全字庫宋体 / 楷体（台湾来源字形，最接近明清正字）字体档没下载，没参与比对。
- 体检里「最近似」的判断仍靠人；「与各字体都不像」只是排查清单。
