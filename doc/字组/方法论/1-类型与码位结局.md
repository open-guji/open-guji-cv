# 1. 类型与码位结局

[← 总览](README.md)

## 1.1 类型只有两种

字组类型只分两类（sheldon 10-24 定），对应注册表 `GroupSpec.kind`。以前文档里的 A–E 五类只是方法，不是类型。

| 类型 | `kind` | 是什么 | 按什么定字 | 拆不开时 |
|---|---|---|---|---|
| **同义** | `variant` | 同一个字的不同写法（异体），如 尙尚、參㕘叅、刊刋、徵徴 | **看刻形**，照录刻本上的写法，绝大多数按 IDS 仔细分 | 可以暂归一，或按参校本取字 |
| **不同义** | `near_form` | 字形相近的不同字（形近），如 己已巳、日曰、子于、个今 | **看文意**：不管刻得像哪个字，一律按文意定（sheldon 10-17）。文意没有区分力、字形反而分得开的（宋朱未、各名、心必），才看字形 | **绝不归一**，送人审 |

**判断标准只有一条**：把这一格换成组里另一个字，句子的意思变不变。不变就是同义，变了就是不同义。

几个容易判错的地方：

- **通假、古今字不算同义**。边表里只有 link、rt 或通假边的对子按不同义处理，例如 刺剌、釆采（sheldon 10-27 定按文意录）。形近护栏 N 类剩下的对子（十士、日曰臼白目口、西酉面而兩、七𠤎、贋𩛻）查过边表，全是不同的字（2026-11-01）。
- **字书引形、满文注音段里的字**，整理本常常照原字书录，这时文意说不上话，要单独送人审。
- **混合组**要先拆成「族」。象彖𧰼 里，彖 和 象𧰼 不同义，象 和 𧰼 同义；冠寇冦宼㓂 里，冠 和 寇族 不同义。先按文意定族，族内再按同义组办（sheldon 11-01 定，见[分篇 4.6](4-参照字与码位组.md#46-两段判与混合组)）。

## 1.2 同义组的五种码位结局

同义组最后落到哪个码位，有五种结局。从上往下优先，前一种做不到才用下一种。

| 结局 | 什么时候用 | 谁定 | 写在哪、留什么痕 | 例 |
|---|---|---|---|---|
| ① **按刻形拆开** | 两种写法都有，且每种 ≥20 个可靠人裁；字形方法按册留出 0 错 | 线程自己做，合 dev | 字组注册，留痕是方法名 | 叙敘、絕絶、教敎、變𠮓、撫橅 |
| ② **照录刻形**（不算归一） | 本书每一对只有一种刻法，码位跟着刻形走 | sheldon 点头 | `codepoints.yaml`，注释写「照录刻形」 | 旣既、淸清、靑青、祿禄、卽即、厯歷 |
| ③ **真归一** | 看图、IDS、整字 HOG 都分不出两形 | 逐对 sheldon 点头 | `codepoints.yaml` | 內内、別别、出岀、卷巻、晚晩 |
| ④ **按参校本取字** | 拆不开，但本书有高置信参校本（四库系书） | sheldon 11-01 定，按书开关 | 证据 `via=variants` | 史記 01–10 |
| ⑤ **暂归一**（可分待拆） | 拆开要大量人工标注或大量切分训练，而且没有可信的参校本 | sheldon 点头，归到**最常见的字形** | `codepoints.yaml` 或 `registry.PROVISIONAL`，证据 `decision=provisional`，登记拆分条件 | 㣲→微、徵→徴、㓂→寇、寶寳→寶 |

### 怎么判断该走哪一种

- **先试①**。能用自己的方法拆开的就拆（sheldon 10-25「能拆就拆」）。拆分的门槛和方法见[分篇 2](2-字形方法.md)。
- **②和③的区别**在于本书到底有没有两种刻法。②是只有一种刻法、码位是两个；③是刻形本身就分不清。两种都要看图：把两种码位的已放行格各抽几十格放在一起看，确认刻法是否一致。
- **④和⑤的区别**在于有没有可信的参照。四库系书有高置信参校本，就照参校本录；殿本的整理本常改字（曰→日、已→巳是常态），不能整体信，只能暂归一。
- **⑤是欠账，不是结论**。登记时必须写四样：类别「暂归一」、理由（为什么现在拆不动、缺什么数据）、归到的最常见字形、拆分条件（通常是「少见形攒够 20 例可靠人裁」或「IDS/字形判法按册留出 0 错」）。
- **不要为了拆开去要求 sheldon 大量标注**（10-25）。要大量人工才拆得开的，先暂归一。

### 暂归一兜底在管线里怎么发生

同义组先按方法数组拆。拆不开、置信度不够、或者与整理本说法不一而本该送人审的格，只要「是这个字」两路都认，就放成这组最常见的字形（`registry.PROVISIONAL`，开关 `group_flow_provisional` 缺省开，cv#718）。

「两路都认」的意思是：

- **补放时**：库首位和分差 0.03 内的候选全在「同一个字的写法」表里，整理本字（缺了就用坐标对位字）也在表里。
- **复核时**：放行字在表里，整理本没有字或者也在表里。

以下情况不兜底，照旧送审：整理本说是组外的字、库里分差内有别的字、没有整理本字、夹注半格只有坐标对位。这些是「到底是不是这个字」的问题，不是写法问题。

殿本 vol07–99 回放：同义组送审 676 格，兜底 464 格，看图字都认对；仍送审 212 格。

## 1.3 「照录整理本」和「按参校本取字」的区别

这两个开关用的是同一套判据（`seed_admit.follow_ref_decide`），都是照录整理本的字形。区别在于信任的范围。

| | 照录整理本 `seed_admit.follow_ref` | 按参校本取字 `seed_admit.follow_ref_variants` |
|---|---|---|
| 粒度 | **按字对**：白名单 `整理本形=库里另一形`，逗号分隔 | **按书**：不限字对 |
| 适用 | 只限白名单里的对子（殿本现有 9 对：㓜幼 劔劍 勅敕 盖蓋 囘回 拘抅 𡚁弊 𪔂鼎 𮘸謬） | 整理本字与库首位／已放行字是同义异体（本步异体关系 `vmap.semantic` 相同、字面不同）的所有对子 |
| 信任依据 | 这几对在本书逐格看过图：两种刻法都有，而且整理本码位就是刻形 | 本书整理本整体可信（四库系书的高置信参校本） |
| 殿本能不能开 | 能（已开） | 不能，殿本整理本常改字 |
| 与暂归一的关系 | 无关，只管白名单 | **替代**暂归一：开了它，暂归一放的格也改回整理本形 |
| 证据 | `evidence.follow_ref` | `follow_ref.via=variants`、`lane.via=variants`，以后可以按它筛出来回查、再拆 |
| 去留 | 临时补丁。某对建好字形组、按册留出 0 错后，从白名单删掉那一对 | 长期的书级策略 |
| 出处 | cv#623（2026-10-26） | cv#841（2026-11-01） |

一句话：前者是「这几对我们核过，整理本可信」，后者是「这本书的整理本整体可信」。

**延伸开关** `group_flow_abstain_ref_ok`（cv#843，书级，写要开的组 id 列表）配合按参校本取字一起用。它做两件事：

1. 复核时解法全部弃权、没有任何方法给出别的字、已放行字等于整理本字，就不降审。
2. 补放时族内刻形拆不开（如 會㑹），整理本是族内的一形，就取整理本形。

史記开了 [jys, zh]，01–10 册放行 178 格，抽看 48 格无错。两个开关同一条红线：**只限意思相同的异体**，不同义的形近字绝不适用。

## 1.4 登记规矩

- 「真归一」「暂归一」「照录刻形」「按参校本取字」分开写，别混写成「归一」。组卡、候选表、`codepoints.yaml` 注释都用这几个词。
- 码位条目的总登记表在 [`doc/字组/README.md` 第二节](../README.md)（一行一对，写类别、理由、拆分条件、负责）。
- **码位决定是最新决定**，可以覆盖并删除之前与它不一致的人审决定。
- 码位条目在中心库 `config/codepoints.yaml`，写中心库要 sheldon 在线程里说「推」。
- 码位定了还要**建码位组**（`cp_*`），否则 seed_admit 的异体护栏仍会把这些格送审，见[分篇 4.1](4-参照字与码位组.md#41-码位组-cp_)。
- **书级固定用字极少用**，只限已定的几组；其余一律走 IDS 或文意。
