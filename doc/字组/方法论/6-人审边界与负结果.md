# 6. 人审边界与负结果

[← 总览](README.md)

## 6.1 目标分两档

- **同义异体要尽量清零**（sheldon 10-31）。同义组拆不开有出路：暂归一，或按参校本取字。
- **文意实在难分的不同义形近字留给人审**，不要过度优化（sheldon 11-01）。
- 顺序：**先做异体，最后做文意不同的形近字**（sheldon 10-31）。异体容易，形近难。

## 6.2 应当留给人审的格

| 类别 | 例 | 为什么不再加方法 |
|---|---|---|
| 文意不确定：L3 和二审小组都没给 high，或两家读得不一样 | kgc 剩 7 格、xz 剩 3 格，小组读不一致约 60 格 | 继续加模型、抬 effort 也不收敛 |
| 整理本错、但图像加文意对 | 三千、二千石、春闈、閭里 | 允不允许越过整理本要 sheldon 定 |
| 字形和文意都分不开 | 入人八 | 暂时不动 |
| 少见形不到 20 例，又不能兜底 | 往徃、釐𨤲、兹茲、刼劫 等 | 攒够例子再建组 |
| 整理本字在组外 | 自、旨、巴、元、白、昌 等约 20 格 | 属于「整理本字复核」，不是字组问题 |
| 对位本身错位 | shan 隅爾惻、lv 㠯昌召、zhuan 詩參 | 不是写法问题 |
| 页首页尾上下文被截断 | 约 15 格 | 要做跨页连读才能解决 |
| 弱证据的单格异体对 | 蘧遽、壕濠、杪秒、鉞鋮 | 边表证据不够强，不走通则 |

## 6.3 试过无效的路（别再试）

| 路 | 结论 |
|---|---|
| 文意路用于 宋朱未、各名、心必 | 已放行格的不一致 21 格全是文意错，改用整字 HOG |
| L3 effort 升到 high 去解决文意与字形冲突的格（入人八） | 不收敛，没有改善 |
| 纯 n 元组逻辑回归做文意 | 零错时只覆盖 30–40% |
| 微调 SikuRoBERTa 后 4 层 | 零错覆盖 67%，不如冻结编码器加小头 |
| 把窗口里的组内字也盖掉再填空 | 更差，丢了「一曰…二曰」这样的排比 |
| 按格存 L2 表 | 成本随册数线性涨，换图源要整表改键，换书用不上；已改成模型直接推断 |
| 用「库首位＝上下文首位」放行（ctx p≥0.5） | 人裁金标只准 97% |
| jys 的非 high 答案放宽 | 样本太小，而且违反「零错才放行」 |
| 入人八 用字形单独补放 | 曾把半个「爻」放成「人」，只许降审 |
| 文意组的字形第二路去处理「已放行格上的字形异议」 | 异议几乎全是字形错判 |
| by_form（按字分类，自动缝）用于 呂吕、徵徴 | 差别不在缝的两侧，0.04 起就有错；改用整字 HOG |
| 窗口法 HOG 用于 彝 | 过拟合（留一偏乐观），改 U-Net 三段 |
| 机器自己扫局部框参数 | 偏乐观，框要 sheldon 在滑块页里调 |
| 补少数形采样（往徃、刪删、扺抵） | 稀有形本来就少，434 格标完仍不够每形 20 例；走字频放主形 |
| 蒙𫎇、隸𨽾、讖識 补少数形 | 殿本里本来就极少（蒙≈12、隸≈5、讖≈8），要靠别的书 |
| 日曰 在殿本用字形细节（中横碰右竖） | 不成立；日 的人裁只有 18 格，不训练 |
| 书级固定用字扩到新组 | sheldon：非常少见，只限已定的几组 |
| 门辶族扩模板库 | 净亏，没上线 |
| match_solo_cnn 通道 | 从未触发的死通道，修好后多放的 19 格多半是错的，已删（cv#376） |
| 只靠出现频率选要建的组（宋朱、四因、與興） | 频率高不等于送审多，这几对送审只有 0–2 格 |
| `pending-stats` 的 V 类口径直接拿来当「异体对」 | 口径过宽，约 290 对其实不是异体；要按边表 T1/T2 收紧 |
