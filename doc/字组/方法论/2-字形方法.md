# 2. 字形方法

[← 总览](README.md)

字形方法是同义组拆分的主力。不同义组在文意没有区分力时也靠它，或者拿它当文意的第二路。实现在 `groups/methods.py`（`hog` `ids` `composite` `custom` `freq` 几类）。

## 2.1 先找差别在哪

动手前，先按 IDS 写出组里每个字的结构，再看刻本上实际能看到的差别在哪里。差别的位置决定方法：

| 差别在哪 | 用什么 | 例 |
|---|---|---|
| 一个可以切出来的部件 | IDS 切部件＋部件模板 | 叙敘（又／攴）、絕絶（刀／⺈）、彝（上中下三段）、撫橅（扌／木） |
| 固定的一角 | 取框 HOG | 教敎（左 0–55%、上 0–46%）、辶族（取右上，避开走之底）、厯歴（下半框） |
| 整字的笔画细节，切不出部件 | 整字 HOG＋岭回归 | 啓啟、呂吕、徵徴、旨㫖、子于、山由出、宋朱未、各名、心必 |
| 一个几何量 | 自定义量 | 一二（数横）、土士和未末（横长比）、日曰（宽高比）、于千子干（竖钩、斜撇） |
| 只在一小笔，样本又少 | 字形不上，靠文意或送审 | 大太、未末、王玉、目自、千干、十卜、戊戌戍、木本 |

注意：结构判断不能只看 `ids_lv1` 的写法，判别区要由数据定。例如 徵徴 不是普通的左右结构，右部 攵 比 叙敘、教敎 的细，所以没有并入攵池。

## 2.2 IDS 切部件

- `groups/ids_plan.py` 由成员的 IDS 自动导出切向和判别叶子。更细的 IDS 放在 `ids_fine.tsv`，例如 絕 作 ⿰糸⿱刀巴、絶 作 ⿰糸⿱⺈巴。⺕ 与 彐 算同一部件，彑 与 彐 要区分。
- **只用通用的 Unicode IDC，不自造格式。**
- 切法有三种：自动缝、折线、U-Net。切线由 sheldon 在切线页里点。

五条关键经验（sheldon 认可）：

1. 模板和测试格必须用**同一种切法**，否则最近邻会认错。
2. 细 IDS 要切到**判别叶子**为止。
3. 切分器不强求共享，每组按册留出选最好的那个。
4. 直线不行就用**折线**。
5. 错例 sheldon 核过：标注的切线都对，错出在识别上，不在切线上。

## 2.3 U-Net 切分

- 适用：三段结构（彝 yi_560 的上／中／下），或左右难切的字（叙敘三组共训左右、絕絶）。
- 纯 numpy 推理（`ids_unet.NpNet`），权重约 1MB，放在 `config/groups/<组>/unet.npz`。缺权重时弃权，留痕 `abstain:no_model`。CPU 上训练 15–30 分钟。
- **切得准不等于判得准**。jue、lih、qik 几组，整字 HOG 反而不比部件差。所以每组都要拿整字 HOG 做对照。
- 权重一律传 R2，不进 git。

## 2.4 整字 HOG 与取框 HOG

- **整字 HOG＋岭回归**：二类，或一对多时每类一列，取第一名和第二名之差作 margin。
- **门槛**：margin 按册留出定到 **0 错**。殿本上的例子：men 0.62、chuo 0.65、xjz 0.7、fu 1.2；厯歴 下半框 size48 门槛 0.25。
- **取框**的框要 sheldon 在滑块页里调。机器自己扫框参数会偏乐观（见[分篇 6](6-人审边界与负结果.md)）。
- **部首族**（门族 27 字、辶族 38 字）：族里字多、模板收不全，库外的字（如 閼）会被高把握判成最像的那个。所以要配 `lift_ref_agree`：补放的字必须与整理本字一致（缺位时用坐标对位字），否则送审。
- **训练字块**必须用线上同一种 `char_patch`。已放行格可以进模板，但每册每字最多 20 格。

## 2.5 字频

- 规则：主形人裁 ≥10，并且来自至少两册（`MIN_VOLS=2`），才放主形；其余成员给 0。
- 两形混用的异体对**不能用字频**，要走 IDS 或整字 HOG。
- 字频表是**书级数据**，换书要重建；建好之前字频一律弃权。
- 同义组的复核**不能用字频**：字频永远说主形，拿它复核会把真的次形也降掉。所以复核只跑字形方法（`registry.SHAPE_REVIEW`，cv#504）。

## 2.6 几何量与笔画

几何量**只当第二路**：文意弃权时才补位，与文意冲突就送审。

| 组 | 量 | 门槛 |
|---|---|---|
| 一二 yr | 数横 `yr_bars` | 见 [yr.md](../yr.md) |
| 土士、未末 | 横长比 | 见组卡 |
| 日曰 ry | 宽高比 | ≤0.68 判日、≥0.88 判曰，中间段完全不看字形 |
| 于千子干 zy | 竖钩：字下 25% 竖笔左侧墨量 | {于子} 0.13–0.99，{千干} 0，40/40 |
| 于／子 | 两横之间是直短竖还是右上斜撇（dx/dy） | 于 −0.17…0.03、子 −0.51…−1.24：18 对 0 错 2 弃权 |
| 千／干 | 首笔左半斜率 kL ≤ −0.10 判千；右端凸起与笔粗之比 ≥0.6 判干 | 14 对 0 错 6 弃权 |

于千子干 的笔画判法是 sheldon 11-01 提的思路，阈值目前只在同一批 40 例上定，还没按册留出，下一步要扩大样本。字块把首笔裁掉的格要弃权。

## 2.7 建组门槛与标签来源

- **建组门槛**（sheldon 10-20）：按刻形判的同义组，**每种字形至少 20 个可靠人裁刻例**。不到就不建，少见形送人审。高频但几乎没有送审的对子也不建。
- **放行字不等于刻形**。放行字只是跟着整理本或台账走的。拿它当标签前，先按册留出，把与标签不一致的格逐格看图。
- 模板库 `config/groups/<组>/ids_bank.json` 的 `source.labels` 要写清标签从哪来：人裁、放行字当标签、看图补的格，以及去掉了哪些格。
- **暂归一兜底放的格不能当模板**（`flow.is_provisional`，建模板的脚本已经剔除）。
- 大批预填后改错的标注，sheldon 可能漏看。机器很有把握、又与他不一致的格要拉出来请他复看。机器结论不当绝对真值，也不直接按机器改。

## 2.8 评测

- 一律**按册留出**。留一法偏乐观。
- 门槛定到留出 0 错；样本少的类直接弃权。
- 离线回放用现有产物包，只看本组的格；改了字、新放行的格逐格看图。回放时 HOG 用原图裁块，与线上 `char_patch` 的 margin 略有出入。
