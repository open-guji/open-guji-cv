# 形近字与异体字组处理方法论：总览

> 2026-11-01 起，A24。这份方法论总结了《四庫全書總目》殿本 99 册上做了两轮多的字组工作，目的是换一本书也能直接照着做。
> 本目录只讲**怎么选方法、为什么这么选**。每个组具体的数字、错例和待办写在组卡 `doc/字组/<组>.md` 里；规范（存放位置、数据格式、状态报告、码位登记表）见 [`doc/字组/README.md`](../README.md)。
> 原先 ai-team 仓的《形近字组方法与判法规则》（M7 总结，2026-10-22）已经并入本目录，那边只留一个指针。

## 一句话

每个字组都问三个问题。第一，组里的字是**同义还是不同义**。第二，有没有**可信的参照字**，也就是整理本或参校本。第三，差别具体在**字形的哪一处**，**文意能不能把它们分开**。按回答给这个组排一个有序的方法数组。任何一路没有把握就弃权，送人审。

## 三条总原则（sheldon 定，换书不变）

1. **零错优先**。自动放行的门槛按「按册留出 0 错」来定。样本少的类别直接弃权，宁可多送人审。
2. **异体看刻形，形近看文意**。同义组照录刻本上的写法；不同义组按文意定字。只有文意没有区分力时，不同义组才看字形，例如 宋朱未、各名、心必。
3. **同义字拆不开有出路，不同义字没有**。同义异体拆不开时，可以暂归一，也可以按参校本取字。意思不同的形近字（例如 个/今）绝不归一，判不了就送人审。

## 选路三问

1. **是同一个字的不同写法吗？** 是的话，先看刻形能不能分开（IDS、HOG、字频）。分不开就选一种码位结局，见[分篇 1](1-类型与码位结局.md)。
2. **文意能分吗？** 先在已放行的格上验证文意有没有区分力。有，就用文意三级；没有，回到字形。
3. **有单一的几何量吗？** 有，就用自定义量当第二路。三问都不行，弃权。

每种放行都要配护栏（[分篇 5](5-护栏与复核.md)）。目标分两档：同义异体尽量清零，文意实在难分的形近字留给人审（[分篇 6](6-人审边界与负结果.md)）。换书的操作步骤见[分篇 7](7-换书与轮次流程.md)。
