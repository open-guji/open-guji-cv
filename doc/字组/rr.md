# rr 入人八（不同义）

## 字形差别
入 人 八 都是两笔，差在交接位置与出头。

## 怎么判
方法数组：`[ctx_rule → llm] ＋ custom:rr_img ＋ composite(crop(0.0, 1.0, 0.0, 0.5) → hog)`（注册在 `groups/registry.py` 的 `GROUPS`）。
- 复核与门：复核降审；补放须 ctx/ids
- 配置：`config/groups/rr/` 下 ids_bank.json prompt.md rules.yaml
- 模板库：人158／入152／八151（dataset char-groups labels/unified.jsonl 人裁（kind=shape）＋殿本 vol04–10 已放行格（放行字当标签，每册每字 ≤20））

文意＋随机森林字形分类器（`rr_img`）＋上半整字 HOG。补放须文意或整字 HOG 给字且各路不冲突；随机森林只许降审（vol04 A/B 曾把过切的半个「爻」单独放成「人」）。

2026-10-26（A24「压低入人八送审」）加三条：
- `ctx_over=("rr_img", "ids")`：文意够硬（L1 规则，或 L2 表 strong＝三模型同字、至少两遍 high）时，两路字形给了别的字只当弱票，照文意补放／复核。殿本 入 多刻成两笔分开、像 八，整字 HOG 常把 入 判成 八；人裁 vol04:62:7:18（人，两路字形都说 入）就是这种。
- `review_fix_strong`：复核时文意 strong 且各路（弱票除外）不反对 → 照文意改字（整理本错，如「宗人府」整理本作八、「咸寧人」放成入）。
- `lift_img_ref_veto`：文意没给字、只有字形给了整理本（现役对位缺格时用坐标对位字）以外的组员 → 不补放（`group_flow_ref_dissent`）。现有产物里拦下的错放：vol28:20:5:4「國家八旗」放成 入、vol46:39:2:19「人物鏡」放成 入、vol44:232:8:13「太極圖說」放成 人；也拦下 vol12:147:2:17 查表落空时 HOG 单独把整理本的 入 补成 八。
- L1 键 `rr-ext-l1-人` 加 鄕、`rr-ext-l1-入` 加 𥨥（中心库码位 鄉→鄕、竄→𥨥 之后整理本用后一形，原键落空）。
