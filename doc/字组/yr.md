# yr 一二（不同义）

## 字形差别
一 一横；二 两横，上短下长、上下对齐。殿本刻得清楚，看图一眼可辨；整字 HOG 却常把握不够（「二」上横短细，「一」又本来就扁）。
容易错的不是字本身，而是**字块**：
- 列尾格常把栏框线收进来，「一」＋边框线像「二」（vol08:7:6:21、vol16:176:9:21）；
- 切分把字切碎：「有」「六」「主」的上半是一横加一点或一竖，被放成「一」（vol15:97:1:3、vol17:112:5:6）；「二」切成两格各放成「一」（vol12:50:3:3–4）；
- 格切进邻字：「無一不謬」的格带上了「不」的上横，判成「二」（vol19:116:9:8）。

## 怎么判
方法数组：`[ctx_rule → llm] ＋ hog ＋ custom:yr_bars`（注册在 `groups/registry.py` 的 `GROUPS`，`_YR_FLOW`），`agree`：给字的须一致。
- 文意：L1 规则只剩「◎閣藏」一条（10-24 下线 21 条，见下）；没有 L2 表。
- 整字 HOG（`config/groups/yr/ids_bank.json`，门槛 0.87）：**不许单独补放**（`lift_needs=("ctx", "yr_bars")`），列尾格会把边框线当第二横。
- 数横 `yr_bars`（`groups/bars.py::count_bars`，2026-10-25）：连通域按竖向重叠并成横带，够长够扁的算一横。一横给一，两横（上横中点落在下横 20%–85%、下横不短于上横 0.9 倍、墨不少于上横 0.8 倍）给二；横外墨多（印章、邻字残笔）、横带虚、一横中段竖起小笔（被切开的「有」「六」「主」）、上重下轻或下横贴底且薄（边框线）、三横以上，一律弃权。没有学来的参数，门槛按殿本已放行格定。
- 补放：文意或数横给了字、其余不反对才放；整理本是组里另一个字就不放（`lift_ref_veto`，防字块切错时两路字形一起错）。
- 复核：任何一路给了另一个字就降审（只降不改）。
