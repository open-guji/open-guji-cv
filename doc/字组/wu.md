# wu 嗚鳴（不同义，看图分不开）

2026-11-13 新建（全唐文 QTW 经 Ops 转；A31 实现）。

## 字形差别
全唐文本书 嗚 的刻形与字形库里 鳴 的刻例看图分不出。QTW m2 层4 有 130 格参校本作嗚、库首位鳴（123 格是 嗚呼／嗚乎／嗚咽／喑嗚），只能靠文意。

## 怎么判
方法数组：`[ctx]`（L1 规则 → 弃权查 L2 表 → L3 裁定库；管线不在线问，未决的问留痕 `ask` 进 `feedback/llm_queue`）。配置：`config/groups/wu/` 下 `rules.yaml`、`prompt.md`。
- 嗚：嗚呼／嗚乎／嗚咽／嗚嗚／嗚哉、喑嗚。「鳴呼」一律按嗚（QTW 口径）。
- 鳴：雞犬蟬鶴鳳馬鐘鼓琴珂＋鳴、鳴＋鳥鑾琴鐘珂條謙…、自／共／相＋鳴＋标点。两可词（悲鳴、哀鳴、鳴＋他字）不收，弃权交 L2／L3。
- 流程：补放、复核都跑；`review_fix_strong` 文意 strong 才改已放行的字，`strong_over_ref` 才越过整理本（同 日曰、刺剌）。

## 需点名才开（缺省关）
`wu` 放在 `registry.OPT_IN_GROUPS`：不进 `GROUPS`、不进缺省 `group_flow`，没点名的册产物逐字节不变。
全唐文册配置 `group_flow` 写成「缺省名单＋`wu`」（书级开，同 zw）。
