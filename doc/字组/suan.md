# suan 算𮅕（同义，按刻形拆判）

## 字形差别
算 ⿱𥫗⿱目廾：下部 廾（两竖）；𮅕 ⿱𥫗狊：下部 大（长撇长捺）。殿本 𮅕 集中在 vol49「算學」各条，vol44、vol48、vol50 也有。
字形库没有 𮅕，库多把它排成 莫（也有 㝠箕集篇負簋），整理本作 𮅕 → 首跑 V 类送审。vol49 多页现役对位缺格，只有坐标对位字。

## 怎么判
方法数组：整字 HOG＋岭回归（`ids_online.SPECS["suan"]`，48×48，λ=1，去碎墨），SHAPE 组，补放与复核改码位。
- 门槛 0.5。
- 陪衬：莫㝠箕集𡚁篇奧負簋窠纂𢑴簣冀其雙（莫㝠箕集篇 进模板库，判成它们＝弃权）。
- `ref_enter`：库首位是陪衬（莫）、整理本（缺对位时用坐标对位字）在组里 → 也进组补放；补放须与整理本同字（`lift_ref_agree`）。
- 模板库 `config/groups/suan/ids_bank.json`：990 格（算 50、𮅕 40，陪衬 900）。
