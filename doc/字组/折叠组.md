## 一、是什么

有些形近字在本书里刻法几乎不分，字形库给两个字的分都在 0.999 上下，机器字等于随手挑。现在只有两组：日曰（`ry`）、己已巳（`jys`）。sheldon 11-05 定的口径：

1. **归组**：匹配到组里任一个字，就算认对了这个组。
2. **定字**：再按文意定是组里哪个字，完全不能参考整理本（整理本在这一类里错得多，殿本己已巳约四分之一与文意不同）。
3. **字形可以帮忙**：日曰长宽差别大的直接按字形判，居中的照己已巳按文意。

## 二、流程（每个待审格）

```
① 进不进   字组在 fold_groups 里、没放行、不是人裁；排除格不碰；
           遮挡格要 fold_occluded，夹注 a/b 半格要 fold_jiazhu
② 归组     现成的字组证据（evidence.group）；
           没有时：fold_coord_ref 用坐标对位补整理本字、按「库首位与整理本字同组」归组
③ 护栏     fold_lib_top_in_group：库首位也得在组里
④ 定字（依次试，先中先用）
   a. 字形宽高  fold_aspect（正文）／fold_aspect_jiazhu（半格），按 fold_aspect_pairs 判窄字／宽字；
               fold_aspect_ctx_veto：上下文首选是另一个字且概率够高 → 作废，往下走
   b. 文意裁定  裁定库里本组 L3 提示词的裁定（high／mid），fold_ruling_first 或 fold_ref_char:false 或半格时查
   b2. 文意答案  fold_ctx_vias：字组流程里本组文意路已 agree 给了组内字、来源层在名单里（可要 strong）
   c. 整理本字  只在 fold_ref_char:true（旧口径）且不是半格时
⑤ 都没有    记 evidence.fold_pending（带 ctx_veto 时一并写），格照旧待审 → 出单归 H01
```

放行的格：通道 `fold`，证据 `evidence.fold = {group, ref, via: aspect|ruling|ref, aspect?, coord?}`，原字和原疑问在 `lifted_from`。

## 三、参数（全是书级，缺省全关，关着不进 params dump）

| 参数 | 取值 | 作用 | 什么时候开 |
|---|---|---|---|
| `fold_groups` | 组 id 列表，如 `[ry, jys]` | 总开关，哪些组折叠 | 本书这几组确实刻法不分 |
| `fold_ref_char` | `true`（缺省，旧口径）／`false` | `false`＝不取整理本字，只放字形／文意给的字 | **新书一律写 `false`**（sheldon 11-05） |
| `fold_aspect` | `[lo, hi]` | 正文格宽高比 ≤lo 判窄字、≥hi 判宽字；一侧不要就写 lo=0 或 hi=9 | 按第四节标定，本书两字分得开才开 |
| `fold_aspect_pairs` | `{组: [窄字, 宽字]}` | 哪些组按宽高判、哪个字窄哪个字宽；缺省 `{ry: [日, 曰]}` | 有新的「长宽可分」字对时加；写 `{}` 等于不按宽高判 |
| `fold_jiazhu` | `true` | 夹注 a/b 半格也折叠；**半格绝不取整理本字**，只按半格宽高或文意裁定 | 本书夹注里这几组多（史記） |
| `fold_aspect_jiazhu` | `[lo, hi]` | 半格单独的宽高阈值（夹注字块比正文扁） | 开 `fold_jiazhu` 时按第四节单独标定 |
| `fold_aspect_ctx_veto` | 概率，建议 `0.5` | 上下文首选（context_decide ranked）给组内另一个字 ≥ 这个数 → 宽高结论作废 | 开宽高判据就建议同开（防切分框不准） |
| `fold_ctx_vias` | 来源层列表，如 `[ctx_l3]` | 认字组流程文意路已给的字（`fold.via=ctx`），这些格多是被日目搭档没表态、殿本宽高比路唱反调挡下的 | 本书各层文意答案先抽检；**L1 不要进**（殿本 H01 里 37 格错 15） |
| `fold_ctx_strong` | `true` | `fold_ctx_vias` 只认 strong | 殿本建议开 |
| `fold_ruling_first` | `true` | 有本组文意裁定先用裁定字 | 已有裁定库的书 |
| `fold_lib_top_in_group` | `true` | 库首位也须在本组 | 建议开 |
| `fold_coord_ref` | `true` | 现役对位缺时用坐标对位；未入组格按库首位入组 | 现役对位常缺的书（全唐文） |
| `fold_occluded` | `true` | 遮挡格也归组（整理本字只判归组，不定字） | 配 `fold_ref_char: false` 用 |

「宽高」量的是切分后字块框的宽／高（`char_index` 的 `width`／`height`），不是字形主体；所以切分框不准的格会量错，这就是 `fold_aspect_ctx_veto` 存在的原因。

## 四、每本书怎么定参数

1. 拉几册 ★main 包（`guji products pack fetch <册> -w <工作区> --label <标签> --to <目录>`），册越多越好，正文、夹注都要有。
2. 标定宽高：

   ```
   python scripts/fold_aspect_dist.py <目录>/<册> [<目录>/<册> …] --pair 日曰 --max-err 0.01
   ```

   真值取「已放行、机器字＝整理本字」的格；正文、夹注半格分开出分位数；按「判出来的格里错 ≤ max-err」（按本书两字实际出现比例算）分别建议 lo、hi；收不到三成的一侧直接说不建议。
3. 在本书 H01 格上看效果：哪些格会被宽高判掉、和上下文首选冲突的有几格，冲突格看图。
4. 文意裁定：H01 剩下的格开干净会话逐格读（不调 API），写裁定库（键＝本组 L3 提示词版本＋前后文窗口），下一轮由 `via=ruling` 放行。
5. 首用按金标抽检一次再推开；结论写进本书的 book_defaults 与本节表格。

| 全唐文 | 005、006、007、011 | 0.72／1.12 | 无 | 判日 lo≈0.97；判曰一侧不建议（日有 1.5% 宽到 ≥1.0，而本书日比曰多） | `fold_aspect: [0.85, 9]`（只判日）、`fold_aspect_ctx_veto: 0.5`；H01 里 14 格日可放 |

几点说明：

- 「错 ≤1%」的「错」以「已放行且机器字＝整理本字」为真值，里面本身有少量错格，所以只当上限看；上线前仍要按金标抽检。
- 同一个阈值在不同书里风险不同：判出来的格里错几成，取决于本书两个字谁多谁少。全唐文日多曰少，所以「≥1.0 判曰」反而危险；史記曰多日少，「≤0.85 判日」危险。
- 史記标定只用了 5 册、全唐文 4 册，SJ、QTW 正式开之前请用更多册重跑第 2 步。
