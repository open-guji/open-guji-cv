# zhuan 撰𢰅（同义）

## 字形差别
撰 ⿰扌巽（巽＝巳巳 下 共）、𢰅 ⿰扌㢲（㢲＝巳巳 下 丌）：差别在右下。殿本刻法：
- 撰：右下 共，两短竖贯下，底下一对小八，字身窄长；
- 𢰅：右下作 丌／大，一长撇一长捺向两边大开，字身扁宽。

两形殿本都有（vol04–20 已放行 撰 1,598、𢰅 33，𢰅 多在 vol19–20），整理本与台账给的码位常与刻形不符：vol05 p128–150 一批「某某撰」整理本作 撰、刻形是 𢰅。

- 整字 48×48，岭回归 λ=1（`ids_online.SPECS["zhuan"]`）。
- 复核改字（`review_fix`）：已放行格判出另一形就按刻形改码位；补放给字。只在 seed_admit.group_flow 点名时生效。
- 门槛 0.5：按册留出不设门槛错 1 格（vol19:114:8:6 𢰅→撰，0.01），0.3 起 0 错；0.5 时给字 236/252（撰 196、𢰅 40）、0 错。
