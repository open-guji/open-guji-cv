# kgc 冠寇冦宼㓂（不同义）

## 字形差别
冠 与 寇 是两个字：冠＝冖＋元＋寸；寇＝宀＋元＋攴（异体 冦、宼、㓂）。殿本里两字上半同形、差在右下 寸／攴，二值图里肉眼勉强可分；
字形库把 寇 形常排成 冠（cov 0.95 一档）。sheldon 10-28：冦 → 寇，要和冠军的冠区分开；形分不开就靠文意。

## 怎么判
方法数组：`[ctx_rule → llm → model → llm_online]`（注册在 `groups/registry.py` 的 `SHAPE_GROUPS`，只在册 `group_flow` 点名时生效）。
- 两段判：文意定 冠／寇族（冠＝衣冠、弱冠、冠服；寇＝盜寇、流寇、入寇、寇準），寇族里 冦宼㓂 按书级 `codepoints` 归一，归一不到同一个字就取库形最近。
- 补放须与整理本（缺位用坐标对位字）同字（`lift_ref_agree`）；库首位与整理本同在组里就进（`ref_top_enter`），组外字紧咬不拦。
- 只补放，不复核（冠 的放行格不动）。与 cp_kou4 共用 宼寇冦：分差内有 冠 的格归本组，只有寇族字的格仍归 cp_kou4。
- 配置：`config/groups/kgc/` 下 prompt.md rules.yaml（L1 只收词组唯一的）；L3 在线缺省开（`group_flow_llm_groups`）。
