# chuo 辶族（不同义）

## 字形差别
走之底加不同部件：通（甬）過（咼）遍（扁）迥（冋）遺（貴）遣（𠳋）逸（兔）遠（袁）邊（臱）……
走之底占了字的左下大半，整字比库形相似度在一族里紧咬（通0.960 迥0.953 過0.946 遇0.943），形近护栏拦下送审。

## 怎么判
方法数组：`composite(crop(0.25, 1.0, 0.0, 0.8) → hog)`（注册在 `groups/registry.py` 的 `SHAPE_GROUPS`）。
- 复核与门：补放须与整理本同字（`FlowSpec.lift_ref_agree`）；陪衬见总表
- 配置：`config/groups/chuo/` 下 ids_bank.json
- 模板库：殿本 vol04–20 已放行格（无疑问，每册每字 ≤4、每字 ≤30）

取右上框（x0.25–1、y0–0.8，避开走之底）做 HOG 一对多（48×48，λ=1，去邻格碎墨），门槛 0.65。补放须与整理本同字（同 men）。
遺還 与 yh 共用：点名排在 yh 之后。**逈 是 迥 的异体，不进组**（码位按刻形分，归异体对的对话）；𮞉 等稀见字只当陪衬。只补放，不复核。
