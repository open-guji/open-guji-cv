# zhun 凖準（同义）

## 字形差别
凖 ⿱⿰冫隹十、準 ⿱淮十：差别只在左旁。殿本刻法：
- 凖：左旁一点＋一笔长提，提笔斜穿到右边的 隹 下；
- 準：左旁三笔（两点＋提）竖排，提短、不穿。

两形殿本都常见（vol04–20 已放行 凖 23、準 28），整理本与台账给的码位常与刻形不符。

## 怎么判
方法数组：`hog`（`groups/registry.py` 的 `SHAPE_GROUPS`，与 尙尚、蓋葢、䟦跋 同一套）。
- 判别区只取左半（x 0–0.5），48×48，岭回归 λ=1（`ids_online.SPECS["zhun"]`）。
- 复核改字（`review_fix`）：已放行格判出另一形就按刻形改码位；补放给字。只在 seed_admit.group_flow 点名时生效。
- 门槛 0.5：按册留出不设门槛也 0 错（48 格），0.5 时给字 33/48、0 错。
