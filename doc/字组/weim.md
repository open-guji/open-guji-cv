# weim 微㣲（同义；与 徵徴徹 形近）

## 字形差别
微 㣲：中下 几／口。工作区 codepoints `㣲: 微`（**暂归一**，拆分条件见 README 第二节：口形人裁攒够 20 例）。
难点是 **徵徴**（中下作 王）和 徹：字形库分不开，整理本作 㣲 的格库首位常是 徵／徴。

## 怎么判
方法数组：取框 HOG＋岭回归一对多（`ids_online.SPECS["weim"]`，取 x 0.2–0.75、y 0.2–1.0 的中下部，48×48），SHAPE 组（`registry._NEAR_FAMILY`）。
- 模板库：两码位并成一类 微，陪衬 徵 徴 徹 进库（判成它们＝弃权）；vol02–99 main 包已放行格：微 88、徴 101、徵 98、徹 80。
  看图剔出 vol10:11:4:9（放行成 徴、字块是 所）。
- 门槛 0.5；补放须与整理本同字；库首位是陪衬也按整理本进入（`ref_enter`）。只补放。

## 评测
按册留出，判成 微 的错例（陪衬判成 微）：整字 48 最高 0.44；取中下框后最高 0.27 → 门槛 0.5 给 微 70／88，0 错。

弃权 22，大多判成 徵／徴（整理本作 㣲、中下刻 口 的格，模板里 口 形少），留人审。
