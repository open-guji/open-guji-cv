## `row_segment` Step3 单列文字切分

- 输入：`gate_manifest`、`column_windows`、`column_image`；可选 `seals`
- 产出：`cells`
- 出口闸 `row_segment_gate`（column，不过时 block）：
  - L0 `page_type_skip`：闸1是否判定这页页型为 skip 类——是则页级直接拒收，不看列级 DP 结果
  - L0u `layout_unsupported`：是否「版式未支持」（整页各列都因弹性 DP 无解而被拒）——职名/目录类，非故障，与真异常分开记
  - L1 `dp_no_solution`：DP 是否有解
  - L1 `slot_count`：格数是否偏离版式格数超过容许范围（非 effective_body_slots 的正当下调）
  - L2 `cut_improvable`：R2 可改善格线数——flag，不拦（该修但不算作废这一列）
  - L2 `cut_touching`：R2s 真粘连格线数——flag，不拦（图像极限，不算错）
  - L4 `sliver_cell`：碎格：格高远小于一格——flag，不拦（列里多数字仍切得对）
- 进指纹的代码：`open_guji_cv.impl.keben.row_boundaries`、`open_guji_cv.impl.keben.row_grid`、`open_guji_cv.impl.keben.jiazhu_split`、`open_guji_cv.seg.warp`、`open_guji_cv.seg.profile`、`open_guji_cv.impl.keben.column`、`open_guji_cv.seg.seam`、`open_guji_cv.seg.cut_select`、`open_guji_cv.impl.keben.roster_segment`、`open_guji_cv.impl.keben.roster_glyph`、`open_guji_cv.impl.keben.yolo_tool_infer`、`open_guji_cv.steps.occlusion`、`open_guji_cv.steps.seal_detect`、`open_guji_cv.steps.row_segment_pagemap`、`open_guji_cv.utils.page_align`、`open_guji_cv.utils.daizhige`、`open_guji_cv.impl.keben.jiazhu_step`、`open_guji_cv.impl.keben.seal_ink`、`open_guji_cv.impl.keben.row_hooks`、`open_guji_cv.feedback.seg_overrides`
