# 2 切字的五小步（2a–2e）

> 2026-11-25 用户定：第二步按下面五小步理解与分析。**这是分析用的逻辑分组，不是五个独立的 Step**：步骤 id、产物、指纹都没动。代码现状与五小步的对应见第三节；把 2b、2d 拆成独立 Step 是后续的事（要重算产物，单独评审）。

坐标约定：「页」坐标是原图（右上角原点、y 向下的新坐标系）；「列图」是拉直后的竖直矩形（左上角原点），列内坐标一律用列图的像素。

## 一、五小步的输入输出

| 小步 | 做什么 | 输入 | 输出 |
|---|---|---|---|
| **2a 拉直** | 用左右两条界行线（可为三段折线）把每列做射影变换，拉成完整矩形；去孤立小墨点 | `raw_page`；第一步的 `borders`（上下版框、内框线、每列左右界行线）、页型闸 | 每列的 `column_windows`（窗口、上下界、`border_*_in_column`）、去噪后的列图 `column_raw` |
| **2b 定字带左右边** | 竖直墨量投影，找左右两端：界行衰减后的谷底，或探进带里的孤立窄墨条的内侧；带外抹白（不裁，坐标不变） | `column_raw` | 每列文字带 `band=(x_left, x_right)`；两侧已抹界行的列图 |
| **2c 字间切分** | 沿竖直方向找字缝：整列等距格网先验＋U-Net 选缝，字数来自先验（整理本、版式格数） | 清理后的列图 `column_image`、`band`、版式先验、人定切分（`切分覆盖.md`） | `cells`：每格的上下界、类型、读序 |
| **2d 列端字** | 首、尾紧挨着上下版框的格：判是否只有框线、剥框线、按内框线位置切（列端曲线切边） | 2c 的首尾格、`border_*_in_column`、内框线 | 修正后的首尾格；列图上下端已抹的版框墨 |
| **2e 字框压缩** | 每格里取字身连通体，收成紧框；剥格内残余界行竖条、框线 | 每格 `cells`、列图、`band` | `char_index`（紧框＋flags）、`char_patch`（字块图） |

## 二、每小步的边界（便于分析）

- 2a 只管几何：不判墨、不找界行；折线按折点分带，每带一个矩阵；`ruled_warp` 是逐行插值的另一种拉法（缺省关）。
- 2b 只用墨量投影，对象是列图的**左右两端**；分横条（240 行）各找一次，因为界行是弯的、常只在列的一段探进带里。写本用 `tight_rule_band`，全唐文用 `inner_bar_span`。**现在 2b 只抹界行，没有给出「字带」的明确左右端供后面共用**（见第四节）。
- 2c 只在字带内切缝，不看版框；列端字的特殊处理放 2d。
- 2d 是唯一同时用上下版框坐标和字墨的一步。
- 2e 只改框，不改 2c 的格线；不能丢字身墨。

## 三、五小步与现有代码的对应

| 小步 | 现在在哪个 Step 里 | 入口函数 |
|---|---|---|
| 2a | `column_warp` | `seg/warp.py`：`page_column_windows`、`warp_column`；`seg/profile.denoise_column` |
| 2b | `column_warp`（`clean_column` 前半） | `seg/profile.column_text_band`、`impl/keben/column.strip_column_rules` |
| 2c | `row_segment` | `impl/keben/row_boundaries`、`row_grid`、`seg/seam`（U-Net 选缝） |
| 2d | 分在三处：`column_warp`（`clean_column` 后半的 `column_border_trim`，列图上下端抹框）、`row_segment`（列端判空 `frame_only_edge_cells`）、`cell_shrink`（`strip_frame_line`、列端曲线切边） | 同左 |
| 2e | `cell_shrink` | `clustering/extractor`：`strip_side_rule`、`strip_frame_line` |

所以：**2a、2b 同在 `column_warp`，2c 在 `row_segment`，2e 在 `cell_shrink`，2d 横跨三个 Step。** 分析某一小步的问题时，先按这张表找代码，不要只按 Step 名找。

## 四、已知缺口（待定）

- 2b 的输出只是「抹掉界行」。用户想要的是：在文字带两端各取一个稍往里缩、墨量最小的点，作为这一列的字带左右端，2c、2d、2e 共用。现在这个数值不存在，各步各自处理左右。
- 2d 的逻辑散在三个 Step，各用各的判据（见 `doc/经验/切分四步-研发记录.md`）。
