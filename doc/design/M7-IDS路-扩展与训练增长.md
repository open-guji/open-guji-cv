# M7 IDS 路：參㕘叅 落地与“文本变多以后怎么扩训练”

状态：2026-10-18，cv#117（草稿，基于 rc/v0.3.1）。承接 [M7-形近字解法模式与扩展](M7-形近字解法模式与扩展.md)。

## 1. 结论与数据

- 慎愼、群羣、點㸃：殿本只刻愼、羣、點，没有“两种刻形二选一”的任务，按“刻形＝系统码位”直接取字，不做 IDS。
- 真正有差别的只有參㕘叅，三字上半同为厽：IDS 里 參＝厽人彡、㕘＝厽人小、叅＝厽人㣺，只差最下一小块。
- 人标池：dataset `char-groups/variant/can/labels.jsonl`，74 格（參 35、㕘 37、叅 2），每格带人确认过的切线。
- 留一评测（模板库只用其余格；弃权阈值 0.02；vol02–10 的 core 格）：

| 做法 | 切线 | 对 | 弃权 | 放错 |
|---|---|---|---|---|
| 一刀（缺省） | 人标 | 67 | 7 | 0 |
| 一刀（缺省） | 自动缝 | 66 | 8 | 0 |
| 两刀（`sub_prior=0.45`，只比最下一块） | 人标 | 71 | 1 | 2（都是叅→㕘） |
| 两刀 | 自动缝 | 69 | 2 | 3（另一格參因缝偏判㕘） |

- 一刀满足“给字格放错 0”，整格读对率 90.5%（差在 7 格弃权）。两刀把參㕘分得更准，但叅只有 2 例，留一时只剩 1 个参照，两刀会把叅放错成㕘。**缺省用一刀；叅每类攒够 8 例再评两刀**。
- 自动缝与人标线墨迹像素吻合 97.7%（最低 0.82），所以生产用自动缝，不需要每格人画线。
- 全部 197 个核心格预测：給字 188、弃权 9；与整理本／放行字不一致的 10 格交人审。

## 2. 文本变多以后怎么扩（不是神经训练，是扩模板库）

求解器是“切线 → 取一块 → 在真实刻例模板里最近邻 → margin 不够弃权 → IDS 查字”，没有权重可训，所谓训练＝**扩人标池、重建模板库、重评**。流程：

1. **取格**：新整理的册里，整理本字或放行字落在组内的 core 格（`research/m7/ids2/crop_cells.py` + 计数脚本）。
2. **预测并分流**：`predict_two.py` 用现有池出证据，分三堆：一致且 margin 高→直接采纳，不抽查；与整理本不一致、弃权、margin 低→进人审；某类样本数不足的类（叅）一律弃权。
3. **人审**：`make_review_cards.py` 出复审卡（隐藏参考字、乱序、机器线预画），页里选字形、点“采纳”确认线；`harvest_verdicts.py` 收回，**追加**到 dataset 的 `labels.jsonl`（只增不删）。
4. **重建与重评**：用新池重跑 `eval_two.py`（留一）。门槛：给字格放错 0 且整格读对率 ≥95%，不过就不许上线、继续弃权。每类 ≥8 例才允许该类给字；叅达标后评两刀，两刀留一放错为 0 才切到两刀。
5. **防漂移**：每次扩池留一册（如 vol10）不进模板库，当 held-out 复核，margin 阈值随池变大重定。
6. **结果落点**：证据 json 放工作区（`yi_ids_*.json` 同格式），池在 dataset，代码不在任何 Step 的 `code_deps` 里，所以扩池不让各书产物判过期；接入 `seed_admit` 才登记注册表，那一步会改 code_hash，要单独报告。

## 3. 复用到其他组

每组一个目录：`config/groups/<g>/ids_override.tsv`（部件停止点、同形别名）＋ dataset `char-groups/variant/<g>/labels.jsonl`。上下切用 `orient=h`，左右切用 `v`；三层结构（如 參）用 `sub_prior` 做第二刀。慎愼类“只有一种刻形”的组先查实刻再决定要不要建池。
