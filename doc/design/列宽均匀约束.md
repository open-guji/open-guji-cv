# 列宽均匀约束（Step1 列线拟合＋检查）

2026-11-03 A22。Sheldon 定：「列宽均匀是强约束，无论是开始的算法还是后面的检查，都一定要把它好好检测出。」

## 一、现状和问题

- Step1 先用自由模式（`seg/lines.find_vertical_lines`）按峰值挑 N+1 条竖线，**挑的时候不看列宽**。
- 列宽出了带，再由 `books/siku_zongmu/pitch_rescue` 一路路补救：frame、grid、extend、fuse、snap、pad，1.15 又补了三处，一共 7 路。每路都是为某一型页面加的，规则越堆越多。
- 列宽带的数（内列 0.9–1.1、外列 0.85–1.3）写死在殿本模块里，别的书没法设。
- 救不成就原样放行：交接闸（`gates/border_detect_gate`）不看列宽，r2 里 4 页外列只有 0.5 倍列宽，照样进了下游，最后变成 90 个待审格。

## 二、设计

### 1. 原语 `seg/columns.py`（多书共用，带单测）

```python
@dataclass(frozen=True)
class ColumnSpec:
    n: int                        # 列数（版式列数，= expected_cols）
    uniform: str = "off"          # strict | loose | off
    inner_band: tuple = (0.9, 1.1)    # 内列宽 / 页列距
    outer_band: tuple = (0.85, 1.3)   # 首末列（量到外框，偏宽）
    pitch: float | None = None    # 列距先验（px，按本册图源；无则取本页中位）
    leaf_layout: str = "single"   # folio 时版心列不受带约束

def check_columns(xs, spec) -> ColumnCheck:
    """出带的列（列号、宽/列距）＋页列距。Step1 产物 flag、交接闸、体检脚本同一口径。"""

def fit_columns(cands, profile, spec) -> FitResult | None:
    """从候选线里一次挑出 n+1 条：每列宽都在带里，证据分最高。"""
```

`fit_columns` 就是把现在 `fuse` 的动态规划做成通用的、唯一的一路：

- **候选**：自由模式的线（高分）、网格模式的线、界行残段（竖墨线连续 ≥ 0.8 列宽）、字间空白段中点、外框外推线（出图边截到图边）。各给证据分。
- **代价**：线落在墨上要扣分（按投影墨占比扣，墨越多扣越多），这样字心假线就选不上。
- **约束**：相邻两条线的间距必须在带内（内列用 inner_band，首末列用 outer_band），列距取先验，没有先验就取本页合格列的中位。
- **解**：在候选按 x 排好的序列上做 DP，求总分最高的 n+1 条链。自由模式的线本来就合格时，它们分最高，结果和现在逐位相同。

现在的 7 路救援都是这个 DP 的特例（换候选或换打分），实现完删掉，`pitch_rescue.py` 只留薄壳，或者整个撤掉。

### 2. 套书配置 `columns:`

写在各书 `book_defaults.yaml`（册 yaml 可以覆盖），读进 `BookSpec.columns`（`ColumnSpec`）：

| 书 | uniform | 说明 |
|---|---|---|
| 殿本四库总目 | strict | 内列 99.9% 在 0.907–1.088（vol04–20 实测） |
| 史記文淵閣写本 | loose | 写本界行手画，带放宽；SJ 自定数 |
| 北行日錄刻本 | strict | 已走网格模式；folio 版心列不约束 |
| 幼學須知等自由版式 | off | 不约束 |

- `off`：不拟合不检查，和现在的非殿本书完全一样。
- `loose`：只检查、打 flag，不重拟合。
- `strict`：自由模式结果出带就走 `fit_columns`；拟合不出就打 flag，交接闸标页。

### 3. 检查（后道）

- Step1 产物：出带的列在 `line_index` 该列的 flags 里加 `col_width_out_of_band：列宽 r 倍列距，出了带`（不加新字段）。
- 交接闸 `border_detect_gate`：strict 书有出带列，就在 manifest 记 `col_width_out_of_band`，**只标记不拦**（拦了整页不切，字会丢）。
- 待审分类（A31 的分类 v2）直接读这个 flag 归「S·Step1 列宽出带」，不必等认字出错才回推。
- `scripts/seg_health`（体检）按册统计出带页数，进后台「切分」栏。

## 三、实施步骤

1. 加 `seg/columns.py`（ColumnSpec、check_columns、fit_columns）＋单测；`BookSpec.columns` 配置读入；殿本 `book_defaults.yaml` 写 strict。
2. border_detect 改用 `fit_columns`，删掉 pitch_rescue 的各路；产物出带列加 flag。
3. 交接闸标页；体检脚本统计。
4. 验收：固定样本集（seg_samples）＋全殿本 border_detect 前后对比。合格页必须逐位不变，变了的页逐页看图；出带页数要降到只剩真异常页（卷端大印页、书名页），并列出名单。

格式：不加字段，只多一种 flag 字符串（flags 本来就是自由文本列表），不算切分结果格式变化。

## 四、落地（2026-11-03，border_detect 1.16、border_detect_gate 1.3）

- `ColumnSpec` 实际字段：uniform（缺省 strict）、inner_band、outer_band、pitch、min_cols；列数取 Step1 线数，版心／edge 列由 `classify_columns` 判、不受带约束。
- `pitch_rescue.rescue` 成了薄壳：备候选、打分、护栏，拟合一律走 `fit_columns`；7 路旧函数已删，旧页型都留在 `tests/test_pitch_rescue.py`。
- 各书 `book_defaults.yaml` 的 `columns:` 还没写（缺省 strict 只在殿本 border_detect 的救援路径上生效）；非殿本书要用由各书项目自己配。
