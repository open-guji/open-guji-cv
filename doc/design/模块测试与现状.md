## 1. 切分线（Step0–4）

### 1.1 目标口径与验证三件套

用户定「Step1–4 100%」，`todo.md` 写死了它的意思：**能从图上分开的都分对，分不开的（真粘连）都标出来，不给错结果**（DP 约束不满足返回无解而非硬切）。
验收线（阶段 A）：vol02 全书 R1 ≥99%、R2 <2%、R3 = 100%、R4 = 0；随机层 400 格 Wilson 下界 ≥99%。

每一处切分改动过三关（`segmentation_v2_pipeline.md` 末节是范例）：

1. **内存新旧对比** `scripts/seg_harness.py`：与 `RowSegmentStep` 同入参重跑 `segment_column`，baseline 与现役产物 0 差异；量两册前 50 页 **851～855 列**，报「格类型变化了几列」→ 逐列看图。
2. **切线金标 eval** `eval_touching_cuts.py`：895 条（2026-09-11 起含 vol03），报 mean / median / p90 / ≤3 px、折线口径最大偏差；**金标零变化本身就是验收**（折线护栏第一版正是被金标页 4 条线被拉偏 17～29 px 抓出来的）。
3. **变化列看图**：逐条**放大到 260 px**。缩图 + 自动量判愈合两次出错（自动 healed 被复标回 12 条；「35 愈合」被复核推翻 14 条 + 自查 4 条），量不到「切点落字身上沿」和「几像素残墨」两类。

另加：单测全绿（切分相关约 160 条）、四把尺子不退、判据 A/B 不退。

**技术**：纯 numpy 无 cv2；**半高宽匹配度**（每点用自身值为基准向两侧走到跌破一半，`alpha=0.5`、`hyst=3`，界行比值 200～500 vs 正文列个位数）；位置 + 角度联合搜索（粗扫范围可窄步长必须细，角度峰半高宽 <0.01）；三段折线直接搜四折点、三角核打分、行过滤局部一致性闸；两翼近零闸 `FLANK_MAX_RATIO=0.35` + 采样窗口垫边 `SEARCH_PAD=60`（压边假峰 28 页 → 0）；抬头框 `HR_DIST_MIN/MAX=90/210`（**从 13 个样本量出，换书必须重标**）；版框几何常数 90 页实测（四边不等距，外条只有外延稳）。

**已知缺陷**：三段折线吃不住段内曲率（vol01/119，用户裁定不增段）；vol01/11 L1 墨少到指标量不出；vol01/42 落在外框；vol02/176、vol02/3 粗条内缘弥散救不了；下版框系统性偏上（dev_set 155 列下界外残字墨中位 21 px、83% 列超 5 px，`BOTTOM_PAD=40` 兜底后剩 52 列中位 5 px，**根修未做**）；弯界行 / 无界行页（vol02/177、178 没印界行）；最外列尾部宽 +18～29%（vol02 19 页）。

**已推翻的结论**（别再走）：vol01/47 系统偏斜「抬头墙线带偏角度」；「界行弯 30 px 必须换曲线模型」（量法太松抬高 3 倍）；137/138/141 底框「画在白纸上」（三页都印了只是极淡，**判有无线不能用绝对墨门槛**）；抬头框「必须成对」（精确率 100% 召回崩到 28%）；水平线整带 NMS；窄窗二次联合搜索；降采样粗定位（弱线排名翻转，结构性）；线程池（GIL）；抬头列漏检 96%（127 条全误报，事件已 revert）。

**下一步**：修 Step1 优先级往后放（真没切对的极少数页需要专门处理弯界行这一族，是模型假设问题）；扩抬头框金标（现 6 页 18 例，换书前必须）；A3 下版框根修**先造直接金标**（现 bottom 7.0 px 是对人工直线量的，半高宽判据已证分不开）；vol01/42 型在外条内侧找次候选。

### 1.4 Step2 单列射影与清版

**测试集**（`char-segmentation/column-warp`）：**115 列 / 76 页**（111 clean / 4 mixed），文字带 230 条界、上下版框 64 条端裁决。分层抽样：随机层 n=40（唯一能估全书比例的一层）、难例尾 n=20、难例优先 n=55——**不能混着算**（混算 mixed 率抬高 10 倍）。标法：整列压扁图 + 投影拖两条竖线；上下版框只点类别不标坐标。另 `legacy-page-anchor` 25 列（人工边线 + 页锚点，隔离 Step1 误差）、`side-rule` 276、`frame-strip` 65、`page-crop` 6 页。

**指标**（`eval_column_warp.py`）：金标是走廊 `[canonical, human]`；三项分开报——落走廊内 / **吃进字身 px（红线）** / 留残墨 px + 墨量；上下版框按类别混淆矩阵。

**现状**（2026-09-03 收口）

| 项 | 值 |
|---|---|
| 落走廊内 | **228/230（99.1%）** |
| 吃到字身的列 | **0/115** |
| 残墨 | 均值 0.000 / 最大 0.006 |
| 上下版框类别一致 | 60/63 |
| 全书 mixed 率（分层加权） | **≈0.39%** |
| 全语料 2,655 列 | `side_floor` >0.01 仅 60 列（2.6%）；「有干净边距却没找对」只剩 **6 列（0.26%）** |
| 下界开到版框外后 | 列图底边触墨 24.5% → **0/216**；vol02 Step3 解出 95.9 → 99.2% |

**最硬的结论**：抽 400 列量带边界处原始墨占比中位 0.0037、超 0.05 仅 1 列，切得最深的 8 列边界墨恰等于该列 `side_floor`——**`column_text_band` 已落在可选范围内墨量最低处，「调判据还能再挤」这条路已否掉**。

**技术**：射影矫正（`out_w=max(顶宽,底宽)` 不压扁，已两条证据证明）；折线页分带射影共用 `out_w` 竖向拼接（拼缝相邻行差与普通行同量级）；`column_text_band` 从两端往里吃「界行本体 ≥0.35 + 裙边 ≥0.12」限 15% 宽，补内缩档（弯界行探进带里）；`strip_column_rules` 分横条（240 行）做；`column_border_trim` 上下版框 a/b/c/d 四档，三把尺子（厚度 30 行、起始陡度、内缩档最低墨 0.15）全拿金标标定；清理顺序固化（先定带 → 抹侧 → 只在带内算投影 → 削上下）；上下界一律取页面右端锚点 x=0（明知取舍，最左几列上端可能低 60 px）。

**金标迁移机制**（Step2 独有，`migrate_column_warp_gold.py`）：主判据图像指纹（≤6 灰阶留用），补救通道只对 clean 列；**不拿算法一致性当留用判据**；`border_class` 类别一条都不能迁（取景范围变了标签定义就变）。实战：全书重跑后 112/114 留用。

**已知缺陷 / 负结果**：mixed 四种机制一个指标覆盖不了（弯界行只探一端、夹注列小注贴边、字身无零墨边距、背景印章散点）；下版框残线 `column_border_trim` 清不干净且试修 `_also_second_bar` 四把尺子全线略差已回退（**要清得在 Step4 图块层**）；**除 L1 外没有第二条经过验证的列级筛选力**（`side_floor` 只看两侧外 25%，扩金标后 clean 上限 0.0111 vs mixed 下限 0.0044 完全重叠，`xfail(strict=True)` 留活证据）；内缩档不能只看峰值、不能取「第一段墨」；行墨占比本身不能当判据。

**下一步**：列级准入要一条不同维度判据（整列噪点密度、连通域碎片数）；`eval run side_rule` 现字保全 99.62%、残余 1.45%（2/138）；**下一册开工前修夹注 a 侧右缘（列内容窗口右界 / `gap_center`）**；TODO 判词「几何已无余量；夹注列非单一版式」。
