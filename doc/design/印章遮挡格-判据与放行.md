# 印章遮挡格：流水线里怎么认、怎么放

> 汇总 2026-09-28 到 2026-10-31 流水线里所有和印章、污渍遮挡有关的处理。都是 Step 里自动做的，跑 pipeline 就生效。
> 人审、待审单分类、怎么统计、怎么回放核对这些校对环节的做法，写在 guji-manager `doc/02-粗校/印章遮挡格-校对处理.md`。
> 参数的缺省值以代码为准（`steps/seal_detect.py`、`steps/occlusion.py`、`steps/seed_admit.py`、`steps/align_ref.py`），开关的证据和状态见 [开关登记表](../开关登记表.md)。

## 一、总览

印章压着的格有两个难处。一是**字形库在印泥斑点下不可靠**：库首位常是少一笔或多一笔的近形字，覆盖度照样能到 0.95–0.99。二是**这些字形太脏，不能进字形库**（用户 09-28）。所以：

1. Step1 之后先定印章位置（`seal_detect`），后面各步都读它。
2. `seed_admit` 先把印章区里够脏的格标成「遮挡」（`occluded`），这些格默认不放行，`char` 填**默认字**（整理本的字）。
3. 然后几条规则把能确定的遮挡格放出来（R5 `lane_seal` 等）。放出来的格**一律不进字形库**（`no_glyph_lib`）。
4. 放不出来的格留给人审，人审卡默认显示整理本的字。

```
seal_detect ──▶ seed_admit: 遮挡判据 ──▶ 默认字 ──▶ 异体规则先走 ──▶ R5 lane_seal 各规则 ──▶ 剩下的待审
   印章外框        (occluded)          (align_ref 坐标/对位)   (occluded_variant_first)
```

## 二、印章定位 `seal_detect`（2026-10-22）

紧跟 Step1 版框，产物 `seals` 是后面各步认印的唯一来源。分两类：

- **大印 `stain`**（卷首叶、卷端页的藏书印）：按「中等墨点」的网格密度判有没有。有就取版框右上角起、边长等于版框宽的正方形当外框（印紧贴版框上边与右边）。读不到版框才退回密度区的外接框。窄而淡的密度区不套整页正方形（vol35 p173 曾误套，42 格正文被判遮挡）。
- **小印 `crisp`**（卷末「乾隆御覽之寶」）：用模板整页搜，分数取「模板笔画处有墨的比例 − 模板空白处有墨的比例」，印压在正文上也认得出。

## 三、遮挡判据（`seed_admit.occluded_gate`）

1. 格落在大印框内，或与小印框重叠 ≥ 0.3（小印压着的字也算）。
2. **格内背景要脏**：格内背景噪点密度（每万像素中等墨点数）≥ `occluded_seal_min_noise`（4.0），否则不算遮挡（#724，用户 10-28 定「印章范围内＋背景有大量噪点」才算；20–99 册约 14% 的原遮挡格背景其实干净）。
3. 没有印章定位的老口径（`occlusion.py`，整页热格成块）仍保留作兜底，阈值见该模块头的标定表。

命中的格：`admit=False`、`doubts=["occluded"]`、`evidence.occluded = {density, via}`。

### 默认字（`_occluded` 的 `via`）

| via | 来源 | 说明 |
|---|---|---|
| `coord` | `align_ref.coord` 坐标对位字 | 逐列本按格位定行，最可靠 |
| `coord_blank` | 坐标对位说这一位是空格 | 印章切出来的假格，`char=None`、`ref_blank=True` |
| `coord_pua` | 坐标对位给的是 〓 | 整理本缺字，无默认字 |
| `align` | 现役对位字 | 没有坐标对位时退用 |
| `none` | 都没有 | 整列对不上，无默认字 |

**卷末印页的空栏**（`occluded_past_leaf_blank`，seed_admit 1.29、align_ref 2.5，11-01）：卷末页整理本只到「…皆附存目」，后面几列是「乾隆御覽之寶」压着的空栏。邻页定位／页钉位时，这些列已过了整理本这半叶的末行，align_ref 记退回原因 `COORD_PAST_LEAF`；列里没有现役对位字时，遮挡格的来源记 `coord_blank`，由 R5 判非字。r1 包 80 册只有 5 页命中，55 格看图全是印文碎块。盖章空栏的墨量保险（模板外墨）在这几页挡住了（印面糊、模板对不齐，模板外墨 0.01–0.2），所以另走这条。

### 盖章空栏（`seal_blank_page`）

固定印「乾隆御覽之寶」命中、印框与格重叠 ≥ 0.5、坐标对位无字、没被强通道放行的格，挪成「遮挡、默认字 None」，再由 R5 的 `coord_blank` 分支判非字。只按格判，不按列判。

## 四、`align_ref` 为印章页做的事

- **`coord_neighbor`**（2.2，A32 10-26）：印章页 OCR 太差、整页定不了位置时，借后一页（再前一页）的位置推出本页的半叶头，按格位给出坐标字。只在原定位失败、且是逐列本时启用。
- **`coord_title_formula`**（2.3，#726）：一列坐标字整串是「欽定四庫全書總目卷N」时，现役对位在印章乱码里零星对上的单字（孤立弱冲突）不再把整列退回。强冲突照旧退回。

## 五、放行规则

### 5.1 异体规则先走（`occluded_variant_first`，1.25，#722，用户 10-28 定）

「异体字能处理的就让它处理，处理不了再按印章走」：

- 默认字就是库首位、且覆盖度 ≥ `seal_lib_cov`（0.9）时，不受异体护栏限制。
- `follow_ref` 和 `group_flow` 不再把遮挡当硬护栏，但 `group_flow` 只能放「给出的字＝默认字」的遮挡格。

### 5.2 R5 `lane_seal`（通道 `seal`，缺省开）

| 规则 | 参数 | 何时加 | 做什么 |
|---|---|---|---|
| 放默认字 | `lane_seal_via`＝`coord,align` | 1.13；1.24 加 align | 默认字来源在列表里且有字 → 放默认字 |
| 判非字 | （`coord_blank`）| 1.13 | 坐标说是空格 → `admit=True`、`char=None`，文本层跳过 |
| 题列不放 | `lane_seal_title_marks`＝`書總目,四庫全書` | 1.13；1.24 去掉「總目」 | 本列坐标字含这些串 → 整列不走 R5（题列常错位）。正文里的「崇文總目」不再误拦 |
| 题列套语 | `lane_seal_title_formula`、`lane_seal_title_norm`＝`巻卷` | 1.24（A32，用户 10-26 定） | 整列坐标字**正好**是「欽定四庫全書總目卷N」→ 按坐标字放，巻 一律录作 卷（项目新规矩，不跟整理本）。不受题列不放、异体护栏、库否决限制 |
| 库否决 | `lane_seal_lib_veto`＝0.95 | 1.24 | 库首位覆盖度 ≥ 0.95、与默认字不同、又不是异体对 → 送审（`lane_skip.why=lib_veto`）|
| 库第二名不否决 | `lane_seal_lib_veto_second` | 1.27（A32 10-31，#801） | 默认字正是库第二名时库否决不生效 |
| 整页错位护栏 | `lane_seal_shift_guard` | 1.24 | 本页印章格的库首位系统性等于上一格或下一格的默认字（≥3 格且多过对齐数）→ 本页 R5 全不放（`why=page_shift`）。来源：vol40 p2 切分漏了列首一行 |
| 已定归一的异体对 | `lane_seal_codepoint_variant` | 1.27（A32 10-31，#801） | 默认字和库候选是异体对、但本书 `codepoints:` 已归到同一码位（𩔖→類、巻→卷、别→別…）或同在暂归一组 `PROVISIONAL` → 放归一后的字（`lane.variant_norm` 记 `codepoint`／`provisional`）|
| 库首位同字 | `seal_lib_agree` | Y1（缺省关） | 默认字＝库首位且 ≥0.9 → 放，题列也认。收益小，没开 |

己已巳一族（`_JYS`）的遮挡格一律不走 R5，归字组流程。

### 5.3 数据依据（看图核对）

- **题列套语**：殿本 47 册 58 列逐格看图，0 错。
- **via=align**：108 页印章页回放新放 105 格，1 格错（vol43 p2 c5 s8，整理本漏「有」，对位错一格）。
- **库否决**：vol20–99 r3 包 340 格逐格看图，默认字真错约 10 格（水/本、詳/洋、門/開、新/浙、安/中…），全在「默认字不在库前二」那档。默认字是第二名的 150 格没见错，所以才加「库第二名不否决」。
- **库否决里很多是「框切掉一笔」**（本→木、二→一）：cell_shrink 的紧缩框在印泥斑点下失准，库按少一笔的字匹配（A31 10-27 看图）。这个要靠切分修。

## 六、规则管不了的（截至 2026-10-31，vol20–99 main 包剩 448 格；11-01 r1 包 443 格，其中卷末印页 55 格由 1.29 放掉）

| 类 | 格数 | 原因 | 归谁 |
|---|---|---|---|
| 无默认字 | 185 | 切分格数与整理本字数不符、挪一格；首叶题列「欽」切成两格、「全書」并成一格（vol83 p1 c1）| 切分（A22）|
| 库否决（默认字不在库前二）| 181 | 约 5% 整理本字真错，不能自动放 | 人审（快速确认）|
| 己已巳 | 30 | 归字组 | 字组 |
| 整理本缺字 〓 | 26 | 无默认字 | 人审 |
| 异体对未归一 | 15 | 本书没定码位 | 码位表 |
| 其他 | 11 | | |

**首叶题列别用「题列按顺序一一对上」去补**：vol83 p1 c1 格数 14＝字数 14，但前 6 格错位（欽 切两格、全書 并一格），顺序对上会错 5 格。

## 七、改这些规则时要注意

- `seed_admit`、`align_ref` 的参数一改，`code_hash` 变，各册产物判过期。新规则要等各册重跑 seed_admit 之后才出新单。
- 放宽前先回放：在当前 main 包上用 dev 与改动分支各跑 `guji step seed_admit <册> --pages …`，只比遮挡格（基线的待审遮挡格要先和 A31 明细逐格对上），再逐格看新放的图。
- 库在印章下不可靠：不要拿库分单独放行遮挡格（A31 10-27 抽样，库分 ≥0.8 的卷首叶格大多是印泥糊住的）。
