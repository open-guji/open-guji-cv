# M7 字组分类与通用处理方案：从「一组一组做」到「按类批量做」

状态：2026-10-22 提案（sheldon 问「剩下几十个字组怎么分类往下推」）。承接 [切分识别经验推广](M7-切分识别经验推广.md)、[全盘点](../research/形近字方法与字组全盘点-2026-10-22.md)、方法数组（`groups/methods.py`）。
本文只是方案，不改代码，`code_hash` 不变。

所以「剩下几十组」真正缺的东西只有两样：**①③ 没有字形路**，**④ 的字形路不可复制**。两样都可以用同一件工具解决。

## 二、核心：一个通用的「字形判别台」，每组只填数据不填参数

不再按组想「差别在哪、怎么切」，而是给每组同一套候选方法，**按册留出自动选**：

| 候选 | 内容 | 来源经验 |
|---|---|---|
| 整字 | 整字 HOG／像素，尺寸 32／48／64 | 厯歴 啓啟 呂吕 |
| **自动判别框** | 两形对齐后求平均图之差，取差最大的子框（再加网格扫），框内 HOG | 厯歴 下半 97%、教敎 左上 94%；替代 sheldon 手调滑块 |
| 切到叶子 | 只在 ids_plan 是 split 且有人标切线时进候选：先验折线／U-Net → 叶子 → 最近邻 | 叙敘 教敎 絕絶 |
| 识别器 | 最近邻（缺省）、岭回归 | 最近邻就够 |

规矩（全部来自前几轮踩过的坑）：
1. **按册留出，且嵌套**：框和参数在内层折上选，外层册只用来报数，免得「在同批数据上选区域」偏乐观（厯歴 这次的毛病）。
2. **门槛定在 0 错**，过门槛放行，其余弃权送审。报「0 错覆盖率」和「次形覆盖率」两个数，次形全弃权不算解决。
3. **模板和测试同一种切法／同一种取框**。
4. 输出直接是一行方法数组登记（方法、框、尺寸、门槛）＋模板库 `ids_bank.json`；不满足 0 错的组不登记。
5. 样本门槛：每形 ≥20 才进；不够的组列进「待标注」清单（见第四节）。

结构判断不靠 IDS 写法（徵徴 在 ids_lv1 里是 ⿰，刻形却不是普通左右结构，右边攵也比叙敘的细，sheldon 10-22），**判别区一律由数据定**；ids_plan 只用来决定要不要把「切到叶子」放进候选。

## 三、分类与每类的处理

| 类 | 判别依据 | 包含 | 方法数组（缺省） | 每组要做的事 |
|---|---|---|---|---|
| **A 码位** | 书级定码位 | 內 別 出 卷 晚 | codepoint | 无 |
| **B 单形异体**（这本书里次形几乎不出现） | 字频表次形≈0 | 状态③的 13 组＋旨㫖 蒙 點 讖 隸 慎 | freq → 字形台 | 跑字形台；次形样本不够时只放主形（「像主形」比「像次形」好学），次形送审 |
| **C 混用异体**（两形都常见） | 两形各 ≥20 人裁 | 呂吕 徵徴 衛衞 刪删 扺抵 厯歴 啓啟 教敎 叙敘 絕絶 參㕘叅 彝 往徃 | 字形台（切到叶子按需） | 重跑字形台，比现在线上好才换 |
| **D 形近，文意可分** | 已放行格上文意准确 | 状态①的 19 组 | ctx → 字形台（第二路，`agree`：给字必须一致） | 字形台当第二路：文意弃权时补位、冲突时降审。量横、宽高比这些专用第二路逐步被它取代 |
| **E 形近，文意分不开**（两字都说得通） | 文意在已放行格上有错 | 宋朱未 各名 心必 子于 山由出 | 字形台 | 已做，换成通用台重跑核对 |

类别本身也可以自动判：B／C 看字频表两形比例，D／E 看文意路在已放行格上的一致率（宋朱未 就是这么发现的）。

**跨书**：模板按书层存（语料库三层里的 book-id 层）。新书先用殿本模板跑，判别台在新书人裁攒够后再按该书留出重选；字频表只对殿本有效的问题由 B 类的字形路兜住。

## 四、需要 sheldon 标的东西

尽量只标「字是什么」，不标切线：

1. **每组每形 20 格的刻形确认**：一张通用手机页，多组一批；机器按字形台预填，按把握排序，sheldon 只改错的。优先标 C、D 类次形不够的（徵徴 衛衞 的字块图还要先从中心库导出）。
2. **判别台拿不准的格**：0 错门槛附近的格（主动学习），每轮一页，标完重跑，覆盖率涨得最快。
3. **切线只在必要时标**：只有当某组「切到叶子」明显好于「自动判别框」（目前只有 絕絶 这种部件小的）才出切线页。

## 五、落地顺序

1. **数据底座**（约 1 小时）：把 unified.jsonl 里所有人裁格的字块图统一从中心库导到数据集 `char-groups/crops/`（现在只有十几组有图，散在 `variant/*/crops`）。
2. **字形判别台**（约 2–3 小时）：`research/m7/bench/` 一个入口 `bench.py <组|all>`，实现第二节；先在已上线的 ④ 组上复现现有指标（不许退步），这一步就是它的验收。
3. **全组跑一遍**出一张总表：每组 现线上覆盖 → 判别台覆盖、缺多少样本。按「送审格数 × 可提升比例」排序。
4. **标注一批**（第四节 1、2）。
5. **按表登记**：B、E 类直接换；C 类比现线上好才换；D 类加第二路要先在 vol04–10 抽样核放行变化。每批一个 PR，报 code_hash，重跑归 M8。

## 六、不做的

- 不追求一个通用模型认所有组（各组样本少、差别各异；判别台通用的是「流程和选法」，模型仍按组）。
- 不新建低送审组（全盘点：宋朱、四因、與興 送审 ≤2）。
- 不强行共享切分器、不按部件建池（攵 池 无增益；徵徴 的攵 不同）。

## 七、首轮结果（2026-10-22 晚）

**数据底座**：`research/m7/bench/export_crops.py`。数据集 unified 里 2549 个人裁刻形格，有图 2166 张：数据集原有 1165、中心库锚点字块 709、原图按锚点裁 292；缺 383（无锚点）。
字块图暂放本机，进数据集前先给 sheldon 过目。另可并入中心库字形库 human 实例（`--glyph-store`），只多出很少几组的样本。

**判别台 v0**：`research/m7/bench/bench.py`（嵌套按册留出，全组一遍约 1 分钟）。两形各 ≥8 张带图的只有 17 组（并入字形库后 22 组）。

| 组 | 判别台（诚实留出） | 说明 |
|---|---|---|
| 厯歴 | 122 对/1 错/3 弃 | 自己选中下半框，与手调相同 |
| 叙敘、參㕘（不含叅）、啓啟 | 100% 0 错 | |
| 日目 | 39/1/0 | 只用字形就很强，可当文意第二路 |
| 教敎 92%、絕絶 85%、呂吕 88%、扺抵 85%、衛衞 82%、徵徴 46–63% | 都有 2–9 错 | 判别台自己选的整字/取框配置；线上 教敎 絕絶 是 IDS 通用判法，另核 |
| 己已巳 日曰 大太 一二 入人八 未末 曾會 宋朱未 | 7%–76%，错多 | 文意组，字形单独不够，只能当第二路 |

**线上配置复核**（`check_prod.py`：配置固定为线上的，只看门槛）：
- 厯歴 啓啟 刪删 扺抵 旨㫖：线上门槛下 0 错；嵌套门槛也 0 错。
- 衛衞：线上 0.7 下 0 错，但错例最大 0.55（全在 vol09，衞 按册集中）；嵌套门槛会错 7 格。殿本内可维持，**换书要重定门槛**。
- 呂吕：vol02:125:8:4（标 呂，判 吕 0.976）；徵徴：vol01:70:7:10（标 徵，判 徴 0.775）。两格都不在线上模板库里（当初人裁不一致被剔），待 sheldon 判：标注对就要抬门槛（呂吕 1.0：65→26；徵徴 0.8：37→29）。
- 教敎、叙敘（IDS 通用判法，`ids_online.evaluate_generic` 按册 10 折）：不设门槛也 0 错。絕絶（U-Net，10 折）：线上门槛 0.05 下 26 对/13 弃/0 错；唯一错例 vol07:107:6:15 margin 0.031，在门槛下。

**结论修正**：
1. 13 个只有字频的异体组在殿本里本来就只有一形（爲 有、為 无），字形路无从训练也不需要；通用做法是**每本书自动建字频表**，新书只确认「是不是单形」。
2. 文意组字形单独不够，判别台只当第二路（`agree`），需要每形 ~20 张人裁才训得动——这是要 sheldon 标的主体。
3. 门槛一律用嵌套留出定；按册集中的字形（衛衞）报警。

## 八、第二轮：文意组加字形第二路的试算（2026-10-22 晚）——结论：暂不上线

**数据**：文意组补标 574 格＋复看更正（数据集 2d3de70，中心库 rev 92635）；象𧰼 补标 80 格（ce983e9）。

**字块取法要和线上一样**：首轮用的字块图混了三种来源（数据集自带、中心库锚点、原图按框裁），到已放行格上一跑，
論→諭 这种一眼可辨的字也会以 1.0 以上的判别值判错。改用线上同款字块（`char_patch`，进程内 `RunContext.materialize`，
同 `guji product patch`；vol02／03 没有产物，这两册的人裁格不进）重跑判别台（`bench.py --only-crops`）：
而面 53%→91%、未末 土士 王玉 甲申 曾會 目自 100%、一二 95%；傅傳 仍只有 37%。

**线上试算**（`ctx_glyph.py`：判别台选的配置＋线上同一打分器 `ids_whole.score_norm`，按册留一定 0 错门槛；
vol04–10 已放行、未人裁的 1.8 万格）：字形与放行字不同的格各组 0–43 格，**逐格看图读上下文，几乎全是字形错判**
（論 自 圖 士 間 的字块带邻格碎墨、框歪，按墨迹外框归一后整体变形），放行字是对的。
同时 vol04–10 里文意弃权、在送审的字组格只有约 100 格（己已巳、日曰 占 35），而且多是怪形（象彖 的 7 格里 6 格是 𧰼）。

所以：
1. 字形第二路当「复核守门」：按现在的门槛每册会多出几十格无谓送审，抬到不误降的门槛又几乎不触发——**不上线**。
2. 当「文意弃权时补位」：可补的格太少，且正是最难的那批——**不上线**，这批格继续人审（字组弃权格线程在做）。
3. 判别台、线上同款字块、按组配置留作离线复查工具：新书人裁攒够后重跑，或给文意表做抽查。

**象／𧰼**：𧰼 共 13 格人裁（vol05 8、vol06 3、vol04 2），在已放行「象」里约占 1.5%。按册留出时机器一格 𧰼 也认不出
（集中在 vol05，留出 vol05 时训练只剩 5 格）；只能做到「很像象才给象」（门槛 1.05，覆盖约三成象、0 错），
而卡在形判的格多半本来就是 𧰼——收益太小，**不上线**，𧰼 一律人审。攒到每形 20 格（规矩）再议。
