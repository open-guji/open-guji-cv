## 一、先判是哪一类

刻本上认不成「字」的东西，按下表分流。**只有最后两行归本文管**，前面几行照原来的流程走。

| 看到的 | 例子 | 归哪 | 怎么记 |
|---|---|---|---|
| 有 Unicode 码位的符号 | ○ ◎ ● □ △ ╳ ⊙ | 定字 | 照常定成字，`c` 写这个符号 |
| 汉字，但 Unicode 没收 | 缺笔字、生僻异体 | 定字 | `c` 写近似字，`zi` 记 IDS（原形） |
| 看不清、残缺、遮挡的字 | 虫蛀、墨污 | 阙文 | `c` 写 □，带 `lacuna` |
| 印章 | 藏书印 | 非正文 | cord `marks` 的 `seal`；第一版阅读器不显示 |
| **在字流里占一格（或连几格）的图形，根本不是字** | 册 005 第 148 叶 2 列 14 格「圖作▢形」：左边半圈，中间一横，右边一个实点 | **图片格** | char 格上加 `fig`，`c` 写 □，**不带** `lacuna` |
| **占若干列、半页或整页的插图** | 卦图、地图、算图、表格图 | **插图块** | char 里加一项 `kind: figure` 的「图列」；cord `marks` 加 `kind: figure` |

判准：

- **先看能不能写成字**。有码位就定字，是汉字就写近似字加 IDS。图片格只给「根本不是字」的图形。
- **看不清不是图**。看不清的字仍是阙文；「是图形」只能用在看得清、确实不是字的格上。认不出的生僻字不许标成图。
- **拿不准就进请审单**，跟其他请审格一样攒着一次问。

## 二、数据长什么样（摘要）

图片格（char）：

```json
{"a": "148:2:14", "c": "□", "fig": "f148-2-14"}
```

插图块（char 的 `columns[]` 里按读序插一项，不含格）：

```json
{"col": 2, "kind": "figure", "span": 4, "fig": "p149-fig1", "cells": []}
```

插图块（cord 的 `marks[]`）：

```json
{"kind": "figure", "fig": "p149-fig1", "col": 2, "span": 4, "box": [900, 330, 880, 2450]}
```

每章另有一个 `NNN.fig.json`，一张图一项：id、kind（inline／block）、页、框、说明 `alt`、文件路径、sha256、mime、宽高、来源（`crop` 裁图／`redraw` 重绘）。图片文件放 book-text 的 `<版本目录>/fig/NNN/<图 id>.png|webp|svg`，和文本一起走 PR。

要点：

- 图片格的 `c` 一律写 □，校验字也是 □，标点、专名、校勘照常锚格位。不认识 `fig` 的旧工具只会显示成方框，不会出错。
- 图 id 和格位无关：重切以后格号变了，id 不变，只改 char 里引用它的格。建议写法：图片格 `f<页>-<列>-<格>`，插图块 `p<页>-fig<n>`。
- norm 里不许有图片格（图没有通行字）。
- 章的 `index.json` 用 `fig_file` 声明本章有图；char 里有图却没声明，F-OV-13 会拦。

## 三、流程

```
精校页／控制台：人定「这格是图形」，或在控制台画插图框，并写一句说明
        │  网站票 choice=figure（图片格）／控制台页级覆盖 figure_region（插图块）
        ▼
cv：人裁事件（新种类 figure、新覆盖事件 figure_region）
        │  guji db sync（推中心库，等 Sheldon 说「推库」）
        ▼
cv 导出（S17，export_guji_format.py）
        │  图片格：char 写 c=□＋fig；cord 不变
        │  插图块：char 写图列；cord 写 marks.figure
        │  裁图：取 R2 页图全分辨率，按框外扩 2 像素裁，写 fig/NNN/*；生成 NNN.fig.json
        ▼
book-text PR（导出结果＋图片文件），文本线升版；F-OV-13 校验
        ▼
网站发布 → 阅读器显示图，复制得到〔图：说明〕
```

### 3.1 怎么定「这是图」

- **一律走人裁事件**，不在 book-text 里手改 char（runbook 四·五「两条硬规矩」第 1 条）。
- 图片格：精校页卡片选「是图形，不是字」，填一句说明（可空，空时导出写「图形符号」）。
- 插图块：第一版没有自动检测，在控制台对该页手工画框，写说明。
- 说明 `alt` 要写人话：读屏、悬停、复制都用它。写形状，不要写「图片」「图形」这种空话。例：「左半圈连一实点」「河圖」。
- `figure` 人裁和别的人裁一样锚页号加框，重切后按框重叠自动改绑（设计 15）。第一版进团队单复核，不自动放行。

### 3.2 导出

- 导出器根据人裁写 char、cord、fig.json，并从页图裁图：图片格存 PNG，插图块存 WebP（q90，长边超过 2000 像素先缩）。不去底、不二值化，保持书影原貌，读者端按主题调色。
- 单个文件不超过 1 MB。
- 再次导出时，**保留**已有的 `source: redraw` 条目（人工重绘的 SVG），不用裁图覆盖。

### 3.3 换成重绘图

裁图太小、放大发糊时，可以人工画一张 SVG 替换。直接开 book-text PR 改文件和 fig.json 的 `file`、`source: redraw`、`sha256`、`mime`，不经 cv，不升文本版本。SVG 只许图形元素，颜色写 `currentColor`，不许脚本、外链和内嵌位图（F-OV-13 会拦）。

### 3.4 1.0 之后发现的图

按 runbook S25 的「B □↔字」走：写人裁事件、推库、在冻结 worktree 上重跑该页、重导出、文本升 patch、重新冻结。
