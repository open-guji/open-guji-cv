# 模型系统

2026-11-04 起。总体构想（用户定）：字形、语料、模型是三个独立系统，每个对象分 global／group／book／volume／page 五层，
册配置记三个系统的总号，任一子项变了总号 +1；大文件按 hash 进 R2，三系统尽快从 cv 剥离、更新与 cv 版本无关。
三系统总设计稿见 Claude Doc「三系统存放设计」；模型现状调研见 Claude Doc「训练好的模型总览」。本文只写模型系统。

## 一、已定

1. global／group 的源文本先放中心库（不另开 git 资源仓），以后再看。
2. 模型归哪层**按从哪里来**：在哪本书的数据上训的就归哪本书；合成数据、公开数据训的归 global；多书混合又没有共同组的归 global、在卡上记出处。
3. group 分法另行拍板（武英殿刻本与文渊阁写本必须分开）。

## 二、模型卡（`model/1`）

每个模型文件一张卡：

| 字段 | 说明 |
|---|---|
| `kind` | 种类，见 `core/model_pack.KINDS`（glyph_cnn、partition_unet、pagetype、shadow_gate、rr_clf、l2_head、rr_shape、pair_shape、book_knn、ids_model） |
| `root`／`path` | 现在的位置：`repo`＝cv 仓，`data`＝本书数据目录（中心库同步） |
| `size`／`sha256` | 内容 |
| `level`／`owner` | 归哪层、归谁（global／书 ID／组名） |
| `consumers` | 读它的 Step |

外部模型（SikuRoBERTa）不在本机文件里，按 revision 钉，放清单的 `external` 段。

|---|---|---|---|
| glyph_cnn r4/r5、pagetype、rr_clf | book | 殿本 96mid1ogzk | 殿本人裁／标注训的 |
| partition_unet_v2 | global | global | 合成对训练 |

## 三、总号与钉住（一期，已实现）

- `guji model build -w <工作区>`：扫出本书现在用的全部模型，写 `config/model-pack/m<N>/manifest.json`（数据目录，`guji db push` 进中心库）。
  内容和最新一版一样不出新号；清单只写一次。
- 册 yaml 写 `model: N`（或 `m3`）钉住。也可经 `--override '{"model": N}'`／任务单 `book_overrides` 临时叠。
- 钉了之后：
  1. 读模型的 Step（`MODEL_STEPS`）起跑前校验清单，文件改了或缺了拒跑；`GUJI_MODEL_DRIFT=warn` 临时放行。
  2. **补缺口**：册同时钉了 `corpus:` 时，`seed_admit.group_flow_fingerprint` 从 `corpus-…` 变成 `corpus-…+model-…`，
     L2 小头、rr_clf、rr_shape、book_knn、IDS 模型换了，这册判过期。此前这些变化被语料钉号整段吞掉，换了模型不过期也不拒跑。
- 不写 `model:` 的册，所有指纹逐位不变（opt-in）。各 Step 的 `model_fingerprint`／`pagetype_model_fingerprint`／`shadow_model_fingerprint` 本来就按内容哈希，不动。
- 其他命令：`guji model ls`（列卡）、`verify`、`list`。

**影响**：L0。没有册写 `model:`，现有产物一个不过期。给殿本、史記写上 `model:` 那一刻，它们的 seed_admit 指纹会变（一次性过期），
所以写之前要拍板，最好和下一轮语料改钉一起做。

## 四、二期

### 4.1 进 R2、按 hash 取回（已实现，2026-11-04）

- `guji model upload -w <工作区> [--version N] --execute`：清单里每个文件按 sha256 传进 R2，键 `sha256/<前两位>/<sha>.txt`（与语料大文件同一套），已有的跳过；本机文件 sha 与清单不符拒传。
- `guji model fetch -w <工作区> [--version N]`：本机缺的文件从 R2 取回，**放回清单登记的位置**（cv 仓 `models/…`、数据目录 `config/groups/…`）；已有但内容不同的不覆盖，报出来，之后起跑前校验拒跑。读令牌就够。
- `guji pipeline` 起跑前：册钉了 `model:` 且清单里有缺的文件，自动取回（`ops/prep.ensure_model_pin`）。
- 取回放回原位，所以各 Step 读模型的路径、代码、`code_hash`、指纹一概不变。这是有意的：改 `cut_select`、`shadow/model` 这些模块会让各书过期。
- 11-04 已传：史記 m1（16 个文件）、殿本 m1（14 个文件，与史記共用的 12 个已在），共约 54 MB。
