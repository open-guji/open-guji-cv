## 1. 交接闸：每步出口的质检机制【规划】

### 1.1 为什么闸不是一步

`column_gate` 现在被写成管线里的第三步，这不对：它不产出新的内容，只判定 Step2 的输出**够不够格进 Step3**。
把它当步骤有两个坏处：DAG 里混进了非生产节点；其他步骤没有对应物，出口质量无人把关，
**上游连坐只能在下游表现成一堆看不出根因的失败**（Step3 那轮量到的最大瓶颈不是 Step3 自己，
而是 13/40 页 Step1 没切对列，Step3 拿到的根本不是一列，逐格全对率 27/29 掉到 8/21）。

**新划分：闸是每个 Step 的出口属性，不是独立节点。**

### 1.2 闸的统一形态

每个 Step 声明一个 `gate`，产出 `gate_manifest`：

```python
class GateSpec(BaseModel):
    unit: Literal["page", "column", "cell"]   # 判定粒度
    levels: list[GateLevel]                   # 分层判据，从便宜到贵
    on_fail: Literal["block", "flag", "degrade"]  # 拦住 / 只打标记 / 降级走备用路径

class GateColumn(BaseModel):     # 每个单位一条
    key: str
    passed: bool
    level: str | None            # 没过是栽在哪一层
    reason: str | None
    metrics: dict[str, float]    # 判据量到的数，供事后标定阈值
```

**四条设计纪律**（都是从 `column_gate` 踩出来的）：

1. **判定粒度要对**。列宽异常原先放在页级，一列坏整页作废（vol01/42 八列完好只因 c9 坏而全废；
   vol02 全书 27 页被拦、其中 17 页只坏 c1）。2026-09-03 改列级后，vol02 页过闸 84.6% → **98.9%**、
   可用列 +193（+13.5%）。**整页性的问题才放页级。**
2. **分层，从便宜到贵**：L1 几何（列数对不对）→ L2 信号（两侧墨）→ L3 人裁金标。
   L3 只在需要高纯度样本时开（`tier=gold`）。
3. **闸的阈值必须拿分布标定，不能拍**。L1c 容差 ±15%/±35% 来自 2,655 列实测
   （真错切 +66～89%，多吃一个外框封顶 +30.3%，容差卡在两族中间）；L2 从 0.012 放到 0.045
   是因为旧值误杀 11.1% 的 clean 列只为捞回约 10 条坏列。
4. **闸拦下的东西要有出路**，不能只是消失：`on_fail=block` 的单位必须落进「待处理」清单
   （现在 vol01 p90–132 那 41 页职名页就是整页被拦、且**没有任何清单在跟踪它们**）。

### 1.3 八道闸的设计

| 闸 | 粒度 | 判据 | 现状 |
|---|---|---|---|
| **闸0** 预清理出口 | 页 | 反色带修复后带内墨占比回落到正文本底量级；未登记页直接过 | 【规划】现在是人工确认后写 yaml，无自动闸 |
| **闸1** 边框出口 | 页 / 列 | 探出列数 = 版式列数；界行 w80 不超阈；上下版框墨占比够（没印上的页标 `none` 不报数）；抬头框距离落 90～210 px | 【规划】判据都已存在（散在 `border_geometry` 与尺子里），未收成闸 |
| **闸2** 单列射影出口 | 列 | L1 页级列数 + L1c 列宽 ±15%/±35% + L2 `side_floor ≤0.045` + L3 人裁 | **【现状】已实现**（`steps/column_gate.py` v1.3），是唯一一道 |
| **闸3** 逐字切分出口 | 列 / 格 | DP 有解；格数 = 版式格数（或 `effective_body_slots` 下调一格）；R2 可改善格线为 0；穿墨格线标 flag 不算错 | 【规划】R1/R2/R2s/R2x 尺子已有，未做成闸 |
| **闸4** 字框收缩出口 | 格 | 紧框外残墨 <20 px（R4）；`flags` 里 truncated / contaminated / frame_bars 标出；空白格不进下游 | 【规划】flags 已有，未做成闸 |
| **闸5** 证据收集出口 | 格 | 四路各自的可用性：库有无候选、OCR 引擎在不在、整理本锚上没有、生僻字索引热了没；**任一路缺席只降级不阻塞** | 【规划】现在是各 Step 自己 `needs=(...)` 标 blocked |
| **闸6** 上下文裁决出口 | 格 / 列 | `glyph_layer_immutability` 硬断言（候选外的字一律无效）；margin 不足则弃权（弃权不是错但要计数） | 【现状】断言已在，未做成闸 |
| **闸7** 放行判定出口 | 格 | 判据 A：自动放行的字对双真值零错；错一条即停整批 | 【现状】判据已有（`round_check.py`），未做成闸 |
| **闸8** 落库出口 | 实例 | 进库前查排除名单、查重、`provenance` 分级；改判必须走撤库+重放不能直接覆盖 | 【现状】纪律已有，散在 `glyph_db.py` |

### 1.4 落地方式

- `StepSpec` 加可选 `gate: GateSpec`；`Step.run` 之后由框架统一跑闸、落 `gate_manifest` 产物。
- 控制台总览的状态矩阵每格加闸的通过率（现在只有新鲜/过期/缺失/失败/阻塞五态）。
- 闸的 `metrics` 全部入产物，用来事后标定阈值——**这是把「拍阈值」变成「量阈值」的基础设施**。
- `column_gate` 从 `steps/` 移到 `gates/`，管线 yaml 里不再出现它。

## 3. 切分线（Step0–4）

### Step0 预清理 `preclean`（页级，按需）

| | |
|---|---|
| 功能 | 修复扫描件局部缺陷（反色带等），原图永不改写 |
| 输入 | 原图 + `books/<book>.yaml` 的 `preclean:` 段（人工确认；`scripts/scan_inverted_bands.py` 只给候选） |
| 输出 | `precleaned/<book>/<page>.png`（显式产物、不是缓存、不被 LRU 清）；`raw_page` 优先读它 |
| 代码 | `utils/preclean.py`、`cli_v2 preclean` |
| 方法 | 反色带不是墨污——抹除法会连笔画抹掉；正解是圈出边界后区内整体反转。边界是多段梯形，逐列用「列间纸列」量出，不写死 y |
| 出口闸0 | 【规划】带内墨占比回落到正文本底量级 |

### Step1 边框与界行探测 `border_detect`（页级）

| | |
|---|---|
| 功能 | 找上下版框、外框、每条界行（三段折线）、抬头框 |
| 输入 | **最原始扫描图**（不用 v1 的 s3 裁剪 / s4 直线增强产物，那会把边框挪最多 96.6 px）、`expected_cols=9` |
| 输出 | `borders`：`top/bottom{slope,y_at_right}`、`verticals[{x_at_top,slope,k2,k3,y1,y2,segments}]`（整页要么全直线要么全三段）、`verticals_straight`（拟合前直线，量「改前」必须用它）、外框偏移、`head_raise[]`、`bend_w80_med/max`。每页约 2 KB，只存线不存像素 |
| 代码 | `steps/border_detect.py` → `utils/peak_line_search.py`、`utils/border_geometry.py` |
| 方法 | 纯 numpy 无 cv2；半高宽匹配度（每点用自身值为基准，`alpha=0.5`、`hyst=3`，界行比值 200～500 vs 正文列个位数）；位置+角度联合搜索（范围可窄步长必须细）；三段折线直接搜四折点、三角核打分、行过滤局部一致性闸；两翼近零闸 `FLANK_MAX_RATIO=0.35` + 采样窗口垫边 `SEARCH_PAD=60`；`_snap_to_inner_rule` 粗外条→细内框；折线护栏 `PAIR_WIDTH_TOL=0.25`；抬头框 `HR_DIST_MIN/MAX=90/210`（**从 13 个样本量出，换书必须重标**） |
| 出口闸1 | 【规划】列数、w80、版框墨、抬头框距离 |

### Step2 单列射影与清版 `column_warp`（列级）

| | |
|---|---|
| 功能 | 沿界行把每列射影成竖直列图，去噪，清两侧界行残墨与上下版框 |
| 输入 | `raw_page` + `borders` |
| 输出 | `column_windows`（窗口左右边线、折线段、`content_x`）+ 列图（**抹白不裁切**——列图坐标系是 Step3/4 与金标共用的锚；image_cache 秒级再生）；页级 `period` / `ref_w`；`border_top/bottom` 在列图坐标的位置 |
| 代码 | `steps/column_warp.py`、`steps/_warpmap.py`（列图坐标逆映射回原图）→ `utils/column_projection.py` |
| 方法 | 射影矫正 `out_w=max(顶宽,底宽)`（不压扁，两条证据已验）；折线页分带射影共用 `out_w` 竖向拼接；`column_text_band` 从两端吃「界行本体 ≥0.35 + 裙边 ≥0.12」限 15% 宽，补内缩档；`strip_column_rules` 分横条（240 行）做；`column_border_trim` 上下版框 a/b/c/d 四档（厚度 30 行、起始陡度、内缩档最低墨 0.15 三把尺子全拿金标标定）；清理顺序固化：先定带 → 抹侧 → 只在带内算投影 → 削上下 |
| **出口闸2** | **【现状】唯一已实现的闸**（`steps/column_gate.py`）：L1 页级列数 / L1c 列宽 ±15%（最外列 ±35%）/ L2 `side_floor ≤0.045` / L3 人裁金标。页级共识量只用几何正常列算，正常列不足半数整页拒绝 |

### Step3 逐字切分 `row_segment`（列级）

| | |
|---|---|
| 功能 | 一列切成 21 个带类型的字格（正文 / 空白 / 夹注 a·b），给读序；粘连处另求折线缝 |
| 输入 | 列图 + 页级 `period` + `n_body_slots=21` + `n_raised` + `content_x` + `border_top/bottom` + `top_slack` + `seam_band=20` |
| 输出 | `cells[{slot,sub,y0,y1,x0,x1,kind,order,gap_center,ink_ratio,raised,seam_top/bottom}]`。`kind ∈ {char, blank, jiazhu_a, jiazhu_b}`；`raised` 是几何标记不是 kind；抬头多出的格 `slot` 取负数（跳过 0），保证同 `n_body_slots` 下任意两列 slot k 是同一条物理格线；**粗框不裁紧**（裁紧是 Step4 的事，夹注判据必须在裁紧前的框上量） |
| 代码 | `steps/row_segment.py` → `utils/row_boundaries.py::segment_column`（弹性 DP）、`utils/seam.py`、`utils/jiazhu_split.py`、`utils/jiazhu_order.py` |
| 方法 | 弹性 DP：候选 = 墨谷（`find_valleys` + `_snap_to_raw_minimum` ±3 px 吸回原始极小）；三层硬约束（`lo/hi_ratio` [0.7,1.5]、首尾 padding、`lam` 软惩罚拉回页级 `period`）；代价项 `blank_cost_full=0.01` / 碎空白 0.05 / `drop_lam=0.3` 锚点外丢墨 / `mass_lam=1.0` 矮格墨满 / `LOW_INK_FRAC=0.12` 低墨补点（`lam4` 默认关）；`effective_body_slots` 版框只装 20 格时按 20 切；抬头列 `top_slack` 开到列图顶端；**折线缝**（走廊 ±20、转折罚 0.02/px、缝墨 >3 才放宽到 ±40，只对 char–char 穿墨格线求） |
| 夹注 | 探测纯几何（`jiazhu_split`：尺子必须是页级列距 `span/ref_w ≥0.75`、缝落墨迹中段 30～70%、列上下文 `MIN_RUN=2` + `ALIGN=8`、噪点段 maxCC<500 否决、段端收编 b 侧 maxCC ≥250 分型）；**界行必须先剥**（`wall_ink_frac=0.25`、`wall_pad=3`，否则整列 span 顶满全列像夹注）；文字先验只在册级 yaml |
| 出口闸3 | 【规划】DP 有解、格数对、R2 可改善为 0、穿墨标 flag |

|---|---|
| 功能 | 每格内收出紧贴字身的框，打 flags |
| 输入 | `cells` + 列图 + Step2 的 `border_top/bottom` 提示 + 缝 |
| 输出 | `char_index`（紧框 bbox + flags：truncated / contaminated / boundary_ink / frame_bars…）+ `char_patch`（image_cache） |

| 出口闸4 | 【规划】R4 残墨 <20 px、flags 标出、空白格挡住 |

## 4. Step5 字符识别（四路并行，原"逐字证据收集"）

> 用户 2026-09-11 控制台重构 v2 反馈定名："字符识别"——UI 与技术设计文档统一叫法。
> 技术本质不变：四路只出候选、互不投票，见下。

**这一步的定位**：给每个字位收集**互相独立的证据**，四路都只出候选与证据，**没有一路能单独定字**。
下一步（Step6）融合，再下一步（Step7）判定放没放行。

**四路必须误差独立**（`glyph_db_first_design.md` §7.3，529 条人审难例回放）：

| 两信号一致时 | n | 准确率 | 能否当双信号 |
|---|---|---|---|
| OCR × 整理本 | 118 | **100%** | 可 |
| 整理本 × 库 top | 144 | **100%** | 可 |
| **OCR × 库 top** | 138 | **97.1%** | **不可**（4 条同错：已/巳、人/入、日/曰、今/全，共同盲区） |
| 三者全一致 | 49 | 100% | 可 |

## 5. Step6 上下文裁决 `context_decide`（列级）

> **本次调整**：这一步的定位明确为「**汇集一切上下文信息**」——同列前文、
> n-gram、混合语言模型、形近字表、夹注短语词表，以及**将来接入的大模型 API**，
> 全部算这一步。它的输出是 ranked 候选 + margin，**不做最终放行决定**（那是 Step7）。

| | |
|---|---|
| 功能 | 把 Step5 四路证据 + 上下文融合成排序与 margin；形近对（人/入、日/曰、諭/論、曾/會）的主判据 |
| 输入 | 四路候选 + 本书 3-gram + 通用 LM + 同列前文 + 形近家族表 + 夹注短语词表 |
| 输出 | `context_decide`：ranked 候选 + `margin`（softmax p1−p2）+ `used_context` + 采用的策略名 |
| 代码 | `steps/context_decide.py` → `clustering/context_step.py`（**策略注册表**，加新信息源就是加一个策略）、`context_rank.py`、`lm.py`、`confusable.py`、`note_lexicon.py`、`vlm_assist.py` |

**已接入的上下文源**

| 源 | 做法 | 实测 |
|---|---|---|
| 本书 3-gram | `CharNgramLM`，权重 0.9 | — |
| 通用语料 LM | 500 万字，权重 0.1；**线性插值不是对数线性**（后者任一分量近零就把结果拖零，而通用语料没收录的本书专名恰好是这一类） | 混合 +2.14% 优于纯本书 +1.71% 与纯通用 +1.21% |
| 候选融合 | 库 3.0 / 语料 2.5 / OCR 1.5 / 字体 0.6，按检索名次衰减；`LAMBDA=0.65` 配比 OCR 与 LM | λ 是有害翻转主开关，0.35 起 LM 开始编字 |
| 形近字家族 | `confusable.py` + 手工/字体/人裁三张表 | 154 题：n-gram 95.5% |
| 夹注短语 | `note_lexicon` 段级闭集通道（词表从语料派生永不手编，段格数 = 短语长度硬约束） | 实际只接住 1 格，是兜底不是主力 |

**待接入：大模型 API**【规划】

- 位置：`context_step.STRATEGIES` 加 `llm` 策略，与现有 n-gram 策略同接口。
- **门槛化不变**：只在候选内选、`margin ≥ 0.70` 才采信、不做全局重排。
- 依据：`confusable-context` 154 题盲测大模型 **98.7%**（n-gram 95.5%、字形层 64.3% 低于多数类基线 76.0%、OCR 66.2%）；論/諭 OCR 系统性认反 11% 而大模型 100%。
- 护栏：`harmful_flip_rate ≤1.2%`；`glyph_layer_immutability` 硬断言（引入候选外的字即判本次评测无效）；语料挖洞纪律照旧。

**关键纪律**：门槛化是 LM 的唯一正确用法——先验变强之后，**无门槛全局重排在任何 λ 下净亏**（λ 0.10～0.95 全扫）。
出口闸6【规划】：断言 + 弃权计数。

**落库纪律**（每条都有案底）

1. **字形与释读分开存**：`shape` → `instances.label` / `glyphs` / `exemplars` / `unicode_cp`（字形索引）；
   `reading` → `admissions.char` / `instances.semantic`。**整理本字永远不覆盖 `char`。**

2. **改判必须走「撤库 + 重放」**：`admit_instance` 的幂等闸是防重复入库的，**不是改判入口**（这个坑咬过三次）。

3. **provenance 分级**：`human` > `context` > `align` > `match`；完美匹配只继承不提升。
4. **逐实例证据，不做盲传播**（起因：94 个「人工」标签全是簇级传播，逐张复核 11.7% 是错的）。

6. **金标记的是「当前切得怎么样」，不是「历史上出过什么问题」**：缺陷修好后要复量改回 `clean`，历史留在 `source_events`。
