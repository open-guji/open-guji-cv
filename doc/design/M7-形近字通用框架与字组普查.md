# M7 形近字：三条路的通用框架与字组普查

> 2026-10-18，Emerson。承接 [解法模式与扩展](M7-形近字解法模式与扩展.md)、[量横画法](M7-字形量横画法-土士未末.md)、[IDS 路扩展](M7-IDS路-扩展与训练增长.md)。
> 只写文档与一个统计脚本（`research/m7/census/group_census.py`，不在任何 Step 的 `code_deps` 里），19 步 `code_hash` 不变。数字来自工作区已有人裁/校勘事件、dataset 的 `ref-mismatch`、`confusable-context`、`char-groups`，**没有重标、没有跑模型**。

## 一、结论

1. 三条路不是三套算法，是**同一个「证据 → 二选一 → 弃权」骨架**配三种信号：部件（IDS）、文意（上下文）、笔画量（量横）。选哪条看「两个字的差别落在哪」，不看字长得多像。
2. 组合原则：**各路独立给证据，只有「给字」才算数；一致放行，只一路给字按该路自己的验收线放行，不一致维持现状抬人审并留痕。**弃权永远安全。
3. 普查（§四）里**真正有量的形近不同义组**，除已做的己已巳、日曰、入人八、土士、未末外，下一批最值得做的是 **论諭、大太、問間、曾會、遺還**；异体里大头（變𠮓、㫖旨、即卽、卿𨜊、蒙𫎇、隸𨽾）**不需要判别器**，只要「刻形＝系统码位」登记（`variant_tie`），真需要 IDS 的只有彝组和參㕘叅（已做）。

## 二、通用框架

### 2.1 一个字组由什么决定走哪条路

先问三个问题，按序：

| 问 | 是 | 否 |
|---|---|---|
| Q1 两字是**同一字的异体**吗？ | 目标是忠于刻形（口径 A）。刻形本身就有码位且码位唯一 → **不需要判别器**，登记 `variant_tie`（慎愼群羣點㸃、㫖旨、蒙𫎇、隸𨽾）。码位不唯一、几个写法要从图上分 → **IDS 路**（彝六字形、參㕘叅） | Q2 |
| Q2 文意能判吗（干支、虚词、书名、固定搭配有强词组）？ | **上下文路**，字形只作护栏 | Q3 |
| Q3 字形上有**单一可量的几何量**（两横哪条长、有无一点、出不出头）？ | **量笔画路**（目前只验证了土士、未末） | 只能弃权，送人审或按字形归组（块 B，未做） |

Q2、Q3 常常同时为真（土士、未末），这时两路都开，见 2.3。

> 口径冲突要写明：**异体按刻形定字，形近不同义按文意定字**。土士里「刻形是末、文意定未」的格，量横给「末」是对刻形的如实描述，但组的口径是文意，所以不能让量横单独推翻文意。

### 2.2 三条路对照

| | IDS 路 | 上下文路 | 量笔画路 |
|---|---|---|---|
| 适用字组特征 | 同字异体，顶层结构相同，差别在 1～2 个**可命名部件** | 字义不同、写法混用，有**强词组/语法** | 同部件同结构，差别是**一笔的长短/有无**，IDS 拆不出来 |
| 例 | 彝𢑴、參㕘叅 | 己已巳、日曰、入人八、論諭、大太 | 土士、未末 |
| 信号 | 折线切段 → 每段与真实刻例模板比 | 前后各 20 字：L1 规则 → L2 haiku 答案表 | 字块图二值化 → 取最长两横 → 比值 r＝下横/上横 |
| 证据形式 | `slots`＋每段 `margin`＋IDS 反查字＋`nearest_variant` 旗 | L1 命中规则/词组；haiku `conf`（只收 high） | `ratio` 与弃权带（土士不弃权，未末 [0.85,1.15]） |
| 弃权条件 | 任一段 margin < 0.02 | L1 与否决冲突；窗口哈希对不上；haiku 非 high；字外格 | 比值落入弃权带；横画断成多截/缺损 |
| 需要的人工 | 切线（约一半，其余预画待采纳） | 复审不一致与低置信格 | 无训练；只要人裁几格验边界 |
| 最怕 | 细笔画（彑/彐）、模板样例少的类 | 窗口取错（夹注读序）、字外格被硬判、金标本身错 | 横画缺损被量错 |
| 验收线 | 给字格放错 0，整格 ≥95% | L1 零错；合并后给字 Wilson 下界 ≥97% | 强真值给字零错（未达则只当旁证） |
| 现状 | 证据已出，未接放行 | `seed_admit.m7_groups` 缺省关，vol04 A/B 过 | `m7_bars` 缺省关，vol04 A/B 过 |

三路共同点（接新字组时每一路都要有）：**缺省关**；成员与解法登记在注册表（`GroupSpec`，`solvers` 是有序列表）；证据写成 `group_clf/1` 风格的「给字/弃权＋原因」；验收口径含「组外格逐格不变」。

### 2.3 组合与弃权

| 情形 | 处理 | 依据 |
|---|---|---|
| 一路给字，另一路弃权 | 按给字那路**自己的验收线**放行（量横只在文意弃权时补位，标 `bars_only` 旗） | vol04 A/B：土 1 格由弃权转放行 |
| 两路给字且一致 | 放行，置信最高 | 两路错误来源不同（文意 vs 字形），一致才放行 |
| 两路给字但不一致 | **不改 A 结果，抬人审，留 `bars_conflict` 证据** | 复核 5 格里 3 格是「刻形与文意相反」，2 格是量错；谁也不能单独推翻 |
| 两路都弃权 | 维持现状（送审） | |
| 字外格（口目白田巴等） | 上下文路不单独放行，要「等于整理本字」才可抬；归组靠字形（块 B） | 日曰 12 个字外格 haiku 硬判 5 个 |

### 2.4 接新字组的统一清单
1. 查 `char-groups` 与 `feedback/events` 里已有标注，**复用不重标**。
2. 按 2.1 三问定路；写进注册表 `GroupSpec`，配置放 `config/groups/<组>/`。
3. 量格数（core 格、强真值数）；强真值不够 130 格就只当 starter，下界到不了 97% 不是准确率问题。
4. 只出证据，缺省关；`guji exp` 单项 A/B（组外格 0 差异）；PR 报告 `seed_admit` 的 `code_hash` 变化。
5. 人工只审：路间不一致、与金标不符、低置信；不抽查。

### 2.5 还没验证的第四种信号（候选，**只是假设**）
- 量**点有无/位置**：大太（太多一点）、玉王、犬太。
- 量**竖出头/不出头**：午牛、干千。
- 这些都要先在字块图上用土士的办法（二值化 → 取部件 → 比值）做 30 格以内的探针，看 AUC，再决定是否值得登记。量横的经验：首版因量长方法错得出「不可用」的错结论，**先和肉眼核对再下结论**。

## 三、方法与口径说明（读表前必看）

- 「事件条数」＝人裁/校勘中**被人看过、涉及该字对**的次数：`collate`（OCR 与整理本不一致并裁过）、`shape≠reading`（刻形与读法不同）、`pairflag`、`ref-mismatch`、`confusable-ctx`。**偏向难例，不等于全书总数**，只用来排序。`confusable-ctx` 是设计题，大太、論諭、而面、問間等主要来自它，反映「已被识别为难」，不是自然频率。
- 「字频」＝殿本整理本（工作区 `corpus/zongmu_wuyingdian_reference.txt`，345,597 字）里该字出现次数。整理本已规范化，异体写法常为 0（如 卽、㫖），这表示整理本不用此形，不表示书里没有。
- 真实格数只有这几组有：己已巳 651、日曰 1395、入人八 2405（`char-groups` core，vol02–10）；參㕘叅 197、群羣 44、點㸃 29、慎愼 33（`m7-ids2` 格数）。其余无格数，字频只是上限。
- 复跑：`python research/m7/census/group_census.py <工作区> <open-guji-dataset> 3`。
