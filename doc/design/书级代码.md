# 书级代码：各书专属代码移出 cv（2026-11-09，Sheldon 定；cv v0.7.0）

> 设计稿全文（含现状盘点、迁移步骤、需通知的点）：Claude Doc《书级代码拆出 cv 与四库版本号方案》
> https://claude.ai/artifact/Xkabhi4DSeSYxvjwG5iz9i 。本文只记落进代码的约定。

## 一、两级

| 级 | 放哪 | 版本 | 谁改 |
|---|---|---|---|
| global | 本仓：`seg/` 原语、Step 壳、引擎、指纹、三条版式的缺省实现（现 `impl/keben`、`impl/modern`、`impl/free`） | `vX.Y.Z`（`doc/版本号规矩.md`） | 改原语、壳、指纹找切分架构维护人（A22） |
| 书 | 各书工作区仓根 `code/`（GitHub 组织 `guji-workspace`，一书一仓） | 整数 `k<N>` | 书的负责人自己发，不等 cv 发版 |

没有 group 级；两本书要同一段代码，各拷一份。**书的 `code/` 为空也能跑**：全走缺省实现，指纹与没有 `code/` 时逐位相同。

## 二、书仓 `code/`

```
code/
  code.yaml        name（＝册的 seg_set）、base（keben/modern/free）、cv 兼容段、overrides
  defaults.yaml    这套代码配套的参数缺省（params: {step: {字段: 值}}），取代 books/<套书>/defaults.yaml
  samples.yaml     样页单
  equiv.yaml       本书登记的代码等价（moved / forked / entries），只许登本书模块
  *.py             本书模块：只许 import open_guji_cv.seg、open_guji_cv.book_api 与本书模块（guji code check 查）
  releases/k<N>.json   每版文件清单（路径 → sha256），只增不改
```

`overrides` 写 `keben.row_boundaries: row_boundaries`（缺省模块短名 → 本书模块）。cv 在 `core/book_code.py` 把 `code/`
挂成包 `guji_book.<name>`，`core/seg_set.resolve()` 先查书仓覆盖、再查 cv 内置的 `OVERRIDES`（过渡期）。

## 三、版本号：字母＋整数

| 字母 | 库 | 册配置键 | 层 |
|---|---|---|---|
| `cv` | 引擎 | `cv_version` | global |
| `c` | 语料库总号 | `corpus` | 册（钉子账，下分底库 b、书库 v、册层） |
| `g` | 字形库 | `glyph_pin` | 书 |
| `m` | 模型库 | `model` | 书 |
| `k` | 书级代码 | `code` | 书 |

- 册配置可写简写 `pin: c31-g19-m2-k3`（`core/lib_pins.py`，逐层展开成分开的键，同层两种写法不一致报错）。
- 产物包标签：`cv0.7.0-c31-g19[-m2][-k3]-<改动名>`（guji-manager `datastore/packs.version_label`）；没有模型、书级代码的册标签与以前相同。

## 四、指纹与钉版本

- **版本号不进指纹**；指纹照旧按每个模块去注释后的代码算。书级模块进指纹的名字是 `guji_book.<name>.<模块>`。
- 从 cv 搬进书仓的模块登 `code_equiv.MOVED`；只改了 import 路径的另登 `ENTRIES`（或书仓 `equiv.yaml` 的 entries）。
  `engine._fingerprint_name` 沿 MOVED／FORKED 链走到头，所以「书仓模块 →搬自→ cv 套书副本 →分叉自→ 殿本模块」也认。
- `guji code release -w <书仓>` 写 `code/releases/k<N+1>.json`（内容没变不出）；书仓里提交并打 tag `k<N>`，书配置写 `code: N`。
- 钉了 `code: N` 的册起跑前比工作副本与 `k<N>.json`，不符拒跑（`GUJI_CODE_DRIFT=warn` 只告警）；`code.yaml` 的 `cv:` 段不含当前正式版也拒跑。

## 五、和 cv 发版的关系

- 只动一本书的代码：书仓提交、出 `k<N+1>`，不碰 cv。
- 改 `seg/`、`book_api`：加东西 PATCH；改签名或删 = MINOR（各书要跟着出新 `k`、改 `cv:` 段）。
- 改缺省实现：照 cv 规矩；改完用 `scripts/seg_samples.py` 比各书样页。
- 只给一本书用的新行为不再往共用 Step 里加「缺省关、按书开」的开关：拷缺省模块进书仓再改；要改的地方不在可覆盖模块里，找 A22 开钩子点。
