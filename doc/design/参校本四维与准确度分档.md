## 一、册配置写法

`references[]` 每份可加（都可不写＝未标）：

| 键 | 取值 | 含义 |
|---|---|---|
| `form` | `column`／`text` | 一行即刻本一列／不分行全文（同 `line_is_column`，两处都写要一致） |
| `punct` | `none`／`judou`／`modern` | 白文／句读／新式标点（现只记录，代码不读） |
| `script` | `faithful`／`trad`／`simp` | 照录刻本字形／规范繁体（异体已归一）／简体 |
| `accuracy` | `very_high`／`high`／`mid`／`low` | 与最终定字一致率的档位（门槛见第二节） |
| `accuracy_evidence` | 一句话 | 量法、样本、一致率 |

`reference_profile` 的段上可写 `accuracy`，只许 ≤ 所指那份的档（序跋、职名等参校本错得多的页段压低）；`kind: none` 段不能写。

```yaml
references:
  - file: qtw_kanripo_grid.txt
    line_is_column: true
    form: column
    punct: none
    script: trad
    accuracy: high
    accuracy_evidence: "CV0 11-27 全唐文 4 册 11.1 万格一致 99.57–99.96%，待审全算错下限 99.52%"
params:
  seed_admit:
    trust_from_accuracy: true     # 缺省关
```

## 二、门槛（拟）

| 档 | 一致率 | 最少样本（0 错时） |
|---|---|---|
| `very_high` | ≥ 99.9% | 3,000 格 |
| `high` | ≥ 99.5% | 600 格 |
| `mid` | ≥ 98% | 150 格 |
| `low` | 不到 98% 或没量 | — |

量法：已定字格（人裁＋放行）里参校字与定字的一致率；码位异体不算错；待审格全算参校本错得到**下限**，**定档按下限**。这是与最终文本的一致率，不是盲读抽样：放行时照了参校本的错字看不出来，好在 `match_ref` 要字形库同意，此偏差有限。

## 四、代码怎么用（seed_admit `trust_from_accuracy`，缺省关）

逐页取本页参照的 accuracy（段上压低优先）：

- `very_high` → `reference_trust: very_high`；`high` → `reference_trust: high`；`mid` → `ref_lib_coord: true`；`low`／未标／无参照页不动。
- 只往上推：册里已写更高的照旧，要压低就把 accuracy 标低。
- `script: trad|simp` 的页关照录参校本异体（`follow_ref_variants`，含 `reference_trust` 带的那项），`edge_pair_to: ref` 退回 `freq`。
- 本册摘要进参数 `ref_accuracy`（进指纹）：改 accuracy／script 本步过期；开关关时三个新键都不进 dump。
