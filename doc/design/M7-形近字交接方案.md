## 一、一页纸摘要

1. **现状**：51 个字组已注册（`groups/registry.py`）并写进殿本 vol01–10 的册配置 `seed_admit.group_flow`：23 个形近不同义组 + 28 个异体组。重算各册 Step7 才会真用上，**重跑归 M8，不是本项目**。
2. **三路方法**：① 上下文（L1 规则 + L2 haiku 答案表）管字义不同的形近字；② 字形（IDS 部件 / 整字岭回归 / U-Net 切线）管同字异体；③ 量横管土士、未末这类差一笔长短的。另有**字频**（异体组里殿本只用一形就放主形）和**库形最近**两条兜底。统一入口是 `groups/flow.py` 的 `group_flow`，一组一个 `GroupSpec`，**加组不改 `seed_admit`**。
3. **铁律**：给字格放错必须 0，否则弃权送人审；弃权永远安全。评测按册留出。
4. **下一步**：第六批形近不同义组（宋朱、四因、與興、法注、月用、出山、河何…，见统计文档 4.1）；第五批 L2 表写中心库；彝组放行率、冊册、啓啟补采等"待重想"；异体备选单大多只能补采样或走字频。
5. **sheldon 的偏好**：中文；能并行就拆线程；手机可点的审查页，答案预填好、没把握的标黄，他只改错的；少依赖他本人操作；人工标注和切线必须落进数据集。

## 二、三路方法

### 2.1 怎么选路（三问，按序）

| 问 | 是 | 否 |
|---|---|---|
| Q1 是同一字的异体吗？ | 目标是忠于刻形。殿本只见一形 → **字频**放主形；两形都有且差在部件 → **IDS 路**；两形都有但差别不在可切处 → **整字岭回归** | Q2 |
| Q2 文意能判吗（干支、虚词、书名、固定搭配）？ | **上下文路** | Q3 |
| Q3 有单一可量几何量（哪条横长）？ | **量横路** | 只能弃权送人审 |

口径：**异体按刻形定字，形近不同义按文意定字**。例：刻形是末、文意定未 → 以文意为准，量横给"末"只是如实描述，不能单独推翻文意。

### 2.2 上下文路（L1 + L2）

- 窗口：前后各 20 字、不分段，匹配串 `前20字◎后20字`（`groups/context.py`）。邻字取法：same → 整理本 → □。
- **L1 静态规则**（`groups/ctx_l1.py` + `config/groups/<组>/rules.yaml`）：词组与正则；运行时零模型。规则必须**对整理本零冲突**。后两批的做法：整理本 vol02–10 前后 1–2 字、夹字上下文，按册奇偶分两半，**两半都见到且从不矛盾、次数够**（多数字≥8，少数≥3）才收，再手工剔除两可词（如"卦象""蔡傳""草本"）。注意：用整理本生成的规则对整理本零冲突是必然，交叉验证只保证没见过的册上不打架。
- **L2 离线大模型判读**（`groups/ctx_l2.py` + `config/groups/<组>/prompt.md`）：每组专用提示词，批量离线跑出 `group_clf/1` 答案表，管线只查表（`l2_make_book.py` / `l2_run.py` / `l2_ingest_book.py` 在 `research/m7/ctx/`）。**生产只用 haiku，只收 conf=high**，其余送人审。三模型一致没必要；Gemini 准但几乎不弃权，错的也标 high，不选。提示词必须留"其他"出口，字外格选其他就弃权。
- **形近字一律按文意定字**，不按刻形；金标有错就用复审裁决改正（"而已"被标成己、"大畜卦曰"被标成日）。
- 结果：己已巳 183 格 172 给字全对，下界 0.978；日曰 抽样下界 0.991；入人八 0.991。己已巳已到天花板，不要再为它单开优化。
- 已知风险：haiku 在日曰的字外格（口目白田）会硬给组内字；靠"整理本字在组外不补放、已放行的字不在组内不碰"兜住。入口只吃"整理本对位字或库前二候选在组内"的格。

### 2.3 字形路

| 方法 | 适用 | 实现 | 结果 |
|---|---|---|---|
| **字频** | 异体，殿本只见一形（刊刋 既旣 清淸 爲為 說説 …） | `groups/freq.py`；表 `config/groups/freq.json` | 规则：主形人裁 ≥10 且至少来自两册，其余成员 0 → 放主形，否则弃权（cv#253） |
| **IDS 部件**（自动缝/折线切分 → 部件模板最近邻 → margin 不够弃权） | 异体两形混用，差别在可命名部件（參㕘叅、彝） | `groups/ids_*.py`、`ids_online.SPECS` 的 by_form | 參㕘叅 74 格留一 67 对/7 弃/0 错 |
| **U-Net 切线** | 自动缝切不准的左右结构（叙敘、彝三段） | `ids_unet.py`，权重 `config/groups/<组>/unet.npz` | 切线准确率 0.965→0.992；叙敘覆盖 33%→87% |
| **整字岭回归**（HOG 或像素，二类） | 差别不在缝两侧：絕絶、厯歴、啓啟、呂吕、徵徴、教敎 | `groups/ids_whole.py` | 都 0 错；覆盖 21%–94% 不等，见实验记录 |
| **量横** | 土士、未末 | `groups/bars.py` | 文意弃权才补位，两路冲突送审 |
| **入人八字形分类器** | 入人八 | `utils/rr_clf` | 只验证过"降级"，不许单独补放 |
| 日曰宽高比 | 日曰 | `groups/aspect.py` | 日窄曰宽，只当第二路 |

经验：
- **切得准不等于判得准**：jue/lih/qik 整字反而不输部件；按组选法，不一刀切。每组都做整字 vs 部件 A/B。
- 差别在**某个局部**时，取框比扫参数有效：教敎 用 sheldon 在滑块页里直接调的左上框（左 0–55%、上 0–46%）+ HOG（归一图放大 48×48）→ 93 格（教68/敎25）按册留出，门槛 0.4：87 对/6 弃/0 错（PR #352 已合 dev，未发版）。此前机器扫百余种配置的最好值还有 6–11 格判错，且偏乐观。**让 sheldon 直接定取框，比机器扫参数有效。**
- 样本太少的类（叅 2 例、啓 8 例）一律弃权；两刀法在少样本类上会放错，缺省一刀。
- 冊册 这类独体字，IDS 用不了，已踢出 IDS 路。
- 彝组 U-Net 三段切分 79 对/2 弃/1 错（数据集 87 格），但 sheldon 不满意，具体点待问。

## 三、组合、弃权、放行规则（`FlowSpec`）

- `solvers` 有序；`combine=first`（第一个给字的说了算，字频成立就不再看 IDS）或 `agree`（给字的必须一致，不一致送审）。
- `review`：已被别的通道放行、放行字在组里的格也进流程复核，解法给了别的字就**降为人审**（只降不改字）；`review_fix` 才改字（只给"字形只定这一族、字全凭文意"的己已巳）；`review_abstain`：解法全弃权也降审（己已巳）；`lift_needs`：补放必须有指定解法给字（入人八要文意）。
- 两路给字且一致 → 放行；不一致 → 抬人审并留证据；只一路给字 → 按该路自己的验收线；都弃权 → 维持现状。
- **组外格逐格不变**是每次 A/B 的硬验收。
- 组成员不得重叠，除非互相声明 `overlaps`（日曰/日目/目自）；入口按分差内候选＋整理本字选第一个装得下的组。`ref_free`：整理本在本组的字上没有参考价值（己已巳，sheldon 10-19 定）。
- **书级固定用字**（册配置 `codepoints`）只限已定几组（內内、別别、出岀、巻卷、即卽、歷厯、晩晚、𡌨埤），**不再新提**；其余异体对用 IDS 或上下文区分（sheldon 10-20）。
- **异体与整理本**：整理本把很多异体规范成通行字，所以"转写不同于整理本"多数是转写对（𠮓→變 206 条），价值在少送审，不在提高识别率。真有识别错的才需要判别器。

## 四、阈值与评测规矩

1. **按册留出**：模板库、U-Net 训练、超参只用非留出册；**超参也只在训练册内选**（不在留出册上扫）。
2. **给字格放错 0** 才允许上线；"0 错覆盖"＝阈值定到留出集 0 错时的给字占比，偏乐观，生产阈值取更保守。
3. **IDS/训练：每形人裁 ≥20 才训**（sheldon 10-20）；不够的进备选单（`doc/design/M7-异体字备选单.md`）。样本其实很多时出补标页让 sheldon 补采；补采结果也要看——往徃/刪删/扺抵 补采样证明稀有形本来就少（往160/徃1，刪111/删5，抵90/扺10），"样本很多只是没人标"不成立，走字频放主形、稀有形送人审。衛衞 加已有人裁后可能到 20，先去重。
4. **字频判法**：主形人裁 ≥10 且至少来自两册；两形混用的不能用字频，走 IDS/整字判法。字频表是离线冻结的表，重算是显式动作（在线现算会让每册新增人裁都使 Step7 过期）。
5. **上下文**：L1 零冲突；L1→haiku(high) 合并后给字 Wilson 下界目标 ≥97%（要≈130 个可评格全对）。样本不够 → 只当 starter，数据多了再测，不是准确率问题。
6. 强真值很少时（象彖、王玉、圓圖），验收靠 L1 与整理本对账 + haiku 与整理本对账，再让 sheldon 抽审。
7. **抽样口径**：只抽样跑相关字组的页，不整册重跑；抽样只覆盖 L1 弃权格约两成，**别当全书结论**。
8. 评测复现：`python -m open_guji_cv.groups.ids_online build|loo <组> --dataset <数据集>`；上下文用 `research/m7/ctx/eval_corrected.py`、`build_review_population.py`；字组评测见 `eval/groups.py`。

## 五、加一个新字组的流程

1. **先查已有标注，复用不重标**：数据集 `char-groups/`（标注清单.md）、中心库人裁事件 `feedback/events`、`research/m7/census/group_census.py`（人裁/校勘/ref-mismatch 普查）。
2. 按 2.1 三问定路；`groups/registry.py` 加 `GroupSpec` + `FlowSpec`，配置放 `config/groups/<组>/`（`rules.yaml`、`prompt.md`，或 `ids_bank.json`）。逻辑留 CV，**数据（词组、书名词例、模板库）进语料层**。
3. 量候选格（`research/m7/ctx/ext_enum_cells.py`），写 L1，跑 haiku，出 L2 表。
4. 单组 A/B（`guji exp`，同一份快照只重跑 `seed_admit`，vol04 221 页）：看组外格 0 变化、放行增减、强真值零错；PR 报告 `seed_admit` 的 `code_hash` 变化（都是 seed_admit 一步变，其余 16 步不变）。
5. 册配置 `group_flow` 加组 id。**当前发布版不认识的组不能点进册配置，否则跑批报错**，要等发版时同步。字频表、L2 表由收口线程统一写中心库。
6. 登记 `doc/开关登记表.md`。
7. 新功能开关**缺省开**（sheldon 10-19 定，取代项目说明里的"缺省关"）；字组成员允许重叠须声明；已放行格要加复核。

## 十、踩过的坑

1. 日曰金标本身有错：形近字一律按文意复核金标，别拿旧金标当真。
2. 字外格（目口白田巴）：候选池里约 24% 的日曰候选整理本字在组外；靠两道护栏兜住。
3. L1 规则用整理本生成 → 零冲突是必然，别当"准确率"。
4. 在测试册上扫超参会偏乐观；超参只在训练册选。
5. 字体相似度 ≠ 刻本真混淆（考者 0.98）；候选要有人裁/校勘证据或抽样确认。
6. 自己切字块坐标错位（见第六节）。
7. 往徃/刪删/扺抵 的"样本很多"是错觉；先用补采样量一下再投入。
8. 写中心库、推 tag：必须按第七、八节走。
9. 新册只有殿本有字频表和文意表；北行日錄、全唐文遇到字频/文意判法会弃权。
10. 日目/目自/日曰共用成员，别忘了 `overlaps`。
11. 单遍 haiku 在一二上与整理本分歧 12 处（字形只差一横、文意两可），一二只用 L1。
