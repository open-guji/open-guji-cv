# M7 IDS 通用计算：由成员 IDS 自动导出切法，不再逐组手填

状态：2026-10-22，第一步（`groups/ids_plan.py`）、第二步（`groups/ids_generic.py`）已落地，叙敘／教敎／絕絶 已改用通用判法。
承接 [M7-IDS路-扩展与训练增长](M7-IDS路-扩展与训练增长.md)。字组方法数组里 `ids`／`composite` 方法见 `groups/methods.py`。

## 1. 现状的问题

每个 IDS 组的切法都手填在 `ids_online.SPECS`：切向 `orient`、看哪一段 `which`、拼 IDS 的 `frame`、是否整字（`whole`）、是否三段（`three`），
加 `ids_override.tsv` 的停止点和别名。新增一组要人想一遍「差别落在哪、怎么切」，容易想错（叙敘 一度取「上 40%」，教敎 切缝不行改取左上角）。

## 2. 差分驱动的切分计划（第一步，已实现）

`derive_plan(成员串, 组目录)`：把各字的 IDS 在最浅一层对齐——结构符和元数相同的逐位置往下比；
位置上各字写法相同的是公共部件，不用看；不同的是**判别位置**。结构对不上时把各字「打开一层」（叶子换成它的拆法，同向嵌套压平）再试，深度预算 2。
输出：`mode`（`split`／`whole`／`same`）、结构符、切向、判别叶子的路径与各字在此处的部件（`diff_leaves`）。

用 ids_lv1 和现有 `alias` 复现了手写规格，**没用任何停止点**：

| 组 | 导出的计划 | 手写规格 |
|---|---|---|
| 參㕘叅 | ⿱厽{}，下半 彡／小／𠇍 | h，which=1，`⿱厽{}` |
| 叙敘 | ⿰余{}，右半 又／攵 | v，which=1 |
| 彝彛彜彞𢑱𢑴 | ⿳，三个判别叶子：(0) 彑彐、(1,1) 糸分、(2) 廾大 | `three`，上／中右半／下 |
| 教敎 | ⿰，左半里的 耂／乂 和 子／𡥂 | 整字 HOG 取左上角（sheldon 提示「差别在左上」） |
| 啓啟 | whole（⿱ 对 ⿰） | 整字 pix |
| 冊册 | whole（⿻ 叠合，没有直线切法） | 退出 IDS 路 |
| 絕絶 | same（ids_lv1 都写 ⿰糸色，表太粗分不出右部「色」的刻形差别；不是字形相同） | 整字 hog |

结论：**切向、判别位置、彝的三段**都能自动得到；整字类的组也能自动判出「该走整字」。这是通用化的第一块，不动任何 Step，不进 `code_deps`。

## 3. 通用计算的后三块（第二步，待做）

1. **切分器不强行共享**（sheldon 10-22 提醒：左右结构的字形可以差很多，合训可能不如分开）。计划（怎么切）通用，切分器每组三选一：自动缝／该组自己训的 U-Net／合训的共享 U-Net，
   **同一批数据按册留出比较，哪个好用哪个**；样本太少的组（叅）才借共享模型初始化。叙敘＋教敎＋絕絶 合训优于旧自动缝（0.992 对 0.965）只说明相近任务合训有益，不外推。判别叶子在更深的位置（彝的 (1,1)）沿用现在「先切三段、中段再竖切」的做法，由计划里的路径驱动。
2. **部件识别**：每个判别叶子一个 HOG＋岭回归，类＝该位置上各字的部件（同部件的字合并，如 彝彞𢑴 的中段都是糸）。训练样本不需要部件标注：用人裁字标签＋切线推出叶子标签。
3. **拼装**：叶子读法代入计划的 frame → IDS → `IdsResolver`（exact／form／nearest）；任何叶子 margin 不够整格弃权。

验收：对已上线的 can／xu／yi_560 复现手写规格的按册留出指标（不许退步），再用同一函数新跑 jiao 的两种读法，比整字 HOG 好才换。

## 4. 已知限制

- 对齐只看 ids_lv1 的拆法，字库里的拆法不一定是殿本刻形的拆法（參的 㐱／彡 靠 `alias`）；`alias` 仍是数据，放组语料。
- 叶子打开深度是启发式，深了会把无关笔画差当判别（教敎 的 耂／乂 已有此味道），所以计划只管「切不切、怎么切」，**判别用的部件由样本决定**。

## 5. 实验与落地（2026-10-22）

对比脚本：`research/m7/ids_plan/cmp_cutter.py`（切法）、`cmp_recog.py`（识别器）；全部按册 5 折留出，0 错覆盖率＝margin 大于最大错例 margin 的格占比。

1. **切法**（与人标线墨迹归段一致率）：U-Net 0.99 ＞ 形状先验折线 0.97–0.98 ＞ 自动缝 0.95 ＞ 部件模板滑动（直线）0.93。
   形状先验折线＝训练格人标切线的平均形状当先验，在它 ±0.12 内 DP 找穿墨最少的折线，不用训练。sheldon：直线不行，要折线。
2. **错例核对**（sheldon 看过 25 格）：标注和切线都对，错在部件识别。
3. **关键：模板与测试格用同一切法切。** 模板用人标线、测试用机器线时切口不一致，最近邻认错；改同一切法后切线也不再需要人标，
   没标切线的人裁格也能进模板（教敎 37→93 格）。识别器换 HOG／岭回归没有更稳，最近邻足够。
4. **细 IDS 切到叶子**：絕絶 判别叶子是右部「色」的上半（刀／⺈），再切一刀只比叶子，0 错覆盖率 23–38% → 67–87%。
5. **切分器不共享**：同口径下 叙敘 先验折线 100%／自训 U-Net 87%；教敎 三种都 100%；絕絶 U-Net 87%／先验 74%。
   固定部件池（攵：敘＋教＋敎）与自训持平，样本少看不出差别。每组按册留出选切法。

| 组 | 旧判法（0 错覆盖） | 通用判法 | 按册留出 | 门槛 |
|---|---|---|---|---|
| 叙敘 | U-Net＋by_form（同口径 57%，旧报 87%） | 先验折线 | 不设门槛 0 错 | 0.02 |
| 教敎 | 左上角取框 HOG 94% | 先验折线＋切到叶子 | 0.03 → 91 对／2 弃／0 错 | 0.03 |
| 絕絶 | 整字 HOG 44% | U-Net（本组 39 格训）＋细 IDS 叶子 | 0.05 → 23／16／0（59%） | 0.05 |

參㕘叅：错都在 㕘→叅（叅 只有 2–3 例，线上本来不许给叅），要补 叅 样本，暂不换。彝：三段，通用函数暂只接一刀两段。
