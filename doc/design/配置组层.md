## 一、六层与生效顺序

代码缺省（Step 缺省 < 链 yaml < 版式缺省或书仓 `code/defaults.yaml`）< **组** < 书（`config/book_defaults.yaml`）< 册（`books/<册>.yaml`）< 运行覆盖（`--override`）。页级设置写在册 yaml 的页段表里。环境变量只管路径、缓存、调试、密钥。

## 二、组

- 组＝一套丛书或一种版刻字体（用户 11-04 定）。首批 `wyg`（文渊阁写本：史記、汉书，以后二十四史）、`wyd`（武英殿刻本：殿本）。
- 书声明：`groups: {config: wyg@1, glyph: [wyg], corpus: [wyg], model: [wyg]}`。只许写在书层；配置组恰好一个。
- 存放：中心库只读工作区 `group-<组>`，文件 `config/group/v<N>.yaml`，只增不改（顶层 `meta:` 是说明，不进合并）。`guji db pull` 把书声明的组拉成只读副本；拉不到报错。
- 组版本（`wyg@1`）与字形库共享库版本（`glyphlib-wyg-v1`）是两套号，各自升，互不相关。字形组实际用哪一版以 `workspace.yaml` 的 `borrow` 为准；语料组对应 `pua-wyg` 等；模型组对应各自模型包。一期只有配置组参与合并。
- 禁写（`FORBIDDEN_IN_GROUP`、`FORBIDDEN_GROUP_PARAMS`）：身份、图源、实测先验、书身份（`book_id` 等、`seg_set`）、钉子（`corpus`、`glyph_pin`、`model`、`code`、`cv_version`、`pua_table_pin`、`pin`）、`references`、`codepoints`、manager 直接读的 `src_w`、`cos_iou_min`；`params.*` 下的 `follow_ref`、`follow_ref_seen`、`pua_rules`、`page_pins`、`coord_title_formula`、`layout_prior`、`roster_ref_corpus`、`roster_ref_pins`；`group_decision.handling.*.methods`。
- 组层的 `seed_admit:` 与 `char_decide:` 两个键都认，同层两个都写报错；新组文件一律写 `char_decide:`。
- 指纹：只看生效值；组名、版本号不进指纹。

## 三、入组的规矩（旧 cv 兼容）

旧 cv（实测 0.7.98、0.7.112、0.7.115）读到 `groups:` 静默忽略、不报错、生效配置不变。所以：

1. 钉旧 cv 的书入组时**只加 `groups:`，不删书里与组同值的键**；验收用各册钉住的 cv 版本逐册比生效字典，全部零差异才推库。
2. 这本书升钉到含组层的 cv 以后，再删书里的同值键，用新 cv 逐册验一次。

## 四、读口（manager、第三步脚本用，别直接读 yaml）

- `open_guji_cv.core.book_config.effective_book_dict(册 yaml, apply_override=False)`：一册的生效配置。
- `effective_defaults(数据目录根或任一册 yaml)`：书级生效配置（组 ∪ 基础配置）。
- `book_groups(基础配置字典)`：`{"config": ("wyg", 1) | None, "glyph": [...], "corpus": [...], "model": [...]}`。
