# 总览：不属于任何单独一步的事

一份任务书跟着它服务的那一步走（见 [../任务书/README.md](../任务书/README.md)）。
**跨步、或压根不属于某一步的**放这里。

> **状态看看板**：https://github.com/orgs/open-guji-core/projects/1 （块:CV）。本 README 只做索引、记内容（结论、数字、判准），不再手写「在跑／排队」；带 `（#N）` 的任务书是看板上还开着的卡，不带卡号的已收。
