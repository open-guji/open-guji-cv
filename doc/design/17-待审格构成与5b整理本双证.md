# 待审格是哪来的、哪一刀最值（2026-10-02，CV 总管调查）

> 用户 10-02：「找到 1–2 处 ROI 最高的地方深入调查；Step7 模型判断法尽快落地。」
> 数据：guji-workspace 四庫快照（09-28 full：vol03–vol10，1,313 页、207,455 格；人裁标签取 vol02 0930T0339 / vol03 0930T0457 的 human 通道 1,737 格，Step5–7 产物取同书 0929 快照）。脚本在 CV 总管 scratchpad（`roi/pend.py` `bucket.py` `rare.py` `size.py`，`ruleA.py` `ruleB.py`），复现只要这两类快照。

## 一、待审格的构成（vol03–vol10）

待审率 4.7%（vol03）→ 8.9%（vol10），越往后越高（新册字形库里没有的字越多）。13,064 个待审格按 doubts：

| 构成 | 占待审 |
|---|---|
| **整理本与载体不同（replace_align）+ 库 unsure + 上下文 margin 不足** | **57.5%** |
| 同上但不带 replace（多为对齐没覆盖到的格） | 12.5% |
| replace_align + context_vs_ref | 8.1% |
| 印章遮挡 occluded | 7.4% |
| 形近 near_form 组合 | ~7% |
| 己已巳 | 3.5% |

**头号成因**：replace 位里 73% 的格，**整理本字根本不在字形库候选里**；其中 80% 这本书里从没放行过这个字——是**新册字形库冷启动**，不是图坏、不是切分错。
78% 是单字 replace（左右都 equal 夹着）。

## 二、ROI 第一刀：整理本 × 5-b 双证（拟名 `rare_ref` 通道）

同一批格里，**5-b（字体模板 emb/CNN，与整理本独立的图像证据）首位就是整理本字的占 94%**。可 5-b 产物现在 Step7 不读（`rare_agree` 只记不放：那是「5-b 与库」一致，R 道测 97.6%/90.7% 不够；**「5-b 与整理本」一致从没试过**）。两路误差独立，符合 Step7「凑双信号挑误差独立的两路」原则。

**规则 A**：align_op=replace 且整理本字存在；5-b 首位 **逐字等于** 整理本字；不是己已巳；没有硬护栏（occluded／never_match／conflict／near_form／空白格／排除名单）；库没有 `same` 强认别字；**库首位不是整理本字的同字异形**（是就交人——见下）。放行字 = 整理本字。

| | 结果 |
|---|---|
| 人裁标签（vol02+vol03 human 1,737 格里规则命中 560） | **558 字形完全对，错 2**（`57:7:20` 蚤→𫊫、`168:3:21` 盡→𥁞，**都是同字罕见写法**，字对、形错）；错误率 0.36%，95% 上界约 1.3% |
| vol05 | 待审 5.52% → **2.51%**（−54%） |
| vol08 | 7.67% → **3.44%**（−55%） |
| vol10 | 8.87% → **3.52%**（−60%） |

**口径与局限**：人裁格全是难例（送审过的），不是放行总体的随机样本；0929 快照里这些格已是 human 通道，doubts 为空，硬护栏在标签集上量不到（偏乐观一点）；09-28 快照是旧代码（之后 Step3/Step5 都改过），量级可信、精确数要在现行产物上重量。**错的是「形」不是「字」**：整理本把刻本的罕见写法规范掉了——离万分之一还差得远，所以不能直接转正，见三。

**负结果（规则 B）**：库首位是整理本字的「异体」时取库形——75 格里只对 11 格，64 格人裁取了整理本字。原因是**异体关系表太松**：`variants.are_variants` 把 大/太、士/土、戊/戌、增/憎、楊/揚、且/旦、規/窺… 都算异体。这张表在 Step7 里还有别处用（`ref_lib` 变体边、`variant_form`），**值得单独查一遍有没有借这条松边放错字**（另开卡）。

## 三、Step7 模型判断怎么尽快落地

现状：影子模型已在 cv main（`open_guji_cv/shadow/`，N1），**只做「降级」**、默认关；没有一本书开过。降级只管已放行的那 98%（match_ref 里几乎一格不降），**不减人审**。真正值钱的是「升级」——把待审格里有把握的放出去，而上面一节说明待审格里最大的一块（双证格）正是模型最擅长的。

三步走（一、二步可同时开始）：

1. **本地即开降级闸（零代码）**：四庫各册 seed_admit 开 `shadow_veto: true, shadow_conf: 0.8`；被降的格全进人审、记结果。两三册后就有「误伤率」的真数。
2. **云端 D3 道：升级模式 + 第二版信号**（默认关）。
   - 信号 v2：加「候选在 5-b 里的名次」「库首位是否整理本字的异体」「候选是否等于整理本字且 5-b 首位」三项（本调查找到的最强组合），可选补 LM 窗口分（X1 结论）。
   - 升级规则：只对无硬护栏的待审格；影子首选必须有**两路独立证据之一背书**（= 整理本字 或 = 库首位），把握 ≥ 门槛 → 新通道 `shadow` 放行，evidence 记全。
   - 正面比：同一人裁集、按页折 + 按册留出（vol02↔vol03），与**规则 A** 比——同放行量下错得更少，或同错数下放得更多才用模型；不如规则 A 就用规则 A 当候选生成、模型只当否决。
3. **本地试一册**：选一册开升级，放出来的格通道名单独记 `shadow`／`rare_ref`；按用户 09-30 定的口径，用 Step8/9 回流（自动放行格被改的比例，按通道分层）当错误率。两册过线再默认开。

形的问题单独处理：放出去的格若整理本字有罕见异体（字表里能查到），evidence 记「形未核」，Step8 按字批量看一眼，量很小。
