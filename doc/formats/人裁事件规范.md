## 三、单位键（`target.key`）语法

`册` = 工作区里 `books/<id>.yaml` 的 id（`vol01`…`vol10`、`bxgb`），**不是** book-index 的 10 位 id，也不是网站的三位章号 `001`。
解析器：`feedback/keys.py::parse_card_id`（`EventTarget` 读回时用它补 `book/page/col/slot`）。

| unit | key 形状 | 例 | 说明 |
|---|---|---|---|
| `cell` | `册:页:列:格[a\|b]` | `vol02:100:4:17b` | 格号正文从 1 起；**负数 = 超框抬头**（`-1` 最靠框，`vol04:6:6:-1`）；**没有 0**。`a`/`b` = 夹注右／左半（右先读）。 |
| `boundary` | `册:页:列:格` | `vol02:87:2:10` | 切线：格号 = **线上方那一格**（`payload.slot_above`）。与 cell 键**同形**，必须连 `unit`/`kind` 一起认。 |
| `column` | `册:页:列` · `headcol:册:页:列` · `colborder:册:页:列:top\|bottom` · `pNNNNcNN`（老） | `vol03:28:2` | 逐列字数、列清理、抬头列、列框。 |
| `page` | `pageline:册:页` · `head:册:页` · `outer:册:页:端` · `cols:册:页` | `pageline:vol02:10` | 版框、抬头有无、外沿、界行。 |
| `cell`（体检） | `v2:册:页:列:格` | `v2:vol02:132:8:17` | 字形库刻例 id，不是格键，`book/page…` 留空。 |

格键的「格」是 **Step3 切分的输出编号**，不是字的身份——重切一次，同一个编号可能指向别的字（§七）。

## 四、信封

一行一个 JSON 对象，`sort_keys`、UTF-8 不转义。字段（`additionalProperties: false`）：

| 字段 | 必填 | 类型 | 规矩 |
|---|---|---|---|
| `id` | 是 | string | `evt_<batch>_<seq:06d>`。**全工作区唯一**；消费记账只认它。 |
| `ts` | 是 | `YYYY-MM-DDTHH:MM:SSZ` | **服务端写入时间**（UTC）。「后到覆盖」的第一排序键。注意：它不是人做判断的时刻——2026-09-16 之前定字台每次提交会把整轮已有裁决重写一遍，那批事件的 `ts` 比 `client_ts` 晚 1–2 小时；`ts` 回答的是「这一版状态是什么时候落盘的」。 |
| `batch` | 是 | string | 一批一个文件，文件名 = `safe_batch_name(batch)`（`:*?"<>\|/\` → `-`，Windows 冒号会写成隐藏数据流丢数据）。**批次名不带语义**：不许从批次名推册号或时间。 |
| `seq` | 是 | int ≥1 | 批内序号；写入时撞号且内容不同顺延，内容相同跳过。 |
| `actor` | 否（缺省 `user`） | `user`／`model`／`align` | 谁的动作触发。**是否算人裁不看它**，看 `counts_as_human`（§5.3）。 |
| `kind` | 是 | 枚举 | 见 §五。 |
| `target` | 是 | object | `step`（出卡的 Step）、`unit`（`book/page/column/cell/boundary`）、`key`（§三）、`book/page/col/slot`（key 的拆分，冗余）、`anchor`（§七）。 |
| `payload` | 否 | object | 各 kind 自定（§五）。公共键：`client_ts`（**毫秒**，人点下去的时刻；量耗时、看「判断时刻」用它，不用 `ts`）、`dwell_ms`、`request_id`（POST 幂等键）、`note`、`via`、`source`、`question`。 |
| `source_format` | 否 | string/null | `server`＝控制台直连；`verdicts`/`seed`/`seg`/`marks`＝旧格式收割；`null`＝脚本直写。 |
| `reviewer` | 否 | string/null | 具体是谁：网站账号 email；本机控制台 `local-dev@127.0.0.1`；Claude 道 `claude-<道>-<任务>`。 |

## 六、排序、覆盖、幂等

1. **唯一排序键 `replay_key(e) = (ts, batch, seq)`**。凡「同一单位取最新」「按序重放」「按序消费」都用它。
   `Event.order = (batch, seq)` 只用于批内（撞号检查），**不许跨批次比**：批次名字典序不是时间序
   （`H-mojibake-fix-…`、`H-web-…` 都排在 `vol01-…` 前面，更正会被旧裁决盖回去）。
2. **覆盖的分组键 `(kind, target.unit, target.key)`**，定字类读者再按 `payload.v` 二次分流。切线与定字 key 同形，不带 unit/kind 分组会互相顶掉。
3. **只追加**。改判 = 追加一条新事件；撤销 = 追加一条把状态改回去的事件（如 `collate_verdict` 的 `who` 空、`return_resolve`、glyph_audit `evict`）。`compact` 只删同组里被覆盖的旧行，**保留留下那条的原 id 与 seq**。
4. **幂等**：消费者把处理过的 id 记进 `consumed/<consumer>.jsonl`；同一事件可能记多次（多条路由同一消费者、两机合并），`consumed_ids` 按集合读。`gold rebuild` 不看记账、按 `replay_key` 全量重放；字形库重建按水位线重放（`replay.py`）。
5. **写入口**：`EventLog.append`（持 `feedback_write_lock`）。`payload.shape/reading/char` 不是单字或合法多码位整批拒；兼容汉字折成统一汉字。控制台 `POST /api/events` 另负责：`request_id` 判重、补 `target.book/page/col/slot`、算锚（§七）、`client_ts` 归一成毫秒、写完按路由消费刚写的几条。

## 七、锚与重切漂移

### 7.1 问题

人裁按格键记，格键是 Step3 的输出编号。重跑切分（改参数、改代码、人裁回流触发重切）后：

- 列内多切／少切一格 → 这一处以下整列顺移一位，旧编号指向邻字（vol02 09-25 实测约 220 / 1,417 条挂错或失效）；
- 切开、合并、夹注改判 → 一条裁决对上两格或半格；
- 字块（`cell_shrink`）重算 → 同一编号的图变了，指纹比对失准（vol01 10-19 云端重跑，100 多格人裁被判 review、全册丢成 □）；
- 切线 `y` 是**列图坐标**，列窗几何一变就漂（vol02 一批漂 20–50px 而 `col_h` 不变）。

### 7.2 锚（`target.anchor`）

写入时按**当时**产物算，全部可选、互相独立，读者缺哪样退哪档：

| 键 | 内容 | 跨重切 |
|---|---|---|
| `bbox`（＋`quad`、`space=raw_page_px@top-right`） | 原图像素外接框 | **稳**：原图不变——锚的主体 |
| `evidence` | 人当时看到的图的指纹 `fp`（`char_patch` 或切线附近的 `column_image`）＋当时产物版本 | 稳（指纹随事件存）；`bindings` 优先比它 |
| `content_sha` | 当时字块图 sha1，图存 `anchor_patches/` | 稳 |
| `ctx` | 当时读序前后各 2 字 | 辅助判整列错位（strict 模式） |
| `product_key` | `{step, key, fingerprint}`：出卡那一步的页产物指纹（控制台 `_product_anchor` 写）；只许这三个键 | 只说明「当时是哪一版」，**不能**用来找格 |
| `cells_sha` | `{<cells 步>: <sha256>}`：算 `bbox` 用的那一版切分产物（`cell_anchor`、补锚档写）。10-21 前混在 `product_key` 里，已迁 | 同上 |
| `source` | `live` / `backfill:<版本>` | — |

切线另在 `payload` 里记 `page_x/page_y/geom_sig`（原图坐标），`resolved_pins` 只收带它们的切线。

### 7.3 重绑定（`bindings.py`）

读人裁的下游（`human_chars`、字形库 `rebind_library_shapes`、`returns`）一律先过绑定表：

| status | 条件 | 下游 |
|---|---|---|
| `valid` | 锚框与同编号现格是同一块（IoU≥0.85，或指纹相近） | 照用 |
| `rebound` | 同一块但落在**另一个编号**上（整列顺移） | 改绑新编号 |
| `review` | 切开、合并、只部分重合、或图不像 | 不采信，回待审 |
| `void` | 锚框处已没有格 | 不采信 |
| `unanchored` | 没有任何锚（也补不出） | 裁于现行切分之后 → 同编号照用；之前 → 不采信 |

没有锚的老事件按序退：补锚档 `anchors/<册>.jsonl` 的 `ink_bbox` → 按裁决时间找当时那一版 Step3（`_prev/`、`<step>.bak-YYYYMMDD/`）的框 → 字形库里入库时的图块。
缓存按页，键 = Step3 产物 sha ＋ 字块产物 sha ＋ 本页事件签名，任一变了自动重算。`GUJI_BINDINGS_STRICT=1` 另开整列顺移闸与「新裁不可用时旧裁不顶上」（R1/R3）。
