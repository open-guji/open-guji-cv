# 缺页：册 yaml `gaps:` 与导出的 `NNN.gaps.json`

2026-11-18 用户定：**只按图片页号记缺页**，不另立「书上页号」。图片页号、产物、人裁事件、字位 id 一概不动，
缺页只是记一句「第几张图之后缺了什么」。起因：《脉经》（99k3i35yww）第 6 册卷九缺叶九、叶十，
图 20（叶八）与图 21（叶十一）在同一对开里相邻，参校本断档约 830 字，原书即缺。

## 一、册 yaml（中心库 `books/<册>.yaml`）

```yaml
gaps:
  - after_page: 20             # 缺在这张图之后（图片页号；0 = 第一张图之前）
    what: 卷九叶九、叶十        # 照书上写缺了什么，网站和文字版原样显示
    kind: 原书缺               # 原书缺（藏本本身没有）／未拍（书里有、图没拍到）；缺省 原书缺
    est_chars: 830             # 估计缺多少字（拿参校本量），可缺
    evidence: 图 20 版心叶八、图 21 版心叶十一，同一对开相邻；参校本断档约 830 字（claude 2026-11-18）  # 可缺
```

- 一段连续缺的写**一条**；同一个 `after_page` 只许一条。
- 只认上面五个键，写错（页号写成字符串、kind 写别的词、多了键）读配置就报 `BookConfigError`。
- 和 `id`、`pages` 一样是这一册图源的事实：**只能写在册 yaml**，基础配置、`--override` 都不许写。
- 不进任何 Step 的指纹（没有 Step 读它），加、改都不会让产物过期。
- 代码：`open_guji_cv/core/book.py` 的 `load_gaps`、`gaps_for_pages`、`gap_note`；测试 `tests/test_book_gaps.py`。

怎么发现缺页：拿参校本逐页定位，看相邻两页在参校本里的位置是否断档；再看版心叶号核实（脉经的做法见
guji-workspace/mai-jing README「已知问题」）。补缺页（另一藏本、补拍）是另一件事，补之前不动这条记录。

## 二、导出

| 出口 | 怎么体现 |
|---|---|
| `guji export format`（`scripts/export_guji_format.py`，legacy 与 char-cord 两种） | 这一章有缺页时另写 `NNN.gaps.json`（见下）；没有就不写，并删掉同名旧文件。**`lines.md`／`char.json` 不动** |
| `guji export md`（`scripts/render_guji_markdown.py`，Step9 稿） | 在 `#第N页` 那页正文之后单起一行注记，如 `〔原书此处缺卷九叶九、叶十，约 830 字〕` |

`lines.md`、`char.json` 是纯字流，标点、实体的锚点（`页:列:格`）和 book-text 校验器都按它数格位，插注记行会把格位算错，
所以缺页走旁挂文件。

### `NNN.gaps.json`（`guji-gaps/0.1`）

```json
{
 "schema": "guji-gaps/0.1",
 "book": "06",
 "chapter": "009",
 "gaps": [
  {"after_page": 20, "what": "卷九叶九、叶十", "kind": "原书缺", "est_chars": 830,
   "evidence": "…", "note": "〔原书此处缺卷九叶九、叶十，约 830 字〕"}
 ]
}
```

- 归章：`after_page` 在这一章的页里就归这一章（缺在章末也归本章）；`after_page: 0` 归含第 1 页的那一章。
- `note` 是文字版注记的现成写法（`kind: 未拍` 写「〔此处未拍…〕」），网站直接用。

## 三、网站怎么显示（交 A41）

- 书影：在 `after_page` 那张图之后插一张灰底占位卡，写 `what`（加估计字数），一段缺页只插一张；占位卡不占页号，页码照旧按图片页号。
- 文字版：在 `after_page` 那页文字之后单起一行 `note`，样式与正文区分；复制、纯文本下载也带这一行。
- 书的介绍页列出各册缺页。
