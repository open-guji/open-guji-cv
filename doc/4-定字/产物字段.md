# 第四步产物字段（4c、4d、收尾）

> 2026-11-28，CV4（结构拆分清单 B4）。只写字段与口径；源头是代码里的 pydantic 模型，字段有出入以代码为准，改字段时同步改本页。
> 4a `align_ref`、4b `context_decide`／`context_rank` 的产物不在本页（见 `步骤与产物.md`）；送审原因取值见 [pending_reason.md](pending_reason.md)；gate 见 [decide_gate.md](decide_gate.md)。
> 纪律（[子步.md](子步.md)）：4c、4d 只出证据，不读放行状态；收尾做全部判断。4c、4d 缺省关，关时收尾自己现算，产物逐字节不变。

## 一、4c 格况 `cell_state`（`products/kinds/cell_state.py`）

一页一份 `PageCellState`：

| 字段 | 类型 | 说明 |
|---|---|---|
| `page` | int | 页号 |
| `cells[]` | `CellStateRec` | 每格一条：`id`、`col`、`slot`、`sub`、`state`、`evidence` |
| `cells[].state` | str | `char`／`occluded`／`seal`／`seg_bad`／`non_char`（`blank` 本期不出，仍在收尾 `_blank_ink_pass`）；优先级 seal > occluded > seg_bad > non_char > char |
| `cells[].evidence` | dict | 只记看到的：`occluded`{density, default, src}、`seal_blank`{seal_score, overlap}、`seg_box`[判据]、`ink`[ink_seal／ink_speck]、`speck_half`、`ref_blank` |
| `ran` | list[str] | 本页真算了的探测器：occluded／seal_blank／seg_box／ink／jiazhu_uneven／header_formula。不在表里＝没开，收尾现算 |
| `occluded` | {格 id: [密度, 默认字, 来源]} | 遮挡探测原值 |
| `seal_blank` | [{col, slot, sub, seal_score, overlap}] | 盖章空栏候选 |
| `seg_box` | {格 id: [判据]} | 字框几何异常 |
| `ink_flags` | {格 id: [ink_seal／ink_speck]} | 只存带这两个旗的格 |
| `speck_half` | [格 id] | 墨点半格 |
| `jiazhu_uneven` | {列号: [[首格, 末格]…]} | 雙行小注分法不均的段 |
| `header_lines` | {列号: 整理本行} | 题列套语 |

读口：`by_id()`、`occluded_map()`、`seal_blank_map()`、`ink_facts()`、`uneven_spans()`、`header_line_map()`，还原成收尾各遍要的原形。

## 二、4d 字组 `group_decision`（`products/kinds/group_decision.py`）

一页一份 `PageGroupDecision`：

| 字段 | 类型 | 说明 |
|---|---|---|
| `cells[].lift` | [组 id, "lift"／"joint"] 或 None | 字组入口归属（待审口径：假定没放行、不是人裁）；已放行格的复核入口读最终放行字，不在这里 |
| `cells[].aspect` | {组 id: 宽/高} | 按组的字框宽高比证据，只给有宽高比判法、且在书的 `fold_groups` 里的组（现在只有 ry 日曰）；窄宽判与门槛在收尾 |
| `ran` | list[str] | 本页真算了的原料：`entry`、`wh`、`near:<方法>` |
| `wh` | {格 id: [宽, 高]} | 字框宽高（来自 `char_index`） |
| `near` | {方法: [{k, ev}]} | 3b `glyph_near` 看图判法原样结论的快照。键形状：普通方法 `[格 id]`；`part_shape` `[格 id, [字, 字]]`；`pair_shape`／`book_knn`／`near_knn`／`stroke_veto` `[格 id, 模型指纹]` |
| `handling` | {组 id: {methods, context, aspect, action, threshold}} | 各组处理方式的定稿快照（登记表缺省＋书级覆盖 `params.group_decision.handling`，书级不许放宽 `methods`）。本版收尾不读 |

读口：`by_id()`、`wh_map()`、`near_map(方法)`；写入用 `pack_near()`。

## 三、收尾 `char_decide`（旧名 `seed_admit`；`products/kinds/recog.py`）

页 `PageAdmit`：`n_auto`、`n_review`、`n_excluded`、`columns[]`；`alt_cols`（改用备选切法的列）、`n_code_fix`、`n_code_mismatch` 为空或 0 时不落盘。

格 `AdmitRec`：

| 字段 | 说明 |
|---|---|
| `id`、`slot`、`sub` | 格位 |
| `admit` | 放行与否 |
| `channel` | 放行（或改字）通道，如 match_solo、context、follow_ref、rr_shape |
| `char` | 这一格的字（刻本字形，照录图上的形），全流程只有这一个字 |
| `provenance` | match／align／context |
| `doubts` | 疑点标记（含 `excluded`） |
| `evidence` | 各遍证据，键按遍名：`group`、`fold`、`rr_shape`、`vis3_shadow` 等 |
| `pending_reason`、`pending_reason_detail` | 收尾直写的送审原因，只写第四步名下的值（见 pending_reason.md）；别的类留 None，由 manager 判 |
| `form_src` | 选形来源：lib／ref／group／code_table／human |

`pending_reason`、`pending_reason_detail`、`form_src` 三项为 None 时不落盘，旧产物逐字节不变。

## 四、改字段的规矩

- 改 4c、4d 或收尾字段，事先用 `send.py` 告诉 GM2–GM4，并改本页。
- 加字段要缺省不落盘或缺省关，保证关时逐字节不变；动了 code_deps 的，合 dev 前把分支名发给 GM2 跑 manager 全套。
