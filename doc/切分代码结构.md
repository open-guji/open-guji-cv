## 二、原语库 `seg/` 有什么

| 模块 | 内容 |
|---|---|
| `lines` | 投影、半高宽找峰、倾斜投影、位置＋角度联合搜一条直线；整页找竖线 `find_vertical_lines`、上下框线 `find_horizontal_border` |
| `grid` | 网格模式：列数已知、列距均匀时逐槽验线、缺槽插值（`find_vertical_lines_grid`、`grid_thresholds`） |
| `polyline` | 界行按弯度拟直线或三段折线（`fit_vlines_polyline`） |
| `frame_types` | 边框结果的数据类型（右上原点的 HLine／VLine／HeadRaiseBorder／BorderDetectionResult） |
| `warp` | 单列射影矫正（`warp_column`）、列窗口（`page_column_windows`） |
| `profile` | 列图去噪、横纵投影、文字带（`denoise_column`、`column_profile`、`column_row_profile`、`column_text_band`） |
| `seam` | 最省墨走缝、缝上墨量、缝外抹白 |
| `cut_select` | U-Net 切点裁判与引导缝 |
| `locate_gutter` | 找书口 |

## 三、各套书怎么做自己的切分

1. **只 import `seg/` 和自己目录**。套书之间不互相 import，`seg/` 不 import `books/`（`tests/test_architecture.py` 守着）。
   想用别的套书的某段代码：复制进自己目录再改，不要跨目录 import。
2. **页型怎么认、哪里用参数、哪里写函数，套书自己定**。个别册的细调照旧写册 yaml。
3. **改共用 Step 里的某个实现**：把那个缺省模块复制进 `books/<套书>/`，在 `core/seg_set.py` 的 `OVERRIDES[<套书>]`
   登记「缺省模块 → 自己的模块」。Step 壳和产物指纹都按这张表换（史記的 roster_* 就是这样）。只改自己那份，别的套书的产物不过期。
4. **新书**：先看它像哪一套。像就在册 yaml 写 `seg_set: <套书>`；版式差得远就新建一套——复制最接近的一套，
   在 `core/seg_set.py` 的 `SEG_SETS` 登记，写自己的 `samples.yaml`。新建套书要动 `core/seg_set.py`，这一步找架构维护人。
5. **样页单 `books/<套书>/samples.yaml`**：10–30 页，每页写为什么在单上（修过什么问题）。册换图源、页号重编后跟着改。
6. **改完怎么验**：
   ```bash
   python scripts/seg_samples.py affected --base origin/dev      # 这次改动牵动哪几套书
   python scripts/seg_samples.py submit --set affected --base origin/dev --cv <你的分支> --why "…"   # 交任务库，每册改前／改后逐页比
   python scripts/seg_samples.py local --set <套书> --ws <册>=<工作区>                             # 数据只在本机的书
   ```
   只说哪些页变了，变得对不对要看图。只牵动自己这一套就自己判、自己合；牵动了别的套书，说明碰到了共用代码，找架构维护人。

## 四、什么时候找架构维护人

- 改 `seg/` 里任何函数的行为（修原语的 bug 也算）——要跑**全部**套书的样页、每个变化点名；
- 往 `seg/` 加新原语（两套书以上要用、或明显通用的看图操作）——原语参数写在签名上、带自造数据的单测、**只加不改**；
- 改 Step 壳、`core/seg_set.py`（新建套书、加 OVERRIDES）、产物指纹（`core/engine.py`、`core/code_equiv.py`）、`tests/test_architecture.py`；
- 搬家、拆模块（要登记 `code_equiv` 的 MOVED／SPLITS 才不让各书产物过期，工具 `scripts/seg_move.py`）。
- 新建套书、从别的套书分叉模块：复制进来的模块登记 `code_equiv.FORKED`（原模块还在，复制没改过时按原模块名进指纹，这套书的产物不过期；之后改了自己那份照常过期），守卫 `tests/test_seg_fork.py`。

其余——在自己目录里改算法、调参数、加页型分支、改样页单——各套书自己做。

## 四之二、套书的缺省参数与选管线（2026-11-03，管线重组方案 B 第一期）

- 册 yaml 写 `seg_set:` 就够了：走哪条管线由 `core/seg_set.SEG_SET_PIPELINE` 推（旧写法 `pipeline:` 仍认，且优先）。
- 同一步在这套书下的缺省参数写 `books/<套书>/defaults.yaml` 的 `params:`（形状同册配置 `params:`）。
  参数层（低 → 高）：Step 默认 < 管线 yaml `params:`（现已搬空）< 套书缺省 < 基础配置 `book_defaults.yaml` < 册 yaml < 运行覆盖。
  `guji book show --effective` 逐字段列来源层。
- **骨架＋槽位**（第二期）：步骤顺序只在 `pipelines/_skeleton.yaml` 写一遍（Step0、`layout`／`seals`／`columns`／`cells`／`recognition` 五个槽位）；
  各链 yaml（`keben_body_v2`、`modern_body`、`keben_free`）只写槽位里放哪几步，`core/pipeline.load_pipeline` 按骨架展开。展开结果与改动前的 `steps:` 逐项相同，步骤 id、产物目录、指纹都没动。
  新增共用 Step 改骨架一处；新增一套书的链 = 新建一个只写槽位的 yaml（`layout`、`columns`、`cells` 必填）。链里写错槽位名会报错，不会悄悄不生效。
- Step 壳按套书拆开的现状没变：`border_detect` 是殿本的 Step1、`line_detect` 是北行的、`block_detect` 是幼學的，各自 import 自己套书的代码。
- 幼學 Step4 以后（`free_cells` → `cells`、列图）还没接：本书没有语料与字形库，先把切分做对；要接时在这里补转换。

## 五、现状与遗留

- Step1／Step2 的壳目前直接调殿本的 border／column（各套书共用这一份调度）；哪套书要改，按第三节第 3 条复制＋登记覆盖。
- Step0（页面预检、反色带、印章定位）与 Step4（紧框）各套书共用，参数按册配。
- `column_crop`（北行现代本 Step2）的指纹表里还列着殿本 column：为了搬家时指纹不变才留的，摘掉时那一步过期一次。
- `utils/daizhige`、`utils/page_align`（整理本对齐，殿本、史記共用）还在 `utils/`。
- 幼學的 free_* 还没改调原语（它自带的找线、走缝与 seg/ 有重复），以后它自己改时可以换成调 seg/。
