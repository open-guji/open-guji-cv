**两个字的用法**
- 未：①否定副词，「尚未、還沒有」：未見、未嘗、未免、未能、未及、未詳、未可、未必、未成、未盡、未發、未備、未刊、未經、未知、未幾、未易、尚未、猶未、亦未、皆未、所未、雖未、而未、偶未；常作「X 未 + 動詞」；②地支第八位（紀年、紀月、紀時）：乙未、丁未、己未、辛未、癸未、未時，**前一字是乙丁己辛癸**；③「未有」＝「還沒有」，後面接的是**所缺之物**（未有序、未有刻本）；若後面接的是具名的跋、序、識語（如「有克跋」「有某某序」），則是「末有」（卷末附有），字是「末」。
- 末：①末尾、末端、後世：始末、本末、卷末、篇末、書末、序末、末流、末學、末葉、末年、末技、末節、末簡、明末、宋末、元末、唐末、漢末、季末、晚末、之末（「…之末」＝…的末尾）；②末後附記：末附、附於篇末；③「本末」「終始本末」連用。

**判断要点**
- 「末」多是名词（后面常接「流、學、年、葉」，前面常有「始、本、卷、篇、之」）；「未」多是副词（后面接动词，如「見、嘗、能、免、詳」）。
- 「之末」「其末」「後末」等歧义处，看后文：后文是动词、否定意味 → 未；后文是名词性（如「亦有…者」）或句点收束 → 末。
- **「此本末有克跋」「卷末有某序」「是本末有識語」**：這裡「末」是位置詞（某本的末尾），「有」後接具名的序跋，字是「末」，不要因為看到「有」就判成「未有」。判法：把「未／末」換成「卷末」讀得通、且後面是具體的序跋人名 → 末。
- 干支必成对：前一字是天干乙丁己辛癸且上文是年號紀年 → 「未」；前一字是甲丙戊庚壬则不可能是「未」（那是「戌」「午」…）。
