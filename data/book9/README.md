# data/book9

数据来源：《欽定四庫全書總目·卷首一~卷首四》影印本（浙江大学图书馆，
China-America digital library project，原格式 DjVu/TIFF，共 206 页）。
本目录为其中卷首一正文 10 页（原书第 10~19 图）。

**与 data/book5 是同一部书（四库全书总目）的不同册**——适合验证
跨册字形库复用（同版同字直接命中）。

## 排版信息
页面类型：单面半页（已裁切，每图一个半页）
边框：有双层边框，内层较细，外层较粗
边框磨损：轻微
界行：有界行，完整
行数：每页9行（与 book5 的 8 行不同——同书不同卷版式有别）
版心：在页面一侧，窄列，含书名/卷次/页码小字
颜色：灰度扫描
页边距：四周有白边，右上有书名条（栏外元素）
干扰项：影印噪点

## 文字信息
印刷：刻本（写刻），排版整齐
字数：每行二十一字
是否严格按字数排列：是（抬头/结尾有空格，如"欽此"后整列空）
每个字占据高度是否一致：是，且**跨列行位置对齐**（整版同刻）
是否有夹注：无
