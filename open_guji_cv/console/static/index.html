        O 现切点正确 · G 绿色折线缝已正确（直接记为折线金标）· V 上下字重叠、切在哪都伤字（线放折中处）· S 拿不准 · ←/→ 翻卡 ·

        U 重做已落定的卡（取消勾选「只看未裁」能看到已裁的卡，改完再落定，后到覆盖）。蓝色虚线 = 现役直线切点，绿色虚线 = 现役折线缝。
        每次落定立刻写入事件，刷新不丢。
      

      

    

  

  

    

      
本书用字账 这本书刻了哪些异体、整理本印成什么；只读，由 scripts/build_book_variants.py 派生

      

        
        
        
        
      

      

        计数读法：刻本形下标是本书刻了几次（products + glyph.db，扣掉 v1 整理本贴标的 align），「·人N」是其中人裁确认的；
        整理本形下标是整理本印了几次；转换对是自动或人裁把「刻本形→文意」记下的次数。
        整理本一栏：single = 整理本对这组只用一种形（它定义不定形，形只能来自图像）；multi = 整理本自己在区分（它的字兼作形证据）。
        分型是关系层的先验（T1 纯异体 / T2 互通·一对多 / T3 形近·通假·仅简繁），最终由这张账定。

        红虚框 = 义定形未定（待审）。单击 = 选中（蓝框），选中后才好按键；
        双击 / 空格 / ←→ = 挪列改形。提交时每格记 shape（所在列）+ reading（整理本字），两者不同即一次转换。
        选中后可按：O 组外（两个形都不是，如标 蠹 实为 𥗤——扔进下面那栏再填字） ·
        N 非字 · T 字形不完整 · C 有噪声——后三个是「这块图不能用，不是认错字」，
        提交后写进金标与排除名单，这一格以后不进库也不再出卡（重扫后可按名单逐条复核放回）。
        「照准全部」把已自动放行的也确认一遍——那就是字形保真率的抽审。
