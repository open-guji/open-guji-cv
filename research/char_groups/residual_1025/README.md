# 已有字组残留送审清理（铺开 #9，A24 2026-10-25）

范围：sb ly dian em can mb wj rr，并入 zheng（徵徴）与 fc（傳傅）一格错放。产物：殿本 vol06–20 的 v0.5.12 重落包（vol16/17 当时只有 v0.5.9p42）。

| 脚本 | 做什么 |
|---|---|
| `census2.py` | 数各组残留送审格（整理本字、坐标对位字、库候选、进流程方式） |
| `sheet.py` | 看图页：本格放大＋同列前后各 3 格（bbox_page 原点在右上，按页宽镜像 x） |
| `corpus_bt.py <组,…> [规则目录]` | L1 规则对整部整理本（中心库 `corpus/zongmu_wenyuange_wikisource.txt`）逐处回测，列每条规则的冲突 |
| `replay.py <产物根> <out.jsonl> --vols … --all [--rules-dir]` | 离线回放：撤回组流程改动，按现行（或指定）规则与代码重跑全部字组，只记本次几组 |
| `cmp.py A.jsonl B.jsonl` | 两次回放逐格比：各组送审数、变了的格 |
| `summ.py`、`glyph_eval.py` | 回放结果汇总；字形方法反对票与人裁／整理本比 |
| `zheng_eval.py`、`zloo.py`、`zheng_cells.py` | 徵徴：线上同款字块评人裁格、按册留出定改字门槛、列产物里的降审格 |

做法与结论：
1. **文意 L1 规则**：组员字在整部整理本里每处都跑一遍规则，冲突逐条看文意。改到冲突只剩整理本自己错为止（採進木、凡有二木一本等）。各组改动见 `doc/字组/<组>.md` 10-25 条。
2. **回放**（vol06–20，组流程送审）：ly 19→16、mb 61→53、rr 33→21、sb 8→6、wj 14→12、zheng 35→13，can dian em 不变。变了的格都看过图，0 错（vol06–10 当留出册）。
3. **影子闸**：同义组已按刻形定码位（can 參㕘叅 15 格），或形近组补放时整字 HOG 过门槛给字（傳傅等 8 格），影子挑同组另一字时不再降审。后一类原来降审后被坐标兜底按整理本放错 6 格。
4. 剩下的送审多数不是组的问题：卷端「欽定四庫全書總目卷X」题名格被印章压住、乱码页、组外候选。
