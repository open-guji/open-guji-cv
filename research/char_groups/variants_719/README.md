## 脚本

| 脚本 | 做什么 |
|---|---|
| `libcheck.py <glyph.db> <输出 tsv>` | 库里每个刻例：库标在有模板库的同义组里 → 用该组在线判法（`ids_online.judge`）判库存字块；殿本只一种刻法的对（`ONE_FORM`）直接按刻形改。只列不一致的 |
| `relabel.py <已核 tsv> <批名> <输出 jsonl>` | 看图确认过的行写成 glyph_audit relabel 事件（格式同 A23 批 H-A23-719-variants-1024） |
