# page-geometry 金标迁移（M1·D 道，2026-09-30）

## 结论先行
- **金标不能原样保留。** 「金标在图像里、不会过期」只对一半：界行确实是图像性质，但旧金标的 x 量在
  **v1 预处理输出帧**（`output/<册>/<页>.png`：透视校正 + 裁到版框）上，不是原图坐标。
  核实：39 页金标的 `image_size` 与工作区原图尺寸 **39/39 页都不同**（如 vol01/101 金标 1717×2474、原图 2353×3053）；
  在云端用仓内 v1 `NormalizePreprocessor+CropMarginPreprocessor` 重放（补了 cv2 5.0 的 LSD 返回形状垫片）只有 2/39 页尺寸吻合，
  v1 帧**不可复现**，也就没法用一个固定变换把旧坐标搬到原图。
- 所以做法是**按图像内容把旧金标搬到原图帧**（旧金标只当「哪几条线是界行」的人工确认来源，位置全由原图像素重新量出）。
- 结果：39 页 → **30 页迁移成功**（旧 285 条界行中 243 条在原图上验证保留），**9 页无法可靠迁移**（旧金标在 `items.jsonl` 里标 `stale` 留档，评测不读）。

## 判据（全程图像内容，不用任何 v2 算法输出 / 不用算法一致性）
脚本 `migrate_geometry_gold.py`（旧金标必须用 `--old pre_migration/` 或 git 里的 v0.3.0；默认路径指向数据集仓，迁完后会被覆盖）：
1. **梳子定位**：旧金标 12 条左右界行（列距≈184px 的等距模式）当模板，在原图中段（±4% 页高）的墨列投影上做 (缩放 a∈[0.98,1.02], 平移 c∈[200,460]) 互相关。
   30 页无歧义页实测 a≈1、c 落在 256~390（= 原图里版框左缘位置，与 v1 「裁到版框」一致）。
2. **版框左缘先验**：原图中段竖向腐蚀后最左的长竖线 xL；旧最左界行 x<40 时它就是版框左缘，要求 |c−(xL−x0)|≤30（c 与先验矛盾的页排除）。
3. **歧义判据**：选定解 ±25px 之外若有得分 ≥0.88×选定解的另一平移解，且无先验佐证 → 排除；得分<0.5（无先验）或 <0.45/竞争≥0.9（有先验）排除。
4. **采样高度**：金标高度定义是「版框内竖直跨度的 16/50/84%」（v1 帧裁到版框，所以等价于旧的页高 16/50/84%）。原图里版框占页高约 9%~91%，
   直接取原图页高 16/84% 会落到抬头/天头带里（实测全崩），故先沿每条线（±7px）找「≥50% 界行有墨」的最长连续段当版框跨度 `frame_y`（多数页落在 2440~2520，与旧金标图高吻合），异常页（跨度不在 2300~2650）退回册级典型 (285, 2775)。
5. **逐高度脊线拟合**：每条旧界行在 3 个高度各做局部脊线拟合（带内斜率 −0.03..0.03 逐档剪切，取覆盖率最高的 x，带半高 4% 版框高，搜索半宽 30px）；
   覆盖率 <0.45（与原建集 `COV_T` 相同）判「图上没有这条线」丢弃。
6. **形状护栏**：三点相对偏移与旧金标之差应随页基本一致（= 原图相对 v1 帧多出的整页错切），偏离页中位数 >12px 丢弃（抓「某一高度锁到字笔画上」：迁移初版 vol02/136 有一条 x_top 偏 45px，评测里暴露，加此护栏后消失；共 26 条因此丢弃）。
7. 目视抽查叠图（vol01/101、vol01/164、vol02/60 的红点全落在界行上；vol02/46、vol02/163 在初版里梳子锁错——红点落在字上——正是被判据 2/3 排除的那批）。

- `items.jsonl`：30 条 active（`input.migrated_from`、history=migrated）+ 9 条 stale；`metadata.json` version 0.4.0；`README.md` 加更新说明（旧基线折叠留档）。
- 本目录：`page-geometry/`（迁移后的完整分片，可整体覆盖数据集仓 `page-geometry/`）、`pre_migration/`（旧 samples + 旧 report.json + 旧 items.jsonl）、`migration_log.json`（逐页 a/c/得分/丢弃界行明细）。

## 评测改动（不碰算法默认值）
- `scripts/eval_geometry.py`：改读 v2 `column_windows`（Step2）→ `ColumnMapper`（与 Step3 `quad_page` 同一映射）回原图，金标三高度上取列带 [左,右]；原图读 `book.raw_path`；尺寸与金标不符/缺产物的页**列出并跳过**，全部跳过时退出码 2（不再静默 0 页）。
- `open_guji_cv/clustering/geometry_eval.py` 新增 `compare_page_v2 / evaluate_v2`（v1 函数原样保留）；指标差异：
  - 列框：v1 竖直矩形 (left_x,right_x) → v2 每列文字带四边形，按金标高度取区间（折线/射影页天然支持）；
  - **shear 不存在**：v2 每列各有射影；`residual_tilt` 改为「界行相对其最近列带边缘的水平偏移，在三个高度上的极差」（= 界行在 v2 列带坐标里还剩多歪），旧定义（金标点去错切后三点极差）不适用，金标自身未矫正的极差另报 `raw_tilt`；**与 v1 的 4.0px 不是同一个量**；
  - `outside_ink`：窗口 = 金标界行 x 跨度 × `frame_y`（v1 是「已裁到版框的整页」），最外列带端取金标中高处；
  - 新增诊断 `clearance_*`（界行点到最近列带边缘的距离）——`rule_in_col` 触底 0% 后仍有分辨力。
- `registry.py` geometry 行：`needs` 去掉 `v1_output`，加 note。
- 一致性核对：列带区间 vs Step3 `quad_page`（vol01/149、33、40、66）最大偏差 1.4px。
- 负对照（验证指标有分辨力）：列带右移 6px → rule_in_col 4.8%，右移 12px → 84%，加宽 8px → 59%，左移 12px → 77%。

## 已知局限
- 金标只剩 30 页 / 243 条，且 vol02 只有 12 页；小样本，`rule_in_col` 已触底。
- 迁移后金标是「人工确认过界行身份 + 图像重新定位」，位置不再是人工拖的；未做逐页人工复核（只抽查了叠图），如需升格 `label_origin: human` 要人看一遍。
- `eval --from-raw` 的缺产物判据是 Step3（`has_products` 查 row_segment），geometry 实际只需要 Step2；会多补一遍 Step3（13 分钟里大半是这个，且 CPU 被同伴占满），没改 runner。
