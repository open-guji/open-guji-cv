## 测什么

页面在扫描/刷印中会变形。deskew 把**横线**摆平了，**竖线**未必竖：

- **错切**：所有界行同向斜，彼此平行；
- **射影**：界行还会**收敛**（斜率随 x 变），列距也沿 x 渐变。

列框是竖直矩形，跟不上斜线——要么把界行圈进图块（下游「混入」缺陷的
最大单一来源），要么让出漂移量把字裁窄。本数据集把这层几何**单独拎出来
量**，不再只能靠下游 flag 率间接推断。

## 金标：界行在三个高度上的 x

每条界行记它在页高 **16% / 50% / 84%** 三处的 x。一条线三个点，同时钉住
三件事：

- 它在哪 —— 列边界的直接证据；
- 它斜不斜 —— 三点不齐 = 有错切/旋转残余；
- 全页的线平行还是收敛 —— 斜率随 x 系统变化 = **射影**。

只记中点的话后两件事就没法判，而它们正是「该做错切校正还是该上射影
矫正」的判据。

## 金标为什么不会过期

金标是**界行在图像里的位置**——图像自身的性质，算法怎么改它都在原地。

对照 [`char-segmentation/instances`](../char-segmentation/instances)：那里的
金标挂在 `page:col:idx` 上，切分一改就漂，实测两轮分别废掉 15 个和 59 个
标注，只能全量重标。本数据集从设计上没有这个问题。

候选由「这条横带里有没有一根够长的黑竖线」这个**弱判据**自动生成——它不是
被测对象（被测的是错切估计、周期/相位拟合、将来可能的射影矫正），所以不
构成循环论证。39 页逐页目视确认：标出的线都落在真界行上，无误标。

## 第二个指标：外侧漏墨

`rule_in_col` 管「界行有没有被圈进列框」，但它管不了「有没有整列被排除在
网格之外」。后者要单独量：**落在最外侧列框之外的字墨比例**。

它不需要金标——是图与管线输出之间的直接关系，可以在任意页上算。

**只算外侧、不算列间缝**：缝里本来就有笔画外溢与内缩留白，算进来会淹没
信号（全书框外字墨中位 10.5%，外侧漏墨中位才 2.7%）。

### 它推翻了「列数不对 = 丢整列」的判断

18 页切出 7~8 列，直觉上是丢了整列。实测：

| | 外侧漏墨中位 |
|---|---|
| 非 9 列页（18 张）| **1.97%** |
| 9 列页（369 张）| **2.79%** |

**非 9 列页反而更好**，漏得最多的（最高 14.1%）全是 9 列页。列数是个很差
的危害代理量，这个才是。

追下去两个子原因：

1. **13 页被上游裁窄**——图宽 1460~1530（正常 1696，差整整一个列距），
   而且**图上真的只有 8 条文字带**（正常页 9 条）。少的那一列在图上就不
   存在。也不是把字切断了：图像左右边缘 25px 内的字墨，窄页 0.06~3.0%，
   相邻正常页 0.05~3.7%，没有差别。
2. **4 页梳子起点偏移 1~5 个列距**——相位原先由文字带的 `content_range`
   锚定，而卷尾页左侧整片**空列**（有界行、无字）会被当成「没有内容」
   跳过，梳子于是从版面中间起步（vol02/38 起点落在 x=981，图宽 1714）。

修法：(2) 加列梳子夹逼（跨度刚性 → 起点自由度只有 `W - span`），4 页全部
修复；(1) 不硬凑 9 列，按装得下的列数切并标 `narrow_page`——真正该修的是
上游裁切，这里只如实反映。

## 更正：剩下的不是射影，是内缩塌陷

上一版据此断定「剩余失败集中在射影页」。**那个结论是错的**，更正如下。

3 张坏页（vol01/166、174、198）的 `inset_l` **只有 6px**，而正常页 28~38px
——列框贴着界行走，界行必然被圈进去。全书量下来：

| | `rule_in_col` 均值 |
|---|---|
| 有一边 `inset` <15px 的 69 页 | **0.083** |
| 其余 318 页 | **0.006** |

差 14 倍，相关系数 −0.346。加了**书级内缩共识**（内缩和格高、列距一样是
物理刚性常量）之后：`rule_in_col` **5.00% → 0.57%**、坏页 **3 → 0**，
**没有动任何射影矫正**。

此前把 `foreshortening` 与失败率的 +0.59 相关读成了因果。实际是**共因**：
目录页界行稀疏，既让内缩量不准，又让列距渐变的估计噪声变大。

代价记账：外侧漏墨中位 3.52% → 4.07%（目录页 7.69%），逐格字墨外溢从中位
1.09% 升到 1.29%（均值不变）——用「列框离界行更远」换来的，可接受。

## 原始发现（保留备查）：错切修完之后的相关性分析

**问题**：残余形变是错切还是射影？要不要按内边框四角做单应矫正？

**回答：要。** 错切与列距两个问题修掉之后，剩余失败集中在射影形变的页上：

| 量 | 与「界行落框」的相关系数 |
|---|---|
| **列距渐变** `foreshortening` | **+0.59** |
| 斜率随机散布 | +0.28 |
| 残余倾斜 | +0.11 |
| 斜率收敛 `projective_span` | +0.03 |

| 分组 | 界行落框 |
|---|---|
| 判为射影的 16 页 | **10.2%** |
| 非射影的 23 页 | **1.9%** |

3 张坏页（vol01/166、174、198）**全部**是射影页，非射影页里一张坏页都没有。

**但射影是必要不充分条件**：16 张射影页里有 10 张零失败。所以矫正的收益
上限是那 3 张坏页（全书 5.29% → ~1%），不是全部射影页。

### 一条测量教训

同一份分析，在 vol02 切分**未同步**时跑过一版，得到的相关系数是 **−0.09**
（看起来射影完全无关），结论正好相反。上游产物没对齐时，相关性分析会
给出反向结论——跑这类分析前必须确认所有分册是同一版。

### 剩下的侵入有多浅

被圈进列框的界行采样点中位探入 **7.5px**，64% <10px。界行本身宽 5px，
多数是贴边级浅侵入。靠加余量继续压要拿列宽换（现列宽 119.8px、格高
114.4px，只剩 5px 余量）——所以下一步该矫正几何，而不是加余量。

## 下一步

按内边框四角（或更稳健地：竖线灭点 + 横线灭点，用整页 9~10 条界行拟合，
比 4 个角点抗残损）估单应，把版面矫成矩形。本数据集可以直接评测它：
矫正后重跑 eval，看 `rule_in_col` 与 `residual_tilt` 降多少、3 张坏页是否
转清。**收益上限已知（5.29% → ~1%），不必凭感觉决定做不做。**
