# 字形套（glyph sets）长期方案：网络只学"看形"，套只管"谁像谁"

> 2026-09-05。用户提出：同一套书字体相似、异体用法一致；同时代、同字体相似。不想用一个
> 大杂烩训练集喂一个模型；字形库要分套（Jigmo 一套、四库总目一套、以后每书一套），带
> 字体/朝代/抄手等元数据；新书来了找最相关的套匹配、多套按形关度加权、当前书权重极高。
> 现在数据小，必须靠 Jigmo 全覆盖。疑问：怎么让网络适应不同套又不总重训。
> 本文 = 长期架构 + 今天四个小实验的实证 + 近期不改算法的动作清单。
> 论文依据见 `zero_shot_ccr_survey.md`，实验台账见 `ocr_engine_and_zero_shot.md`。

## 0. 一句话

**一个共享的度量网络 + 多个可插拔的原型库（套）。** 套放在索引层，不放在网络层：
加一套、换一套、给套加权，都不碰网络权重；重训只在"新风格在冻结基准上掉到阈值以下"
时做，而且是多风格一起训，不做每套一个网络。

## 1. 为什么"套"应该在索引层，不在网络层

用户担心的"无关字形污染训练集"，对两种用法的影响完全不同：

| | 分类头（训一个 4,636 类 softmax） | 原型检索（embedding 对模板最近邻） |
|---|---|---|
| 训练集里多了别的风格 | 决策边界和类先验被改，**会污染** | 只让度量更风格不变，**是好事** |
| 换一本新书 | 类表不同要重训 | 换原型库即可，不重训 |
| 限定"只在这本书的字里找" | 做不到（softmax 对全类） | 天然：候选 = 该套的原型 |
| 当前书权重极高 | 做不到 | 该套的名次表权重最大 |

我们现在已经是检索为主：embedding 单源比分类头高（94.5 vs 93.3），三源融合里它权重 3。
所以架构上要做的只是把"模板库"从"4 套字体的均值"推广成"若干套、各有元数据和权重"。

文献里这条路已经被验证：CoLa 用每类 10 张模板做原型分类（历史文献 57% vs CCR-CLIP 22%）；
CCR-CLIP 把冻结的原型矩阵当分类头，新字免微调；EASA 给每个未见类 1 张真实样本，24% → 92%。
它们都是"网络固定、原型可换"。

**度量网络的训练集反而应该尽量杂**：越多风格，学到的越是"这两张图是不是同一个字"而不是
"这张图像不像四库总目"。污染的说法只对分类头成立。

## 2. 今天的小实验（不改算法、不训练，只在 embedding 空间做检索）

脚本在会话草稿区 `exp_glyph_sets.py`；网络 = 现役第五轮 checkpoint；候选 = 整理本字表 +
基准里的字（4,654）；异体算对。top-1 / 5 / 10。

### E1 本书真刻例原型 vs Jigmo 字体模板

| 设定 | 字体模板（现役） | 加本书原型（w=1） | 加本书原型（w=4） |
|---|---|---|---|
| seen_test 2,621（类在训练里见过） | 99.7 / 100 / 100 | 99.7 / 100 / 100 | 99.7 / 100 / 100 |
| unseen 里恰 2 例的 305 类，1 例当原型 | 97.4 / 99.0 / 99.7 | **98.0** / 99.0 / 99.7 | 96.7 / 98.7 / 99.3 |
| mid 278 类，1 例当原型、671 例测 | 97.9 / 99.4 / 100 | 97.9 / **99.9** / 99.9 | 97.8 / 99.6 / 99.6 |

**读法**：对这本书，网络训练时就见过它的风格，字体模板已经够用；加真刻例原型 1-shot 只
+0.6，权重太高（4）反而掉。EASA 的 24 → 92 是在"网络没见过这种风格"的前提下发生的，
我们不在那个处境。

### E2 字体与本书的形关度

| 字体 | 与本书 658 类原型的平均余弦 |
|---|---|
| I.Ming | 0.995 |
| Jigmo | 0.994 |
| Jigmo2 / Jigmo3（扩展区） | 0.971 |

按形关度加权（幂 1 / 4 / 16）：96.8 / 96.7 / 96.6，等权 96.8；只用最像的 I.Ming：**95.6**。
**读法**：形关度能算出来（这就是将来"套间相似度"的算法），但在字体这一层加权没有收益，
单一最像字体反而差——**多样性比相似度值钱**。

### E3 线性适配器（不重训，最小二乘把一个空间映到另一个）

模板侧"字体 → 刻本空间"：94.1（比不适配的 96.8 差）；两者相加 96.8（持平）；查询侧映射崩掉。
**读法**：刻本与字体在现役网络里已经对齐，没有"风格鸿沟"可以用线性层填。这是训练时
把真刻例和字体同类混训的结果。

### E4 同一套书的另一册：vol02 dev_set 12 页用现役管线重跑

vol02 旧产物是早期管线跑的，人审率 16.3%。重跑结果：**见 §2.5 补记**。这是"同一套书
字形相似"最直接的实证：网络和字形库都只见过 vol01。

### E5 异体偏好：60 页里能挖出什么

放行记录里字形 ≠ 文意的系统性对只有 6 组：

| 刻本字形 → 整理本文意 | 次数 |
|---|---|
| 卽 → 即 | 17 |
| 彚 → 彙 | 10 |
| 㫖 → 旨 | 5 |
| 厯 → 歷、櫽 → 檃、𨽾 → 隸 | 各 1 |

金标层 68 组里 21 组是异体，其余 47 组都是 1 次的零星错例。**读法**：一本书的异体偏好
表很短、很尖（三组占 90%），完全可以自动导出；但它是先验不是规则。

### 2.5 补记：vol02 用现役管线重跑（网络、字形库、金标都只见过 vol01）

| 批 | 自动放行对整理本 | 人审率 | 备注 |
|---|---|---|---|
| vol02 旧产物（早期管线，188 页） | — | 16.3% | 对照 |
| vol02 dev_set 12 页（特意挑的难页） | **1520 / 1520 = 100%** | 8.8% | 12 页里 9 页判为挤排 |
| vol02 普通页 p10–21 | **1737 / 1737 = 100%** | 5.1% | 1 页挤排 |
| vol01 普通页 p15–26（对照） | 100% | 0.5% | 同一管线 |

**读法**：同一套书的另一册，自动放行的准确率原样迁移（两批 3,257 字零错），"同书字形
相似"成立。人审率比 vol01 高 3–5 倍，96 条人审里 94 条是「库 unsure + 上下文 margin 不足」，
85 条是 OCR 首选与整理本不一致（34 条完全不同、31 条形近如 檢/儉、墜/堅、漢/渡）；
库的覆盖度中位 0.947 并不低，是拿不准而不是没见过。所以差异来自 OCR / 切分在新册
上的表现（含双行小字位），不是字形套的问题；系统保守是对的（A 100%）。这批人审完
才能定是哪一层的账，先不动算法。

## 3. 长期架构（五层，从下往上）

### 层 1 度量网络（一个，版本化）
- 现役：小 ResNet，256 维，第五轮 checkpoint；指纹进产物（换网络相关产物自动过期）。
- 训练集 = **所有套的真刻例 + 字体渲染 + 退化增广**，风格越杂越好；不做每套一个网络。
- 换网络时所有套自动重新 embed（15k 样本几秒，10 万字字体渲染约 1 分钟，已有磁盘缓存机制）。

### 层 2 套（glyph set）
- 定义：`{set_id, 元数据, 样本引用, 原型索引}`。元数据字段 glyph.db 的 `sources` 表已经有
  （`edition_tag / script_style / era / kind / collection / title / volume`），
  **2026-09-06 已填**（见 §5.1）。
- 现有的套：Jigmo 四字体（其实是 4 个子套，E2 证明等权最好）；武英殿《總目》一套，
  下辖 `vol01` 与 `v2` 两个 source（**`v2` 是同书同页的 v2 管线产出，不是第二册**）；
  vol02 进库后才是这个套的第三个 source。
  注意 `edition_tag` 现在被当成 source 标识用，表达不了"同套多 source"，见 §5.1 第 2 点。
- 原型索引文件：`cache/glyph_sets/<set_id>_<ckpt指纹>.npz`，与现有 `emb_<key>.npz` 同机制。
- 一个字在一个套里 = 该套所有已确认实例的均值向量（`glyphs.n_confirmed` 已在记）。

### 层 3 套选择与加权
- 现有 RRF 三源就是雏形：每套出一份名次表，`rrf(..., weights=)` 融合。
- 权重初值（规则，不学）：当前书 4 ／ 同版本其它册 2 ／ 同时代同字体 1 ／ Jigmo 0.5。
  E1 说明当前书权重不要超过字体太多（w=4 反掉），初值从 2 起调。
- 形关度 = 两套在共有字上的原型平均余弦（E2 的算法）。等有第二种风格再校准权重表。
- 候选召回分层沿用现在的两级字表：本书字表 → 整理本字表 → Unicode 全集（Jigmo 套负责
  全覆盖召回，本书套负责精排——GL-HPN 的粗召回 → Top-K 精排）。

### 层 4 异体偏好表（每套一份）
- 从放行记录自动导出 `config/variants/<edition_tag>.json`：`{字形: {文意: 次数}}`。
- 三个用处：(a) 定字时 `reading` 的默认推断；(b) 候选排序先验（本书常用 卽 就把 卽 排在
  即 前）；(c) 新书按时代/版本继承最近的表当初值。
- 现有 `variants/` 与 `are_variants` 是"是否异体"的通用知识；偏好表是"这本书用哪个"，两层。

### 层 5 字符集策略
- 默认候选 = Unicode 全部汉字（Jigmo 能渲染），按套分层缩小。
- 没有 Unicode 编码的刻工写法：走 IDS 文本锚（调研 §五.B），这是唯一对口机制；GlyphWiki
  的部件描述可机械转 IDS（许可待核）。

## 4. 什么时候重训，怎么判断"数据够不够"

- **触发条件（量化）**：一个新套（新书/新风格）进来，先不训，只做 embed + 原型；在它的
  dev 页上量 0-shot（只字体模板）unseen top-10 与 1-shot top-1。低于 97 / 95 才把它的真刻例
  加进训练集重训一轮（1 小时）。同版本另一册（vol02）预期不触发。
- **过拟合的判断**：现役网络对 1,022 个训练里没有真刻例的字做到 95%，说明它学的是形状不是
  背样本；风险在"只见过一种风格"。所以下一本不同风格的书（抄本、影宋本）才是真考题，
  vol02 不是。
- **数据再多能否看出效果**：已做（台账 §2.13）。真刻例取 25 / 50 / 100% 各训 40 epoch：

  | 真刻例用量 | 分类头 unseen top-1 | emb 检索 top-1 | 三源 rrf |
  |---|---|---|---|
  | 25% | **88.3** | 92.3 | 93.2 |
  | 50% | 86.1 | 92.3 | 92.5 |
  | 100% | 84.0 | **92.6** | 93.2 |

  **分类头随真刻例增多而退化 4.3 点**（真刻例只覆盖 658 类、字体渲染覆盖 4,636 类，
  占比失衡让网络偏向背熟已见类）；**embedding 检索与三源融合完全不受影响**。
  结论：现有做法安全；"多跑几册"对当前算法既无害也无益，**真刻例的正确用法是当原型
  而不是当训练样本**——这正是 §1 的论点，现在有了本地实证。

### 5.1 补记：动作 2 已落地（2026-09-06），以及它暴露的一个结构问题

`sources` 两行都已填全：`collection=四庫全書總目 / title=欽定四庫全書總目 /
script_style=woodblock_kai / era=qing_qianlong / cols_per_page=9 / chars_per_col=21`。

填的时候发现两件原文没写对的事：

1. **`v2` 不是第二册**。它与 `vol01` 页码完全重合（101 页 vs 108 页，同一批 page id），
   是 v2 管线产出的实例源。所以库里现在**只有一个套的两个 source**，不是两个套。
   原文 §3 层 2「vol02 将是第二个 source」仍待兑现——vol02 的实例还没进库。

2. **`edition_tag` 改不得**。它是 `glyphs` 的连接键（`scripts/bench_font_glyphs.py:48`
   靠 `glyphs.edition_tag = sources.edition_tag` 做 join），把它统一成 `wuyingdian_zongmu`
   会让那个 join 返回 0 字；而且 vol01 与 v2 在 **229 个字种**上重叠，合并直接撞
   `UNIQUE(edition_tag, char)`。这不是改个字符串的事，是一次数据迁移。

第 2 点对层 2 有实质影响：**现在的 schema 表达不了"同一个套下的多个 source"**——
`edition_tag` 同时被当成 source 标识和套标识。要么给 `sources` 加 `set_id`，要么把
`glyphs` 的连接键换掉。这是 §5 动作 4（原型库按套聚合）的前置条件，已作为 G8 进 todo。


**不做**：每套一个网络；大骨干；笔画序列；Slot Attention；在只有一种风格时调套权重表。

## 6. 风险与口径

- 同书迁移好（vol02）不代表跨风格好，别外推到抄本。
- 异体偏好表只有 6 组，作先验，不作规则；`己已巳` 仍按用户规矩强制人审。
- 评测口径：unseen 1,327 条里约 30 条的金标不在整理本字表内，融合评测（字表 = 整理本）
  的 emb 单源 94.5 与本实验（字表 + 基准字）的 96.8 差在这里，两边各自自洽，比较时对齐字表。
